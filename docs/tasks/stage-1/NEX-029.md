**Status:** ready-for-review · **Owner:** Claude · **Branch:** task/NEX-029 · **Depends on:** NEX-010, NEX-031
**Requirements:** D15, D16, D22, E-7, G-6, C-4, M01–M07, M10, M11, M83

## Goal
`@nexus/mocks` serves the demo fixtures over MSW (browser and Node) as `/api/v1/*` read endpoints that behave like the
real API: tenant isolation, paging, `ApiError`, permission and entitlement checks, minor masking, and switchable
`empty` / `error` / `slow` / `offline` scenarios.

## Build
1. Every response body is parsed with its contract schema inside the handler before returning (fail loudly in tests).
2. Permission names come from the NEX-010 catalogue; vault/access endpoints need `m83.*` permissions; audit needs
   `m06.audit.read`. Never return another tenant's records (D22 test).
3. Each handler file ≤ 300 lines; no write (POST/PUT/PATCH/DELETE) handlers here — screen tasks add their own.
