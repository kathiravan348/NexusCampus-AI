## Goal
`@nexus/services` is the only data path for screens: one API client for `mock | real`, every response Zod-validated,
TanStack Query with an encrypted IndexedDB-persisted cache (L1), an outbox-backed mutation helper (L2), and the read
hooks the app shell needs.

## Files
Create (in `frontend/packages/services/src/`), each with a `*.test.ts(x)`:
- `config.ts` — `DATA_MODE` from `import.meta.env.VITE_DATA_MODE` (`mock` default in dev, `real` otherwise; any other
  value throws), `API_BASE` (`/api/v1`)
- `client.ts` — `ApiClient` (`get(path, schema, query?)`, `send(method, path, body, schema)`): sets `X-Nexus-Tenant`,
  `X-Nexus-User` (mock mode only) and `X-Nexus-Scenario` (mock mode, from `getMockScenario()`); parses success with
  the given schema and errors with `ApiErrorSchema`; throws `ApiRequestError { status, error }`; network failure →
  `ApiRequestError` with `status 0`, code `internal`, `offline: true`
- `session.ts` — `SessionProvider` / `useSession()` holding `{ tenantId, userId } | null`, persisted in
  `sessionStorage` (`nexus.session`); `signIn(tenantId, userId)`, `signOut()` (calls `signOutWipe`; returns
  `{ blocked: true, pending }` when the outbox holds writes, O-3); `getMockScenario` / `setMockScenario`
  (`localStorage` `nexus.mockScenario`, try/catch)
- `query.tsx` — `NexusQueryProvider` (QueryClient + `PersistQueryClientProvider` with an async persister backed by
  `@nexus/offline` `setCached`/`getCached`, scoped to `{ tenantId, userId }`; `buster` = app version); retries off for
  4xx; `useLastSynced(queryKey)` for the "last synced" label
- `mutation.ts` — `useOutboxMutation({ moduleId, operation, mergeRule, priority, send })`: online → `send`; offline or
  network error → `enqueueWrite` and resolve as `{ queued: true }`; registers an `OutboxTransport` that replays via the
  client with the entry's `idempotencyKey` header `Idempotency-Key`; `flushOutbox` on `online` event
- `keys.ts` — `queryKeys` factory (`['t', tenantId, 'm01', 'tenant']` …); every key starts with tenant + user
- `modules/m01.ts` (`useDemoTenants`, `useTenant`, `useInstitutionProfile`, `useCalendars`, `useLocaleSettings`),
  `modules/m02.ts` (`useMe`), `modules/m03.ts` (`useTheme`, `useFonts`), `modules/m04.ts` (`useTextOverrides(locale)`),
  `modules/m05.ts` (`usePlan`, `useEntitlements`, `useUsage`) — response schemas built from contracts
