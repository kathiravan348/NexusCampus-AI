# NEX-015 — Text & language studio (M04): key search, per-locale overrides, in-context preview, import/export, history

**Status:** ready-for-review · **Owner:** Gemini · **Branch:** task/NEX-015 · **Depends on:** NEX-012
**Requirements:** M04 (L1), C-2, G-1, D8, D28, D30, NEX-003 review note

## Goal
An admin finds any message key, sees the resolved text per layer (platform → terminology → group → institution →
campus), sets or removes an override per locale with ICU validation (`isValidMessage`), previews it, sees the history
and rolls back, and imports/exports overrides as JSON.

## Build
1. Keys searchable by key and by current text; filter "overridden only". Group-locked override shown read-only.
2. An invalid message never saves (client `isValidMessage` + server check). Raw keys never appear in the UI.
3. Tests: search finds `term.learner`; override changes the menu text app-wide after save; invalid ICU blocked;
   rollback restores previous text; import dry run lists adds/changes/rejects; Apex edits `ar` text RTL.
