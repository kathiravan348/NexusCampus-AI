# NEX-050 — Vault: HashiCorp Vault in Compose, per-tenant keys, field encryption, key status API (M83)

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-050 · **Depends on:** NEX-046
**Requirements:** M83, ARCHITECTURE §10, D46, V-2

## Goal
Each tenant has its own Transit key in Vault; sensitive fields (health, safeguarding, ID numbers, bank details) are
envelope-encrypted with it; `GET /api/v1/vault/keys` returns key metadata only; offboarding destroys the key.

## Files

## Build
1. Never log or return key material; the API returns the `KeyStatus` contract only.
2. Crypto-shred: destroying a tenant key makes its encrypted fields unreadable; audit chain still verifies.
3. BYOK / HYOK custody values are stored and shown; their onboarding flow is Stage 2.
