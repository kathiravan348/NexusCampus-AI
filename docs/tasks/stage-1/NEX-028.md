# NEX-028 — Contracts (identity): Person, RoleProfile, User, Session, SsoProvider, Role, Permission

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-028 · **Depends on:** NEX-008
**Requirements:** E-1, E-6, C-4, G-6, M02, D15, D25, D31

## Goal
`@nexus/contracts` defines the strict Zod schemas and TS types for NexusCampus identity and access control — separating
`Person` from `RoleProfile` memberships (D25), plus `User`, `Session`, `SsoProvider`, `Permission`, `Role`, and scoped
`RoleAssignment` — with zero secret fields on the wire.

## Files
Create (in `frontend/packages/contracts/src/`), each `X.ts` with a `X.test.ts`:
- `person.ts` — `PersonSchema` (`id`, `tenantId`, `legalName`, `preferredName` nullable, `dateOfBirth` nullable `IsoDate`, `isMinor` boolean, `email` nullable, `phone` nullable E.164, `preferredLocale` nullable `Locale`, `retentionState`, `createdAt`, `updatedAt`); `RoleProfileKindSchema` (`staff | guardian | learner | alumni | external`); `RoleProfileSchema` (`id`, `tenantId`, `personId`, `institutionId`, `campusId` nullable, `kind`, `academicYearId` nullable, `effectiveFrom`, `effectiveTo` nullable, `status` `active|inactive|suspended`, `createdAt`, `updatedAt`)
- `user.ts` — `UserSchema` (`id`, `tenantId`, `personId`, `email`, `status` `invited|active|suspended|locked`, `mfaEnabled`, `passkeyCount` int ≥ 0, `ssoOnly`, `lastSignInAt` nullable, `createdAt`, `updatedAt`); `SessionSchema` (`id`, `tenantId`, `userId`, `deviceId`, `deviceLabel`, `authMethod` `password|sso|passkey`, `mfaVerified`, `ipAddress` nullable, `createdAt`, `lastSeenAt`, `expiresAt`, `revokedAt` nullable); `SsoProviderSchema` (`id`, `tenantId`, `institutionId` nullable, `protocol` `oidc|saml2`, `name`, `issuerUrl` HTTPS URL, `clientId`, `domains` non-empty unique lowercase, `scimEnabled`, `enabled`, `createdAt`, `updatedAt` — never client secrets)
- `rbac.ts` — `PermissionCodeSchema` (`<module>.<resource>.<action>`, e.g. `m02.user.invite`); `PermissionSchema` (`code`, `moduleId`, `sensitive`, `descriptionKey`); `ScopeKindSchema` (`group | institution | campus | department | class | own`); `RoleScopeSchema` (`kind`, `targetId` nullable); `RoleSchema` (`id`, `tenantId`, `name`, `system`, `permissions` non-empty unique, `allowedScopeKinds` non-empty unique, `createdAt`, `updatedAt`); `RoleAssignmentSchema` (`id`, `tenantId`, `userId`, `roleId`, `scope`, `academicYearId` nullable, `effectiveFrom`, `effectiveTo` nullable, `grantedBy`, `createdAt`)

## Build
1. Every object uses `z.strictObject`; export `XSchema` and `type X = z.infer<typeof XSchema>`. Named exports only. Files ≤ 300 lines. Compare timestamps with `Date.parse` (not string compare, per NEX-008 review).
2. Refines: `updatedAt >= createdAt` on every timestamped record; `effectiveTo >= effectiveFrom` when non-null (`RoleProfile`, `RoleAssignment`); `Session`: `lastSeenAt >= createdAt`, `expiresAt > createdAt`, `revokedAt >= createdAt` when non-null; `SsoProvider`: `issuerUrl` must be `https://` and `domains` lowercase + unique; `Permission`: `code` starts with `${moduleId.toLowerCase()}.`; `RoleScope`: `targetId === null` iff `kind === "own"`; `Role`: `permissions` and `allowedScopeKinds` unique.
3. Tests per schema: valid example passes; unknown extra key, invalid enum/format (non-E.164 phone, `http://` issuer, mismatched `Permission.moduleId`, `own` scope with non-null `targetId`, `effectiveTo < effectiveFrom`, `expiresAt <= createdAt`) all fail.
