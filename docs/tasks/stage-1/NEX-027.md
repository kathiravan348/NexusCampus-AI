# NEX-027 — Contracts (ops): notifications, sync, AI, vault & access grants

**Status:** planned · **Owner:** — · **Branch:** task/NEX-027 · **Depends on:** NEX-008
**Requirements:** M07, M10, M11, M83, O-1, O-3, A-1–A-5, V-2, V-3, V-5, D13, D14, D22, D24

## Goal
`@nexus/contracts` has strict Zod schemas + TS types for notification templates/deliveries/preferences, device sync
and conflicts, AI settings/credits/Assist answers, and vault key status, access requests, grants and break-glass.

- `AGENTS.md` §7; `docs/ARCHITECTURE.md` §5, §7, §10; `docs/REQUIREMENTS.md` §6, §8, §10
- `frontend/packages/contracts/src/{common,event,rbac}.ts` (style), `frontend/packages/offline/src/types.ts` (read

## Files
Create (in `frontend/packages/contracts/src/`), each `X.ts` with a `X.test.ts`:
- `notification.ts` — `ChannelSchema` email|sms|whatsapp|push|in_app; `NotificationTemplateSchema` (`id`, `tenantId`,
  `eventType` dotted, `channel`, `locale`, `subject` nullable — required iff `email`, `body` non-empty ICU, `version`,
  `enabled`, `updatedAt`); `NotificationDeliverySchema` (`id`, `tenantId`, `templateId`, `recipientPersonId`,
  `channel`, `status` queued|sent|delivered|failed|suppressed, `reason` nullable — required iff failed|suppressed,
  `queuedAt`, `sentAt` nullable ≥ queuedAt); `NotificationPreferenceSchema` (`userId`, `channel`, `eventType`
  nullable = all, `enabled`, `quietHours` nullable `{ start, end }` `HH:mm`, `timeZone`)
- `sync.ts` — `DeviceSyncSchema` (`id`, `tenantId`, `userId`, `label`, `platform` web|android|ios|edge,
  `lastSyncAt` nullable, `pendingCount`, `conflictCount`, `lostWriteCount` ints ≥ 0, `status`
  active|revoke_pending|revoked, `revokedAt` nullable — set iff revoked); `SyncConflictSchema` (`id`, `tenantId`,
  `deviceId`, `moduleId`, `operation`, `mergeRule` lww-audited|append-only|manual-review-only, `summaryKey` message
  key, `clientVersion`/`serverVersion` ints, `status` open|resolved, `resolution` nullable
  keep_server|keep_client|merged — set iff resolved, `createdAt`, `resolvedAt` nullable)
- `ai.ts` — `CapabilityTierSchema` fast|balanced|reasoning|embedding|multimodal; `AiSettingsSchema` (`tenantId`,
  `enabled`, `modules` record ModuleId→boolean, `blockedModules` must include `M61`, `M83`; `safeguardingEnabled`
  default false, `piiRedaction` literal `true`, `minorGuardianConsentRequired` literal `true`, `defaultTier`,
  `provider` `{ kind: cloud|local, label }`, `updatedAt`); `AiCreditSchema` (`tenantId`, `periodStart`,
  `periodEnd`, `granted`, `used` ints ≥ 0, `hardCap` boolean); `AssistAnswerSchema` (`id`, `tenantId`, `question`,
  `answer`, `locale`, `aiGenerated` literal `true`, `sources` non-empty `{ moduleId, recordType, recordId, label }[]`,
  `tier`, `creditsUsed`, `createdAt`)
- `vault.ts` — `KeyStatusSchema` (`id`, `tenantId`, `purpose` tenant_data|field_health|field_identity|field_finance,
  `custody` platform|byok|hyok, `status` active|rotating|revoked|destroyed, `createdAt`, `rotatedAt` nullable — never
  key material); `AccessRequestSchema` (`id`, `tenantId`, `staffRef` opaque, `staffDisplayName`, `reason`,
  `modules` non-empty unique, `mode` read|edit, `durationHours` 1–72, `status` pending|approved|denied|expired|revoked,
  `requestedAt`, `decidedAt`/`decidedBy` nullable — set iff not pending); `AccessGrantSchema` (`id`, `tenantId`,
  `requestId`, `modules`, `mode`, `startsAt`, `endsAt` ≤ startsAt + 72 h, `revokedAt` nullable);
  `BreakGlassNoticeSchema` (`id`, `tenantId`, `category` legal_order|security_incident, `approverRefs` exactly 2
  distinct, `occurredAt`, `notifiedAt` ≥ occurredAt, `reportUrl` nullable)
Modify: `frontend/packages/contracts/src/index.ts`, `docs/CONTRACTS.md` (rows; mock "NEX-031")

## Build
1. NEX-028 rules: `z.strictObject`, `XSchema` + `type X`, `Date.parse` for time order. Named enum schemas exported.
2. Tests per schema: valid passes; extra key, bad enum and each refine above fail (e.g. 73 h grant, 1 approver,
   `AiSettings` without `M61` blocked, `piiRedaction: false`, email template without subject).
3. Test: no field in any `vault.ts` / `ai.ts` schema matches `/material|secret|token|private|wrapped|apikey/i`.
