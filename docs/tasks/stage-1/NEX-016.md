# NEX-016 — Users, roles & permission matrix (M02): users list, invite, roles, scopes, sessions, SSO settings

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-016 · **Depends on:** NEX-012
**Requirements:** M02 (L1), E-1, E-6, C-4, G-6, D25

## Goal
An admin lists and searches users (minors masked per role), invites a user, suspends/reactivates, assigns roles in a
scope, edits custom roles in a permission matrix (system roles read-only), sees and revokes sessions, and views/edits
the SSO provider settings (no secrets shown or stored in the browser).
