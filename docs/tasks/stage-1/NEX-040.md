# NEX-040 — Default languages English, Hindi, Tamil; Arabic removed (Owner decision D42)

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-040 · **Depends on:** NEX-003, NEX-010, NEX-021
**Requirements:** D8, D9, D42

## Goal
The platform ships three languages: English (source), Hindi (`hi`) and Tamil (`ta`). Every message key and every
terminology pack exists in all three, and tests enforce it for all future work. Arabic is removed (texts, terminology,
font, demo data). Right-to-left support stays in the code (logical CSS, `direction.ts`), so an RTL language can be added
later without rework.

## Found by
Owner: "for default keep three languages English, Hindi, Tamil … in future development also keep these three; if we need
more we add later; ignore Arabic." Owner chose: remove Arabic; Riverside Education Group runs in Hindi, Apex Coaching in
Tamil (both also offer English); the other demo institutions stay English.
