# NEX-018 — Plans & usage (M05): current plan, modules on/off, AI credits, usage meters

**Status:** planned · **Owner:** — · **Branch:** task/NEX-018 · **Depends on:** NEX-012
**Requirements:** M05 (L0), A-1, ideology §2.2 ("off = hidden, never broken"), D19, D20

## Goal
An admin sees the current plan, every module with its entitlement source (core / plan / add-on / trial + expiry), can
switch optional entitled modules on/off for the institution (menu updates at once), and sees usage meters (learners,
staff, storage, AI credits, SMS, email) with limits and warnings at ≥ 80 % and ≥ 100 %.

## Build
1. Switching a module off removes its menu item; its URL then shows `ModuleOff` (shell). Switching on restores it.
2. AI credits meter reads `UsageMeter` `ai_credits`; Little Steps shows AI not in plan.
3. Tests: toggle hides/shows a menu item; core switch disabled; 95 % meter has danger tone and accessible value text;
   `empty` scenario shows EmptyState.
