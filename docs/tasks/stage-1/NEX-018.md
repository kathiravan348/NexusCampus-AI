## Goal
An admin sees the current plan, every module with its entitlement source (core / plan / add-on / trial + expiry), can
switch optional entitled modules on/off for the institution (menu updates at once), and sees usage meters (learners,
staff, storage, AI credits, SMS, email) with limits and warnings at ≥ 80 % and ≥ 100 %.
