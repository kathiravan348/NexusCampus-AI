# NEX-041 — L1 screens show when their data was last synced (fix from Stage 1 review)

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-041 · **Depends on:** NEX-021
**Requirements:** O-1 (L1), ARCHITECTURE §5, D43 (fix allowed by the freeze outcome)

## Goal
Every L1 module screen (Users & access, Theme studio, Text & language studio, Notifications) shows a small
"Last synced {time}" line under its heading, from the time its main data was last fetched, so offline readers know how
old the cached data is.

## Read first
- `AGENTS.md`; `docs/review/STAGE-1-FEEDBACK.md` (Freeze outcome); `docs/ARCHITECTURE.md` §5
- `frontend/apps/campus/src/app/modules.ts` (offline levels); `frontend/apps/campus/src/app/ShellHeader.tsx`

## Files
Create:
- `frontend/apps/campus/src/app/LastSynced.tsx` (+ `LastSynced.test.tsx`) — takes a TanStack Query `dataUpdatedAt`
  (ms; 0 = never) and renders `common.syncLastSynced` with the time formatted by `@nexus/i18n` `formatDateTime` in the
  tenant time zone (same as `ShellHeader`); renders nothing when 0
Modify:
- `frontend/apps/campus/src/modules/m02/AccessPage.tsx`, `m03/ThemeStudioPage.tsx`, `m04/TextStudioPage.tsx`,
  `m07/NotificationsPage.tsx` — place `<LastSynced>` under the page intro, fed by the screen's main query
- the four page tests (one assertion each); `docs/guides/USER-GUIDE.md` (offline section: one sentence)

2. Style `text-body-sm text-text-secondary`; plain text (no live region), so refetches are not announced.
3. In the pseudo-locale, format the time in the source locale, like `ShellHeader`.
