**Status:** planned · **Owner:** — · **Branch:** task/NEX-059 · **Depends on:** NEX-047–NEX-058

## Goal
CI proves that every backend response model accepts and rejects the same JSON as its frozen Zod contract, so the
backend can never drift from the screens.

## Read first
- `AGENTS.md`; `docs/CONTRACTS.md`; `frontend/packages/contracts/src/index.ts`

## Files
Create:
- `frontend/packages/contracts/scripts/export-samples.ts` — for every contract: valid samples (from the mock
  fixtures) and invalid samples (from the contracts' own tests) → `frontend/packages/contracts/parity/*.json`
- `backend/tests/parity/test_contract_parity.py` — maps contract name → Pydantic model; valid parse, invalid reject
- `backend/tests/parity/contract_map.py`
Modify:
- `frontend/packages/contracts/package.json` (script `export:samples`), `backend/scripts/check.py` (fail if samples
  are stale: hash check), `docs/CONTRACTS.md` (column "Backend model"), `.gitignore` if samples are generated

## Build
1. Every contract row in `docs/CONTRACTS.md` has a backend model or is marked "frontend only".
2. Field names: camelCase in JSON (Pydantic alias generator), snake_case in Python.
3. A missing mapping fails the test with the contract name.
