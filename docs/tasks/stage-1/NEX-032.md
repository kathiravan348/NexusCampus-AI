# NEX-032 — Startup & test timings: timing harness, Vitest reporter, soft budgets, and baseline log

**Status:** planned · **Owner:** — · **Branch:** task/NEX-032 · **Depends on:** NEX-012
**Requirements:** AGENTS.md §8a, D37

## Goal
Every project start (`campus` dev/preview, `ui-storybook` dev, browser dev cold-boot) and every test/check command (`pnpm test`, per-package `test`, `build`, `review:check`) prints elapsed time and warns when over its soft budget, with measured baselines in `docs/TIMINGS.md`.

## Read first
- `AGENTS.md` §5a, §8, §8a, §9; `docs/DECISIONS.md` (D37); `docs/templates/HANDOFF.md`
- `frontend/{package.json,vitest.config.ts,tsconfig.base.json}`, `frontend/apps/campus/{package.json,src/main.tsx}`, `frontend/packages/ui-storybook/package.json`

## Files
Create:
- `frontend/scripts/timing-budgets.ts` — soft-budget table (ms) for `dev:campus`, `preview:campus`, `dev:storybook`, `boot:campus`, `build:campus`, `build:storybook`, `build:all`, `check:format`, `check:lint`, `check:typecheck`, `check:test`, `review:check`, `test:pkg`, `e2e`, plus reserved keys (`dev:control`, `backend:start`, `backend:check`, `compose:up`); exports `TIMING_BUDGETS_MS`, `formatDuration(ms)`, `evaluateBudget(key, ms)`
- `frontend/scripts/time-run.ts` — Node 24 TS CLI (`node scripts/time-run.ts <key> [--label <name>] [--ready-pattern <regex>] [--exit-after-ready] -- <cmd...>` and `--sequence` for `review:check`) via `hrtime.bigint()`; logs `[timing] <label>: X.XXs (budget Y.Ys — OK | WARN: over budget)`, preserves exit code, never fails on soft-budget warning
- `frontend/scripts/vitest-timing-reporter.ts` — zero-dep Vitest `Reporter`: per-package/project test time, total time, top-5 slowest test files, soft-budget warning (`check:test`)
- `frontend/scripts/measure-timings.ts` — runs cold/warm start probes (`campus` dev/preview, `ui-storybook` dev via `--ready-pattern` + `--exit-after-ready` with clean process-tree teardown) + `review:check`, printing a markdown table for `docs/TIMINGS.md`
- `frontend/scripts/time-run.test.ts` — unit tests (formatting, OK vs WARN, exit code, `--ready-pattern` + `--exit-after-ready`, `--sequence` table, Vitest reporter aggregation)
- `frontend/tsconfig.scripts.json` — extends `tsconfig.base.json` (`types: ["node"]`, includes `scripts/**/*.ts`)
- `docs/TIMINGS.md` — living baseline & soft-budget table for all places (dev/preview/Storybook/boot starts, builds, workspace & per-package tests, `review:check` steps, plus reserved tables for `e2e`, `apps/control`, `backend/`, Docker Compose)
Modify:
- `frontend/package.json` — route `dev`, `storybook`, `build`, `test`, `check:format`, `check:lint` (also lint `scripts`), `check:typecheck` (also `tsc -p tsconfig.scripts.json --noEmit`), `check:test`, `review:check` (`--sequence`) via `scripts/time-run.ts`; add `"timings:measure": "node scripts/measure-timings.ts"`
- `frontend/vitest.config.ts` — add `scripts` test project (`scripts/**/*.test.ts`, `environment: "node"`) and wire `vitest-timing-reporter.ts` alongside `"default"`
- `frontend/apps/campus/package.json` (`dev`, `preview`, `build`, `test`), `frontend/packages/ui-storybook/package.json` (`dev`, `build`, `test`), and every other `frontend/packages/*/package.json` (`test` with `--label test:<pkg>`, budget `test:pkg`) — wrap with `node ../../scripts/time-run.ts`
- `frontend/apps/campus/src/main.tsx` — dev-only (`import.meta.env.DEV`) `performance.mark`/`measure` for `nexus:boot` (entry → MSW ready → React mount), logging `[timing] boot:campus` to console; zero prod logs, zero UI strings
- `docs/STRUCTURE.md` (add `frontend/scripts/` and `docs/TIMINGS.md`)

## Build
1. Zero new dependencies (Node 24 native TS + `node:*` built-ins); PowerShell 5.1 safe (`AGENTS.md` §5a); kill full process tree on Windows/POSIX on `--exit-after-ready` so no orphan Vite/Storybook servers remain.
2. Strict TS, no `any`, named exports, files ≤ 300 lines. Soft budgets warn only and never alter exit codes.
3. Run `fnm exec --using=24 -- pnpm --dir frontend timings:measure` to populate real baselines in `docs/TIMINGS.md`.
