# NEX-002 — Theme engine: tokens + runtime tenant theme + contrast guard

## Goal
`@nexus/ui-core` exposes Nexus Style tokens as CSS variables and Tailwind v4 classes (light default, dark), and can
apply an institution's full theme (colours, fonts, radius, density) at runtime, refusing themes that fail WCAG 2.2 AA.

## Build
1. Port NOVA's pipeline; rename `nova` → `nexus` (storage key `nexus-theme`). Themes `light` (default) and `dark`.
2. Colour tokens = NOVA's set renamed: `action*` → `brand-primary`, `brand-primary-text`, `brand-primary-subtle`,
   `on-brand`; add `brand-accent`; `profit*` → `success*`; `loss*` → `danger*`; keep `warning*`; add `info`,
   `info-subtle`, `info-text`; drop `chart-benchmark`. Keep NOVA hex values for renamed tokens.
   Font tokens `font-sans`, `font-mono`; radius tokens as NOVA; density presets (`compact` | `comfortable` | `spacious`)
   via CSS spacing-scale variable. Add `contrastPairs` to `tokens.json`: every text/background and UI-component pair
   used by components, each declaring `minRatio` (`4.5` for normal text, `3.0` for large text, icons, focus rings and
   borders per WCAG 2.2 SC 1.4.11).
3. Fonts: font library = `@fontsource/inter` (default sans), `@fontsource/noto-sans-arabic` (RTL fallback),
   `@fontsource/jetbrains-mono` (mono). `fonts.ts` maps a font id → CSS family + loader; unknown id → default.
4. `tenantTheme.ts`: `applyTenantTheme({ light?, dark?, fonts?, radius?, density? })` sets only CSS variables on
   `<html>` (partial token maps); `resetTenantTheme()`. Before applying it calls `checkTheme()`.
5. `contrast.ts`: WCAG 2.2 ratio; `checkTheme(theme)` returns every failing `contrastPairs` entry (`< pair.minRatio`)
   for both themes after merging with defaults; `applyTenantTheme` throws `ThemeContrastError` listing them.
6. Tests: tokens generate both themes; all default pairs pass; a theme with `brand-primary: #FFEB3B` text on white fails
   with that pair named; a valid partial theme changes only its variables; `check-classes` rejects non-token classes.
