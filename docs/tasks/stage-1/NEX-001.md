## Build
1. Copy NOVA's config files and rename every `@nova/*` → `@nexus/*`, `novaAliases` → `nexusAliases`.
   Drop aliases for packages that do not exist here (`ui-trading`, `mocks/browser`, `ui-core/styles.css`).
2. Aliases for all 7 packages plus `@nexus/brand` (→ `../brand.config.ts`) in both `tsconfig.base.json` and `vite.aliases.ts`.
3. ESLint: adding a rule that forbids physical direction classes/properties is **not** part of this task (NEX-005).
4. Pin exact versions (no `^`/`~`). Same versions as NOVA unless one fails to install; then note it in the handoff.
5. `index.html` has no hardcoded brand name in `<title>`.
6. Install with `fnm exec --using=24 -- pnpm --dir frontend install`; commit `frontend/pnpm-lock.yaml`.
