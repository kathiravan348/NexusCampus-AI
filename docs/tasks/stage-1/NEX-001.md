# NEX-001 — Monorepo setup (port NOVA tooling)

**Status:** planned · **Owner:** — · **Branch:** task/NEX-001 · **Depends on:** —

## Goal
An empty but working frontend monorepo, same tooling and versions as NOVA, where `pnpm review:check` passes on Windows.

## Read first
- `AGENTS.md`, `docs/STRUCTURE.md`, `brand.config.ts`
- NOVA sources to copy from (read-only, sibling folder `../NOVA/frontend/`): `package.json`, `pnpm-workspace.yaml`,
  `tsconfig.base.json`, `vite.aliases.ts`, `vitest.config.ts`, `eslint.config.js`, `.prettierrc`, `.prettierignore`,
  `apps/nova-orbit/{package.json,tsconfig.json,vite.config.ts,index.html,src/main.tsx,src/App.tsx,src/App.test.tsx}`

## Files
Create:
- `frontend/package.json` (name `nexus-monorepo`; NOVA's devDependencies and versions; scripts `build`, `typecheck`,
  `lint`, `test`, `format`, `format:check`, `check:*`, `review:check` as in NOVA; `dev` = `pnpm --filter campus dev`)
- `frontend/pnpm-workspace.yaml`, `frontend/tsconfig.base.json`, `frontend/vite.aliases.ts`, `frontend/vitest.config.ts`,
  `frontend/eslint.config.js`, `frontend/.prettierrc`, `frontend/.prettierignore`
- Empty packages, each with `package.json`, `tsconfig.json`, `vitest.config.ts`, `src/index.ts` (`export {};`):
  `ui-core`, `ui-edu`, `i18n`, `offline`, `contracts`, `services`, `mocks` — names `@nexus/<folder>`
- App `frontend/apps/campus` (package name `campus`): Vite + React + TS; renders one `<h1>` with `brand.name`;
  sets `document.title` from `brand`; `<html dir>` defaults to `ltr`; smoke test `src/App.test.tsx`
Modify:
- `docs/STRUCTURE.md` only if the real layout differs.

## Build
1. Copy NOVA's config files and rename every `@nova/*` → `@nexus/*`, `novaAliases` → `nexusAliases`.
   Drop aliases for packages that do not exist here (`ui-trading`, `mocks/browser`, `ui-core/styles.css`).
2. Aliases for all 7 packages plus `@nexus/brand` (→ `../brand.config.ts`) in both `tsconfig.base.json` and `vite.aliases.ts`.
3. ESLint: adding a rule that forbids physical direction classes/properties is **not** part of this task (NEX-005).
4. Pin exact versions (no `^`/`~`). Same versions as NOVA unless one fails to install; then note it in the handoff.
5. `index.html` has no hardcoded brand name in `<title>`.
6. Install with `fnm exec --using=24 -- pnpm --dir frontend install`; commit `frontend/pnpm-lock.yaml`.
