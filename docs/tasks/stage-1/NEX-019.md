# NEX-019 — Sync centre (M10): this device, pending queue, conflicts, devices, remote wipe

**Status:** planned · **Owner:** — · **Branch:** task/NEX-019 · **Depends on:** NEX-012
**Requirements:** M10, O-1–O-4, D13, NEX-007 (outbox, wipe)

## Goal
Any user sees this device's sync state, pending and failed writes (from the local outbox) with "sync now", and resolves
conflicts; an admin sees the institution's devices, their pending/conflict/lost-write counts, resolves server-side
conflicts and requests a remote wipe (revoke) of a device.

## Build
1. Devices/Conflicts tabs only for users with `m10.device.read`; This device tab for everyone, offline included.
2. Revoking the current device is allowed but warns twice; the mock marks it `revoke_pending` (wipe runs on the device
   in the build step — note it in USER-GUIDE as a known limit).
3. Tests: outbox entries render and update live; sync now flushes via a fake transport; offline render works; revoke
   confirm flow; conflict resolve removes it from the open list and decrements the device count.
