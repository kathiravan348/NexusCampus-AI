## Goal
Any user sees this device's sync state, pending and failed writes (from the local outbox) with "sync now", and resolves
conflicts; an admin sees the institution's devices, their pending/conflict/lost-write counts, resolves server-side
conflicts and requests a remote wipe (revoke) of a device.
