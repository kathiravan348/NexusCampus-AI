# NEX-014 — Theme studio (M03): token editor, fonts, density, logo, live preview, contrast guard, group locks

**Status:** planned · **Owner:** — · **Branch:** task/NEX-014 · **Depends on:** NEX-012
**Requirements:** M03 (L1), C-1, G-8, D7, D28, D29, NEX-002 review note

## Goal
An admin edits the institution theme (light + dark colour tokens, fonts, radius, density, logo/favicon URLs) with a
live preview; the contrast guard lists every failing pair and blocks save; tokens locked by the group are read-only;
changing `brand-primary` suggests matching `brand-primary-text` / `on-brand` values that pass.

## Build
1. Preview applies to the preview pane only; **Save** applies to the app (`applyTenantTheme`) after the server accepts.
2. Save is disabled while `checkTheme` returns failures; the panel explains which pair and the required ratio.
3. Riverside institution admin: `brand-primary` locked by the group (read-only, explains why).
4. Tests: editing a token updates the preview; failing pair blocks save; suggestion fixes it; locked token read-only;
   saving shows a success toast and new version; reset to platform default per token.
