# NEX-051 — Provider access (M83): access requests, approval, time-boxed grants, break-glass notices

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-051 · **Depends on:** NEX-050
**Requirements:** M83, V-1–V-7, ARCHITECTURE §10 (no standing access)

## Goal
Provider staff can only reach tenant data through an access request that the institution owner approves (narrowed,
≤ 72 h) or denies; an approved grant yields a short-lived scoped credential, every use is audited in the tenant's log,
and grants expire or are revoked early. Break-glass notices are readable.

## Build
1. Approval can only narrow modules, mode and hours (wider → `400`, like the mock); approver needs
   `m83.grant.approve` and must acknowledge the end time.
2. Grant use outside its window, modules or mode → 403; revoke takes effect on the next request.
3. Every grant use writes an audit row with `actorKind = provider_grant` and `grantId`.
