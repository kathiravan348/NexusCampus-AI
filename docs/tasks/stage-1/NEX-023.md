# NEX-023 — Data vault & access grants (M83): key status, access requests, active grants, break-glass, history

**Status:** planned · **Owner:** — · **Branch:** task/NEX-023 · **Depends on:** NEX-012
**Requirements:** M83 (L0), V-1–V-5, D22, E-3, A-3 (never AI on keys or grants)

## Goal
An institution owner/admin sees the vault key status (custody, rotation — never key material), approves or denies
provider access requests (scope, mode, ≤ 72 h, reason, named staff), revokes active grants early, sees break-glass
notices with their report, and reviews what each grant did (audit events with `actorKind: provider_grant`).
