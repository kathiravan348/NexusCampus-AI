## Goal
The database has the tenancy core (tenants, groups, institutions, campuses, locale settings, calendars) with RLS by
`tenant_id`, a transaction-scoped tenant context, region pinning, and a seed that loads the five demo tenants.

## Build
1. App role `nexus_app` without `BYPASSRLS`; migrations run as the owner. Every tenant table has `tenant_id`, an RLS
   policy `tenant_id = current_setting('app.tenant_id', true)` and `FORCE ROW LEVEL SECURITY`.
2. `tenants.region`; the app refuses (`503`, logged) any tenant whose region ≠ `settings.region`.
3. Columns mirror the Zod contracts (snake_case); constraints carry their rules (default locale ∈ supported, …).
4. The seed is idempotent; `--reset` reloads demo data only when `settings.environment = dev`.
