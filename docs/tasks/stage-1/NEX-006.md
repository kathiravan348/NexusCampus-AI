## Build
1. **No hardcoded text (D8):** `@nexus/ui-core` uses `useText()` from `@nexus/i18n` for default UI chrome (`AppShell` skip link, open/close menu, main nav label; `Modal`/`Toast` close label; `DemoBanner` default notice; `EmptyState` default message; `SyncStatus` labels; `DataTable` empty/loading/pagination labels). Add any missing `common.*` keys to both `en.json` and `ar.json` with translator descriptions.
2. **Tokens & RTL:** map all NOVA tokens to Nexus Style (`brand-primary`, `on-brand`, `bg-surface`, `danger*`, `warning*`, `success*`, `info*`); use `rtl:tracking-normal` on `text-label`. Logical CSS only (`start-0`, `border-e`, `md:ps-(--sidebar-width)`, `focus:start-3`, `-me-2`, `text-end` — zero physical left/right classes). Mirror directional chevrons in RTL (`rtl:rotate-180`) where meaningful. Keep files ≤ 300 lines.
3. **Components:** port `AppShell` (desktop fixed sidebar + mobile Radix drawer + skip link), `NavItem`, `Modal` (Radix Dialog, `md|lg|xl`), `Tabs` (Radix Tabs), `Toast` (`ToastProvider` + `useToast`, tones `info|success|warning|danger`), `EmptyState`, `DemoBanner` (`role="note"`), `DataTable` (TanStack Table, offset pagination `{ page, pageSize, total }` per D15, responsive mobile cards at 360px, loading/empty/error states). Build `SyncStatus` for O-1 (`state: synced|pending|syncing|conflict|offline|error`, optional `pendingCount`, `conflictCount`, `lastSyncedAt`, `onClick`; props-driven — do not import `@nexus/offline`).
4. **Tests & stories:** Vitest unit tests (wrapping `@nexus/i18n`-backed components in `I18nProvider`) and Storybook stories (default, loading, empty, error, offline/pending where relevant) checked at 360px/desktop, light/dark, `en-XA`, `ar` RTL with zero a11y violations.
