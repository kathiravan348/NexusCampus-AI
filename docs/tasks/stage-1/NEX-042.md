## Goal
`backend/` exists as a modular-monolith FastAPI app that starts locally against PostgreSQL 16 (pgvector image) and
Redis in Docker Compose, with `backend-check` (format, lint, strict types, tests) and `[timing]` lines.

## Build
1. Compose project `nexuscampus`: `pgvector/pgvector:pg16` on `127.0.0.1:55432`, `redis` on `127.0.0.1:56379`, both
   with `mem_limit` and named volumes. Never touch other projects' containers.
2. Unknown exceptions → `500 internal` envelope without a stack; validation → `400 invalid_request` with `details`.
3. `nexus-dev` runs uvicorn on `127.0.0.1:8000` with reload and logs one `[timing] backend:start …` line when ready.
4. Pin every dependency exactly; list them in the handoff and in DECISIONS Requests.
