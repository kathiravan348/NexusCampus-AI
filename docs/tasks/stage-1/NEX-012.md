# NEX-012 — App shell: providers, demo sign-in, persona + tenant switch, locale switch, entitlement menu, route guard

**Status:** ready-for-review · **Owner:** Gemini · **Branch:** task/NEX-012 · **Depends on:** NEX-006, NEX-011
**Requirements:** C-1, C-2, C-4, G-1, G-8, O-1, A-1, M01, M02, M05, D7, D8, D17, D36

## Goal
`apps/campus` boots (MSW in mock mode), signs in as any demo persona of any demo tenant, applies that tenant's theme,
locale, text overrides and terminology, and shows a responsive shell whose menu lists only modules the tenant is
entitled to and the persona may open; guarded routes, a module registry later tasks add one line to, and a home page.
