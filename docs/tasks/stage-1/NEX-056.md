# NEX-056 — Notifications engine (M07): templates, preferences, outbox worker, delivery log

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-056 · **Depends on:** NEX-046
**Requirements:** M07, G-1, D42 (templates in en / hi / ta)

## Goal
Domain events from the outbox become notifications: the worker picks the template for event + channel + the
recipient's locale (fallback to the institution default, then `en`), honours preferences and quiet hours, renders ICU
and records each delivery. Stage 1 channels deliver through a dev adapter that only logs (no real email/SMS).
