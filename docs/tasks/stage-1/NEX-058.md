# NEX-058 — AI gateway (M11): capability tiers, Claude adapter, guarded pipeline, pgvector retrieval, credits

**Status:** planned · **Owner:** — · **Branch:** task/NEX-058 · **Depends on:** NEX-052, NEX-055
**Requirements:** M11, A-1–A-8, G-5, ARCHITECTURE §7, D14, D24, D45, D47

## Goal
`POST /api/v1/ai/assist` answers questions through the gateway pipeline (entitlement + credits → minor consent and
blocked-module guard → context fetched as the user + tenant-isolated vector retrieval → PII redaction → Claude by
tier → restore names → cite sources → log + meter), and AI settings / credits endpoints work for real.

## Build
1. Never call a model outside `gateway.py`; M61, M62 (unless enabled) and M83 data never enter context.
2. Every answer `aiGenerated: true` with ≥ 1 source; no source → no model call, no credit.
3. Credits: hard cap → `429 rate_limited` reason `credits`; minor without guardian consent → reason `consent`.
4. Tests use `providers/fake.py`; no network in `backend-check`.
