## Build
1. `tokens.json` changes (keep every other value exactly as it is):
   - `radius-xs`: `3px` → `4px`; usage "Progress bars, meters and checkboxes."
   - `border-strong` light: `#7E93B0` → `#7389A6` (old value is 2.92:1 on `bg-ground`). Dark stays `#5B76A3`.
   - New colour token after `brand-accent`: `brand-sky` = `#0284C7` / `#38BDF8`, usage "Ocean Sky: gradient
     highlights and hero auras paired with brand-primary. Tenant-overridable."
   - New `contrastPairs` (minRatio 3): `border-strong` on `bg-ground`, `border-strong` on `bg-raised`,
     `brand-sky` on `bg-surface`. Total pairs: 41.
   - New top-level `effect.tokens` list with one entry: `hero-glow` = `radial-gradient(at 0% 0%, color-mix(in srgb,
     var(--brand-primary) 12%, transparent), transparent 60%), radial-gradient(at 100% 0%, color-mix(in srgb,
     var(--brand-accent) 12%, transparent), transparent 60%)`, usage "Welcome/hero header glow over bg-surface;
     follows tenant brand colours." (No hex: it derives from the brand tokens.)
2. `build-tokens.ts`: add `effect: { tokens: NamedValue[] }` to `TokensData` and emit each effect token as
   `--<name>: <value>;` in the `:root` block (after sizes). No Tailwind entry for effects.
3. Run `pnpm --filter @nexus/ui-core tokens` to regenerate both CSS files.
4. `tokens.test.ts`: add a `"Campus Prism palette is frozen (D39)"` test holding a literal map of **all 33 colour
   tokens** (light + dark) and all 4 radius values; assert `tokens.json` equals it exactly (no extra or missing names).
   Add a test that `:root` in `tokens.css` contains `--hero-glow:` and no `#` hex inside its value. Keep existing tests.
