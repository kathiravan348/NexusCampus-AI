# NEX-004 — Storybook with theme, tenant-theme, locale, RTL and viewport toggles

**Status:** planned · **Owner:** — · **Branch:** task/NEX-004 · **Depends on:** NEX-002, NEX-003

## Goal
One Storybook (`@nexus/ui-storybook`) where every later component is checked in light/dark, under sample institution
themes, in `en` / `ar` (RTL) / `en-XA`, per institution type, at 360/768/1440px, with the a11y panel.

## Build
1. Port NOVA's package (Storybook 10.6.0, `@storybook/addon-a11y` 10.6.0, `@storybook/react-vite` 10.6.0; exact
   pins). `main.ts`: `nexusAliases`, Tailwind plugin, stories from `../src`, `../../ui-core/src`, `../../ui-edu/src`.
   `build` script = `storybook build -o storybook-static --quiet` (so `pnpm build` covers it).
2. Toolbar globals in `preview.tsx` (one decorator applies all, in this order):
   - `theme`: light (default) / dark → `applyTheme`.
   - `tenantTheme`: `none` (default) + every entry of `SAMPLE_THEMES` → `applyTenantTheme` / `resetTenantTheme`.
   - `locale`: `en` (default) / `ar` / `en-XA` → wrap the story in `I18nProvider` (sets `<html dir lang>`).
   - `typePack`: `k12` (default) + the other 7 institution types → `I18nProvider typePack`.
   Viewports 360×800, 768×1024, 1440×900 (NOVA's). `a11y.test: "error"`.
3. `sampleThemes.ts`: `SAMPLE_THEMES` with 3 fictional institutions: a green school (light + dark `brand-primary`),
   a purple music academy (`brand-primary` + `brand-accent`, `radius-md` 4px, `spacious`), an Arabic-font college
   (`fonts.sans: "noto-sans-arabic"`, `compact`). Pick colours that pass; the test proves `checkTheme(theme)` is `[]`
   for every sample (so the toolbar can never throw).
4. `Tokens.stories.tsx` (developer docs; plain English labels allowed here, never in components): colour swatches
   read from `tokens.json` (name + light/dark value + usage), the contrast-pair table with live ratios via
   `contrastRatio`, type scale, spacing, radius, density presets. No hex literals in the file.
5. `Texts.stories.tsx`: every `MESSAGE_KEYS` entry rendered with `useText()` (so toolbar locale/type changes show),
   plus `formatMoney`, `formatDate` (all 4 calendars), `formatDateTime`, `formatPhone` samples.
