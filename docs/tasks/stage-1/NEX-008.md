# NEX-008 — Contracts (core): primitives, ApiError, Page, DomainEvent, tenancy, academic calendar

**Status:** ready-for-review · **Owner:** Claude · **Branch:** task/NEX-008 · **Depends on:** NEX-001
**Requirements:** E-6, E-7, G-1, G-2, G-3, G-5, M01, D9, D10, D11, D15, D25

## Goal
`@nexus/contracts` has the Zod schemas + TS types every later contract builds on, and the tenancy contracts (group →
institution → campus, type profile, academic calendar) that Stage 1 screens and mocks use.

## Read first
- `AGENTS.md` §7, `docs/ARCHITECTURE.md` §2 and §6 (event envelope, temporal scoping), `docs/REQUIREMENTS.md` §3–4
- NOVA (read-only, `../NOVA/frontend/packages/contracts/src/`): `common.ts`, `error.ts`, `error.test.ts` (style only)

## Files
Create (in `frontend/packages/contracts/src/`), each `X.ts` with a `X.test.ts`:
- `common.ts` — `IdSchema` (non-empty opaque string), `UtcDateTimeSchema` (ISO-8601 with `Z`), `IsoDateSchema`
  (`YYYY-MM-DD`), `LocaleSchema` (BCP 47, must equal `Intl.getCanonicalLocales(x)[0]`, so `en_IN` fails),
  `TimeZoneSchema` (accepted by `new Intl.DateTimeFormat("en", { timeZone })`, incl. `UTC`), `CurrencyCodeSchema`
  (in `Intl.supportedValuesOf("currency")`), `CountryCodeSchema` (ISO 3166-1 alpha-2, upper case), `MinorUnitsSchema`
  (safe integer), `RegionSchema` (`in`, `eu`, `us`, `me`, `apac`), `InstitutionTypeSchema` (`ey`, `k12`, `he`, `voc`,
  `tp`, `sk`, `onl`, `grp`), `ModuleIdSchema` (`M01`–`M99`, `P01`–`P99`), `DisplayCalendarSchema` (4 calendars, as i18n)
- `error.ts` — `ApiErrorSchema` `{ error: { code, message, details?, requestId? } }`; codes `invalid_request`,
  `unauthorized`, `forbidden`, `not_found`, `conflict`, `module_disabled`, `rate_limited`, `internal`; `details` =
  `{ path: string, message: string }[]`
- `page.ts` — `pageSchema(item)` → `{ items, total, page, pageSize }` (page ≥ 1, 1 ≤ pageSize ≤ 200, D15);
  `PageQuerySchema` `{ page?, pageSize? }` with defaults 1 / 50; refine: `items.length ≤ pageSize`
- `event.ts` — `DomainEventSchema` (ARCHITECTURE §6 fields; `eventType` dot.case like `m02.user.invited`,
  `schemaVersion` int ≥ 1, `actorId` nullable, `payload` record)
- `tenancy.ts` — `LocaleSettingsSchema` `{ defaultLocale, supportedLocales (non-empty, includes default), timeZone,
  currency, country, weekendDays (unique 0–6) }`; `GroupSchema`; `InstitutionSchema` (`tenantId`, `groupId` nullable,
  `type`, `region`, `locale`, `status` active/trial/suspended, `createdAt`, `updatedAt`); `CampusSchema` (`tenantId`,
  `institutionId`, `code`, `name`, `timeZone` nullable override, `address` with `countryCode`);
  `InstitutionTypeProfileSchema` (`type`, `defaultModules: ModuleId[]`, `structure` terms/semesters/trimesters/rolling,
  `gradingScheme` id, `terminologyPack` = type)
- `calendar.ts` — `AcademicCalendarSchema` (`tenantId`, `institutionId`, `academicYear` label, `startsOn`, `endsOn`,
  `periods[]` {id, kind, name, startsOn, endsOn}, `holidays[]` {date, name}, `displayCalendar`); refines: every range
  ends ≥ starts, periods inside the year and not overlapping, holidays inside the year
Modify:
- `frontend/packages/contracts/package.json` (`zod` 4.6.5 exact; drop `--passWithNoTests`), `src/index.ts` (exports)
- `docs/CONTRACTS.md` (one row per contract; endpoint column "Stage 1 build step")
