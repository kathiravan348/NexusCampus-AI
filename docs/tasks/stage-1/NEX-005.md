## Build
1. Port `lib/cn.ts` and the 11 NOVA components plus a matching `Textarea` (same tokens/states as `Input`, default `rows={3}`). No domain words, no API calls, no hex literals, no font names. Keep files ≤ 300 lines.
2. **Tokens:** map NOVA tokens to Nexus Style (`action`/`on-action` → `brand-primary`/`on-brand`; `profit*` → `success*`; `loss*` → `danger*`). Use `*-text` tokens (`text-danger-text`, `text-success-text`, `text-warning-text`, `text-info-text`, `text-brand-primary-text`) for text (≥ 4.5:1), never bare icon/border tokens. `Badge` tones: `neutral | brand | info | success | warning | danger`. Focus ring: `focus-visible:ring-2 focus-visible:ring-brand-primary focus-visible:ring-offset-2 focus-visible:ring-offset-bg-ground`.
3. **RTL & a11y:** logical CSS only (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`, `text-start`, `text-end` — zero `ml-`/`mr-`/`pl-`/`pr-`/`left-`/`right-`/`text-left`/`text-right`). Rename `Field` `labelPosition` to `"top" | "end"`. Mirror `Switch` thumb in RTL (`ltr:data-[state=checked]:translate-x-5 rtl:data-[state=checked]:-translate-x-5`). Respect `prefers-reduced-motion` on `Skeleton` and `Button` spinner (`motion-reduce:animate-none`). All form fields forward refs, auto-generate `id` via `useId()`, and wire `aria-invalid` + `aria-describedby`.
4. **Tests & stories:** every component has a Vitest render/interaction/a11y test and a Storybook story (default, disabled, error/loading, variants/sizes). Stories use `useText()` from `@nexus/i18n` for visible UI text so `en-XA` and `ar` (RTL) work everywhere; components stay decoupled from `@nexus/i18n` (receive text via props).
