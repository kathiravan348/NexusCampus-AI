# NEX-003 — i18n engine: messages, layered overrides, formatters, RTL

**Status:** planned · **Owner:** — · **Branch:** task/NEX-003 · **Depends on:** NEX-001
**Requirements:** C-2, G-1, G-2, D8, D9

## Goal
`@nexus/i18n` gives every screen translated, institution-overridable texts and locale-correct formatting, with a
pseudo-locale and RTL support, so no component ever needs a string literal.

## Read first
- `AGENTS.md` §6–7, `docs/ARCHITECTURE.md` §4

## Files
Create (in `frontend/packages/i18n/`):
- `messages/en.json` (source: `{ key: { message, description } }`; start with `common.*` keys: save, cancel, edit,
  delete, search, loading, empty, error, retry, offline, syncPending, back, next, close)
- `messages/ar.json` (same keys, Arabic), `terminology/{ey,k12,he,voc,tp,sk,onl}.json` (overrides for `term.learner`,
  `term.learners`, `term.teacher`, `term.class`, `term.guardian`; e.g. EY learner = "Child", HE = "Student", SK = "Learner")
- `src/resolve.ts` — `resolveMessages({ locale, typePack?, group?, institution?, campus? })`: merge order campus →
  institution → group → terminology pack → locale → `en`; reports missing keys via callback, never returns a raw key
- `src/pseudo.ts` — `en-XA` pseudo-locale (accented, ~40 % longer, wrapped in `⟦ ⟧`)
- `src/direction.ts` — `getDirection(locale)` (`rtl` for ar, he, fa, ur); `applyDirection` sets `<html dir lang>`
- `src/format.ts` — `formatDate`, `formatDateTime` (UTC in, tenant time zone out), `formatNumber`,
  `formatMoney(minor, currency, locale)` (ISO 4217 minor units), `formatPhone` (E.164 display) — all via `Intl`
- `src/I18nProvider.tsx` (wraps `react-intl` `IntlProvider` with resolved messages + direction), `src/useText.ts`
  (`t(key, values)` typed against `en.json` keys)
- `src/keys.test.ts` (every key in `en` exists in `ar` and has a description), and a test per file above
Modify:
- `frontend/packages/i18n/package.json` (add `react-intl`, `date-fns`, `date-fns-tz`, exact versions), `src/index.ts`
- `docs/DECISIONS.md` Requests (new dependency `react-intl`)

## Build
1. ICU MessageFormat only (plurals, select). Keys follow `<area>.<screen>.<element>`.
2. `formatMoney(125000, "INR", "en-IN")` → `₹1,250.00`; `(125000, "USD", "en-US")` → `$1,250.00`;
   `(1250, "JPY", "ja-JP")` → `￥1,250` (currency minor-unit digits from `Intl`).
3. Typed keys: `useText` rejects unknown keys at compile time.
