# NEX-024 — Notifications engine (M07, core): templates per locale, channels, preferences, quiet hours, delivery log

**Status:** planned · **Owner:** — · **Branch:** task/NEX-024 · **Depends on:** NEX-012
**Requirements:** M07 (L1), G-1, G-7, C-3, D8, D30, DM-7

## Goal
An admin edits notification templates per event, channel and locale (ICU-validated, with a preview using sample
values), enables/disables them, and reads the delivery log; every user sets their own channel preferences and quiet
hours. Channels without a configured provider show as unavailable, never broken.

## Build
1. Channel availability comes from a `channels` field the mock adds to `GET /notification-preferences` response —
   define its response schema in `modules/m07.ts` (prototype-only, not a contract) and note it in the handoff.
2. Preview renders the ICU body with `react-intl` in the template's locale (Apex `ar` RTL).
3. Tests: invalid ICU blocks save; new `ar` version appears; delivery filters work; preference change offline queues
   one outbox write; unavailable channel switch disabled.
