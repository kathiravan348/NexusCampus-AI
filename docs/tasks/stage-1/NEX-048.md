**Status:** planned · **Owner:** — · **Branch:** task/NEX-048 · **Depends on:** NEX-047

## Goal
All M02 endpoints except SSO/SCIM work for real: people (with minor masking), users, invite (creates the Keycloak user
in the tenant's organization), suspend/reactivate, custom roles, role assignments, session list and revoke.

## Build
1. Minors' contact fields masked unless the caller holds `m02.person.readRestricted` (same as the mock).
2. "You cannot remove your own last admin role" and self-suspend rules match the mock (409 `conflict`).
3. Invite is idempotent per email; duplicate → `409 conflict`; audit every write.
4. Revoking a session deletes it server-side; the next request with that cookie → 401.
