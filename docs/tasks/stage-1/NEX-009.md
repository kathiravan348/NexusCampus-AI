- `studio.ts` — `SettingScopeSchema` `{ kind: platform|group|institution|campus, targetId }` (`targetId` null iff
  `platform`); `HexColorSchema` (`#RRGGBB`); `ColorTokenNameSchema` (kebab-case `/^[a-z][a-z0-9-]*$/`);
  `ThemeSchema` (`id`, `tenantId`, `scope`, `light`/`dark` record token→hex, `fonts` `{ sans, mono }` nullable ids,
  `radius` record `radius-*`→`/^\d+(\.\d+)?px$/`, `density` `compact|comfortable|spacious` nullable, `assets`

  `updatedBy`, `updatedAt`); `FontSchema` (`id`, `family`, `source` library|upload, `roles` non-empty `sans|mono`,

  `TextOverrideSchema` (`id`, `tenantId`, `scope`, `locale`, `key` dotted message key, `message` non-empty, `version`,
  `updatedBy`, `updatedAt`); `TextOverrideRevisionSchema` (`overrideId`, `version`, `message` nullable = deleted,
  `changedBy`, `changedAt`); `TerminologyPackSchema` (`type` InstitutionType, `locale`, `entries` record key→message)

  `learnerLimit` nullable int); `EntitlementSchema` (`tenantId`, `moduleId`, `enabled`, `source` plan|addon|trial|core,
  `expiresAt` nullable); `UsageMeterSchema` (`tenantId`, `metric` learners|staff|storage_bytes|ai_credits|sms|email,
  `used` int ≥ 0, `limit` nullable int ≥ 0, `periodStart`, `periodEnd` > start)
- `compliance.ts` — `AuditEventSchema` (`id`, `tenantId`, `occurredAt`, `actorKind` user|system|provider_grant,
  `actorId` nullable, `grantId` nullable — required iff `provider_grant`, `action` (`<module>.<entity>.<action>`),

  never values), `prevHash` nullable + `hash` 64 hex); `ConsentSchema` (`id`, `tenantId`, `personId`, `purpose`

  `DataSubjectRequestSchema` (`id`, `tenantId`, `personId`, `kind` access|correct|delete|export, `status`

  nullable); `CompliancePackSchema` (`code` gdpr|uk_gdpr|ferpa|coppa|dpdp|lgpd|popia|pdpa|eu_ai_act, `region`,
