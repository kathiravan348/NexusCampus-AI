## Goal
`@nexus/offline` provides the L1–L3 client-side building blocks: an encrypted per-user Dexie store, an idempotent
priority-ordered outbox with conflict handling, a reactive `useSyncStatus` React hook, safe sign-out / remote-revoke
wipes, and a shared-device idle-lock controller — all unit-tested with zero PII in plaintext IndexedDB columns.

## Build
1. **Encryption & isolation (`crypto.ts`, `db.ts`, `cache.ts`):** per-`(tenantId, userId)` scope key (`${tenantId}:${userId}`). Generate non-extractable `AES-GCM` `CryptoKey` stored in IndexedDB `keys` so encrypted data survives restarts (O-3). Encrypt all cache values, outbox payloads, and `serverSnapshot`s with fresh 96-bit IVs; keep only operational metadata (`id`, `idempotencyKey`, `moduleId`, `operation`, `mergeRule`, `priority`, `priorityRank`, `status`, `attempts`, `createdAt`, `updatedAt`, `deviceId`, `syncedAt`) unencrypted for indexing — never PII. Prove User A cannot read User B's or another tenant's rows.
2. **Outbox (`outbox.ts`):** `enqueueWrite` stamps client `id`, `idempotencyKey` (deduplicates repeated keys per scope), `deviceId`, UTC `createdAt`, `mergeRule` (`lww-audited | append-only | manual-review-only`), and `priority` (`critical | high | normal | low`). `flushOutbox(db, scope, transport)` replays `pending` writes ordered by priority then `createdAt` (O-4) with single in-flight guard: `ok` removes + updates `lastSyncedAt`; `conflict` marks `conflict` + encrypts optional `serverSnapshot`; `retryable` increments `attempts` + keeps `pending`; `fatal` marks `failed`. `resolveConflict` supports `keep-server`, `retry-local`, or `{ kind: "replace", payload }`.
3. **Wipe & idle lock (`wipe.ts`):** `signOutWipe` **refuses** (`{ wiped: false, reason: "unsynced_writes", pendingCount, conflictCount }`) if any `pending`/`syncing`/`conflict` writes exist (O-2/O-3); otherwise deletes the scope's key, cache, outbox, and `lastSyncedAt`. `remoteRevokeWipe` wipes immediately and returns `{ wiped: true, lostWrites }` (metadata only, zero PII) for M10. `createIdleLock({ timeoutMs, onLock })` locks/unlocks without deleting IndexedDB data.
4. **Hook (`useSyncStatus.ts`):** listens to `online`/`offline` and `subscribeOutbox`; exposes `state` (`offline` > `conflict` > `syncing` > `error` > `pending` > `synced`), `online`, `pendingCount`, `conflictCount`, `failedCount`, `lastSyncedAt`. All files ≤ 300 lines; strict TS, no `any`.

## Acceptance checks
- [ ] Encrypted payload round-trips across a fresh DB handle (simulated restart); raw IndexedDB rows contain no plaintext payload; cross-user/cross-tenant isolation holds.
- [ ] Outbox deduplicates `idempotencyKey`, replays `critical`/`high` before `normal`/`low`, handles `ok`/`conflict`/`retryable`/`fatal` and `resolveConflict`.
- [ ] `signOutWipe` blocks when unsynced/conflict writes exist and succeeds once empty; `remoteRevokeWipe` wipes immediately and reports lost-write metadata with zero PII.
- [ ] `useSyncStatus` reacts to online/offline events, enqueue, conflict, and flush; `pnpm review:check` passes.
- [ ] Definition of done in `AGENTS.md` §9 (`STRUCTURE.md` updated; `Guides: none`).
