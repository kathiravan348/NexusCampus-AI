# NEX-045 — Identity: Keycloak in Compose, OIDC sign-in, server sessions, `/me`

**Status:** planned · **Owner:** — · **Branch:** task/NEX-045 · **Depends on:** NEX-044
**Requirements:** M02, ARCHITECTURE §8, D25, D44

## Goal
A user signs in through Keycloak (authorization code + PKCE); the backend creates a `Session`, sets an HttpOnly
secure cookie, resolves the tenant from the session (never from a header) and serves `GET /api/v1/me`.

- `docs/guides/API.md` (M02 `/me` row)

## Build
1. Cookie `HttpOnly; Secure; SameSite=Lax; Path=/`; CSRF double-submit token on unsafe methods.
2. The Keycloak organization maps to `tenant_id`; a Keycloak user without a NexusCampus `User` row gets 403.
3. `/me` returns `{ user, person, roleProfiles, assignments: [], permissions: [] }` (NEX-046 fills the last two).
4. Every sign-in and sign-out writes an audit event (NEX-044).

## Acceptance checks
- [ ] Login → callback → cookie → `/me` 200; logout revokes the session (then 401).
- [ ] Tampered or expired session → 401; a fake tenant header is ignored (test).
- [ ] Definition of done in `AGENTS.md` §9; `docker compose down` when done.
