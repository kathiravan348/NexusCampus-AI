# NEX-013 — Institution setup (M01): type profile, hierarchy, region, locale, time zone, currency, calendar

**Status:** planned · **Owner:** — · **Branch:** task/NEX-013 · **Depends on:** NEX-012
**Requirements:** M01 (L0), E-6, G-1–G-3, G-5, D2, D9, D27, D36

## Goal
An admin can view and edit the institution: type profile, group → institution → campus tree (add/edit campus), region
(read-only after creation), locale settings, time zone, currency and academic calendar (periods, holidays, display
calendar) — validated by the contracts, saved to the mock API, with a live preview of formats.

## Build
1. Forms use React Hook Form + `zodResolver` with the contract schema (D36); server `details` map to field errors.
2. Region shows as read-only with a note (data residency, G-5). Changing time zone shows the preview immediately.
3. Teacher persona: no menu item; by URL → `Forbidden` (from the shell). Riverside admin sees both campuses.
4. Tests: renders each tab for K12 and HE; invalid overlapping period shows a field error; saving a campus updates the
   tree; `error` scenario shows `EmptyState` error with retry; offline shows the L0 notice and disables save.
