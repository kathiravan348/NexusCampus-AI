# NEX-035 — NexusCampus logo assets (D40)

**Status:** planned · **Owner:** — · **Branch:** task/NEX-035 · **Depends on:** NEX-034
**Requirements:** C-1, D7, D39, D40

## Goal
The Owner's NexusCampus logo (shield "N" in the Campus Prism blue → sky → teal gradient) is in the repo as
web-ready files: a transparent mark, light and dark lockups, favicons and PWA icons. The campus app shows the favicon,
and `brand.config.ts` names every logo path.

## Read first
- `AGENTS.md` §6, `docs/DECISIONS.md` (D39, D40), `brand.config.ts`, `frontend/apps/campus/index.html`

## Files
Create (`frontend/apps/campus/public/brand/`), converted from the Owner's artwork with the AI watermark cropped out:
- `nexuscampus-mark.png` (1024², transparent; white gaps are see-through)
- `nexuscampus-lockup-horizontal.png` (1600 w, transparent, for light backgrounds)
- `nexuscampus-lockup-stacked.png` (1200 w, transparent, for light backgrounds)
- `nexuscampus-lockup-horizontal-dark.png` (1600 w, opaque dark background, for dark backgrounds)
- `favicon.ico` (48), `favicon-16.png`, `favicon-32.png` (transparent)
- `apple-touch-icon.png` (180, white), `icon-192.png`, `icon-512.png` (white), `icon-maskable-512.png` (white,
  mark inside the 80% safe zone)
Modify:
- `brand.config.ts` — add `logo` with the public paths above (`mark`, `lockupHorizontal`, `lockupStacked`,
  `lockupHorizontalDark`, `favicon`, `favicon16`, `favicon32`, `appleTouchIcon`, `icon192`, `icon512`, `iconMaskable512`)
- `frontend/apps/campus/index.html` — `<link rel="icon">` (ico + 16/32 PNG) and `<link rel="apple-touch-icon">`
- `docs/STRUCTURE.md` — `public/brand/` line

## Build
1. Add the files above; no other image formats, no originals with the watermark.
2. Add `logo` to `brand.config.ts`; link the favicons in `index.html` (paths start with `/brand/`).
