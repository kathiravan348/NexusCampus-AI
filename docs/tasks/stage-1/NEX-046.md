# NEX-046 — RBAC and entitlement guard: permission catalogue, roles, scoped assignments, module switch

**Status:** planned · **Owner:** — · **Branch:** task/NEX-046 · **Depends on:** NEX-045
**Requirements:** M02, M05 (switch), ARCHITECTURE §6 (Entitlements), D25 (temporal scoping), V-1

## Goal
Every endpoint declares a permission and a module; a request passes only if the module is switched on for the tenant
and the user holds the permission in a matching scope at the current date. `/me` returns real assignments and
permissions.
