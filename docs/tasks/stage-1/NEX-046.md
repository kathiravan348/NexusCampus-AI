**Status:** done · **Owner:** Claude · **Branch:** task/NEX-046 · **Depends on:** NEX-045

## Goal
Every endpoint declares a permission and a module; a request passes only if the module is switched on for the tenant
and the user holds the permission in a matching scope at the current date. `/me` returns real assignments and
permissions.
