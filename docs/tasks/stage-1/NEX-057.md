# NEX-057 — Sync API (M10): outbox replay with idempotency, devices, conflicts, remote wipe

**Status:** planned · **Owner:** — · **Branch:** task/NEX-057 · **Depends on:** NEX-046
**Requirements:** M10, O-2, O-3, ARCHITECTURE §5 (merge rules as in `@nexus/offline`)

## Goal
Devices register, replay their outbox writes idempotently, get conflicts per the module's merge rule, and can be
revoked (wipe on next contact, lost writes reported). The M10 screens' endpoints work for real.

## Build
1. Conflicts store no payload (privacy) — only `summaryKey`, ids and the merge rule (as the contract).
2. Revoke: device status `revoke_pending` → on next heartbeat the server answers `wipe`, marks `revoked`, counts lost
   writes; audit both steps.
3. Revoking your own current device needs the same double confirmation flag as the screen.

## Acceptance checks
- [ ] Same write replayed 3 times → applied once, same response each time.
- [ ] Revoked device gets `wipe` and then 401.
- [ ] Definition of done in `AGENTS.md` §9.
