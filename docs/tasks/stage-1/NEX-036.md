# NEX-036 — NexusCampus logo in the app header and sign-in page

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-036 · **Depends on:** NEX-035
**Requirements:** C-1, D7, D40

## Goal
The NexusCampus mark shows in the signed-in app header (before the institution name) and on the sign-in page (with
the platform name above the title), in light and dark, LTR and RTL, from 360px up.

- `frontend/apps/campus/src/app/{Shell.tsx,ShellHeader.tsx}`, `frontend/apps/campus/src/pages/SignIn.tsx` (+ tests)

## Build
1. `PlatformMark({ size: "sm" | "md", decorative?: boolean })`: `<img src={brand.logo.mark}>`, `sm` = `h-7 w-7`,
   `md` = `h-10 w-10`, `object-contain shrink-0`; `alt={brand.name}` unless `decorative` (then `alt=""`); hides
   itself on load error (same pattern as `ShellBrand`). No hex, no hardcoded text (the alt is the platform name).
2. `Shell.tsx`: header `title` becomes the mark (`sm`) + the institution name in a truncating span.
3. `SignIn.tsx`: above the `h1`, a row with the mark (`md`, decorative) and `brand.name` as `text-section-title
   font-semibold`. Not the lockup images: their tagline is baked-in English and the dark one has its own background
   (NEX-037).
