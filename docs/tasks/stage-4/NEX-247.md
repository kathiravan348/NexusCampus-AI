## Build
1. `QuestionBankSchema` `{ id, tenantId, institutionId (null = group), code, name, subjectIds (≤ 20),
   editorStaffProfileIds (1–20), createdAt, updatedAt }` (id lists unique everywhere in this task).
2. `QuestionKindSchema` `single_choice | multiple_choice | true_false | short_text | numeric | essay | order`;
   `QuestionOptionSchema` `{ id (`^[A-Za-z0-9_-]{1,32}$`), text (1–2000), correct }`. `QuestionItemSchema` `{ id,
   tenantId, bankId, kind, stem (1–10000), language (Locale), options (unique ids; 2–10 for choice and order kinds,
   exactly 2 for true_false, empty otherwise), acceptedAnswers (1–20 of 1–200 chars iff short_text, else empty),
   numericAnswer (`{ value, tolerance ≥ 0 }` iff numeric), maxPoints (0.5–100 in 0.5 steps), difficulty (easy |
   medium | hard, nullable), outcomeIds (unique, ≤ 20), qtiIdentifier (≤ 200, nullable), explanation (≤ 5000,
   nullable), source (manual | ai_generated), status (draft | in_review | approved | retired), version (int ≥ 1),
   createdByProfileId, createdAt, updatedAt }`. Correct flags: exactly one for single_choice and true_false, at least
   one for multiple_choice, none for `order` (the options' order is the answer; delivery shuffles).
3. `TestSectionSchema` `{ id, title, itemIds (≤ 200), pool (`{ bankIds (1–10), outcomeIds (≤ 20), itemCount (1–100) }`,
   nullable) }` — exactly one of non-empty `itemIds` or `pool`.
4. `OnlineTestSchema` `{ id, tenantId, courseSpaceId (nullable), assessmentId (M20 link, nullable), title, mode
   (practice | graded | adaptive), sections (1–20, unique ids), timeLimitMinutes (1–600, nullable), opensAt, closesAt
   (> opensAt), attemptsAllowed (1–10; null = unlimited, practice only), shuffleOptions, showResults (immediately |
   after_close | manual), passMarkBps (1–10000, nullable), proctored (only graded or adaptive), status (draft |
   scheduled | open | closed | archived), createdAt, updatedAt }`; `adaptive` tests draw only from pools.
5. `TestAttemptSchema` `{ id, tenantId, testId, learnerId, attemptNumber (≥ 1), status (in_progress | submitted |
   auto_submitted | marked | released), startedAt, submittedAt (set iff not in_progress, ≥ startedAt), scorePoints
   (nullable, ≤ maxPoints), maxPoints (> 0), clientId (UUID), deviceId (nullable) }`; score set when marked / released.
6. `TestResponseSchema` `{ id, tenantId, attemptId, itemId, selectedOptionIds (≤ 10), textAnswer (≤ 20000, nullable;
   personal data), numericAnswer, autoScore, manualScore (nullable; scores ≥ 0 in 0.5 steps), markedByStaffProfileId (iff manualScore), flagged, answeredAt }`.
7. `ItemStatisticSchema` `{ tenantId, itemId, testId (null = all), responses, facilityBps (0–10000), discrimination
   (−1…1, nullable), optionCounts (option id → int ≥ 0), computedAt }`. 8. `updatedAt >= createdAt`; doc comment lists
   server checks (only `approved` items in tests, `ai_generated` approved by a person, scores ≤ points, attempts ≤ allowed).
