# NEX-214 — Contracts (M35): mastery, learning paths, tutor settings, tutor sessions and messages

## Goal
`@nexus/contracts` defines mastery per outcome, learning paths, and a guard-railed AI tutor per course space — always
labelled AI, citing sources, and for minors only with a guardian's `ai_features` consent.

## Build
1. `MasteryLevelSchema` `not_started | emerging | developing | secure | mastered`; `MasteryRecordSchema` `{ tenantId,
   learnerId, outcomeId, level, scoreBps (0–10000), evidenceCount (int ≥ 0), lastEvidenceAt (nullable), updatedAt }`;
   `not_started` iff `evidenceCount` is 0 (then `scoreBps` 0 and no `lastEvidenceAt`).
2. `LearningPathStepSchema` `{ id, order (≥ 1), kind (content | test | practice | assignment | live_session), refId,
   outcomeId (nullable), status (locked | available | done | skipped), reason (1–300; why it is suggested, A-5) }`;
   `LearningPathSchema` `{ id, tenantId, learnerId, courseSpaceId, source (teacher | adaptive), assignedByStaffProfileId
   (set iff teacher), status (active | paused | completed), steps (1–100, unique ids and orders), createdAt, updatedAt }`.
3. `TutorModeSchema` `hints_only | explain | socratic`; `TutorAudienceSchema` `children | teens | adults` (sets the
   guard-rail profile); `TutorSettingsSchema` `{ tenantId, courseSpaceId, enabled, mode, audience, sourceContentIds
   (unique, ≤ 200; the tutor answers only from these and the space's outcomes), dailyMessageLimit (1–200),
   transcriptsVisibleToStaff (shown to learners before they start), updatedByStaffProfileId, updatedAt }`.
4. `TutorSessionSchema` `{ id, tenantId, learnerId, courseSpaceId, learnerIsMinor, consentId (Consent with purpose
   `ai_features`; required when `learnerIsMinor`), status (open | closed), startedAt, endedAt (set iff closed, ≥
   startedAt), messageCount (int ≥ 0), flaggedForReview }`.
5. `TutorSafetyCategorySchema` `self_harm | violence | sexual | personal_data | off_topic | academic_integrity`;
   `TutorMessageSchema` discriminated on `role`: `learner { id, tenantId, sessionId, role, text (1–4000; personal data),
   createdAt }` and `tutor { id, tenantId, sessionId, role, text (1–8000), aiGenerated: literal true, sources
   (AssistSource ≤ 10), locale, blocked, safetyCategory (set iff blocked), feedback (helpful | not_helpful, nullable),
   createdAt }`; a tutor answer that is not blocked cites at least one source.
6. Doc comment: server checks (consent is granted, current and given by a guardian of the learner; tutor off when the
   tenant AI switch or the space's tutor is off; health / safeguarding records never reach the tutor, A-3; daily limit;
   `refId` matches the step kind; a blocked answer shows a safe message and flags the session). Strict objects, named
   exports, `XSchema` + `type X`, ≤ 300 lines, no workspace imports.
