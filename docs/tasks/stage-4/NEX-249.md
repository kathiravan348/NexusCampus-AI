# NEX-249 — Contracts (M36): live sessions, joins, recordings, AI summaries and chapters

**Status:** ready-for-review · **Owner:** Claude · **Branch:** task/NEX-249 · **Depends on:** NEX-211
**Requirements:** M36, A-5, G-6, V-7, D19–D20, D87 (rules 1, 2, 4; split from NEX-215)

## Goal
`@nexus/contracts` defines provider-neutral live classes (Zoom, Meet, Teams, BigBlueButton or the demo provider):
scheduled sessions, joins that can suggest attendance, recordings with a retention date and AI summaries a teacher
publishes — with no join link, meeting password or provider secret in any contract.

## Build
1. `LiveSessionStatusSchema` `scheduled | live | ended | cancelled`; `LiveSessionSchema` `{ id, tenantId,
   courseSpaceId (nullable), timetableSlotId (nullable), title (1–200), provider (`^[a-z][a-z0-9_-]{1,31}$`, a settings
   key), externalMeetingId (≤ 200, nullable), scheduledStart, scheduledEnd (> start), hostStaffProfileIds (unique,
   1–10), status, actualStart (set iff live | ended), actualEnd (set iff ended, ≥ actualStart), recordingEnabled,
   attendanceFromJoins, createdAt, updatedAt }`. Joining goes through a later endpoint that returns a short-lived link.
2. `LiveJoinSchema` `{ id, tenantId, sessionId, profileId, role (host | participant), joinedAt, leftAt (nullable, ≥
   joinedAt), durationSeconds (int ≥ 0) }` — personal data; minutes only *suggest* M17 marks, a teacher submits the roll.
3. `LiveRecordingStatusSchema` `processing | ready | failed | deleted`; `LiveRecordingSchema` `{ id, tenantId,
   sessionId, status, durationSeconds (int ≥ 0, nullable until ready), sizeBytes (nullable until ready), deleteOn
   (IsoDate), visibleToLearners, noticeShownToParticipants: literal true, createdAt }` — metadata only, no key or URL.
4. `LiveChapterSchema` `{ title (1–200), startSeconds (int ≥ 0) }`; `LiveSummarySchema` `{ id, tenantId, sessionId,
   recordingId, aiGenerated: literal true, tier (CapabilityTier), language (Locale), summary (1–5000), chapters (≤ 50,
   strictly ascending `startSeconds`), status (draft | published), publishedByStaffProfileId + publishedAt (set iff
   published), createdAt }` — learners see a summary only after a teacher publishes it (A-4 style check, A-5).
5. Doc comment: server checks (provider configured for the tenant else the feature is hidden, D19–D20; provider keys and
   meeting secrets live in settings / OpenBao only; recordings deleted on `deleteOn`; learners whose guardians opted out
   of media (M91) are not recorded on camera; transcripts and summaries need the tenant AI switch; joins of other
   tenants are rejected).
6. `updatedAt >= createdAt`. Strict objects, `XSchema` + `type X`, named exports, ≤ 300 lines, no workspace imports.
