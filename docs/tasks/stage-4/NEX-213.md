## Build
1. `SubmissionKindSchema` `text | file | audio | photo | link`; `SubmissionFileSchema` `{ fileName (plain file name,
   as `LearnerDocumentSchema`), contentType (1–100), sizeBytes (1–100 000 000) }` — metadata only, no URL or key.
2. `AssignmentSchema` `{ id, tenantId, courseSpaceId, title (1–200), instructions (≤ 10000), outcomeIds (unique, ≤ 20),
   assessmentId (M20 gradebook link, nullable), rubricId (nullable), maxMarks (1–1000 in 0.5 steps, nullable =
   feedback only), submissionKinds (unique, 1–5), openAt, dueAt (> openAt), lateUntil (nullable, ≥ dueAt), groupWork,
   peerReview (`{ reviewsPerSubmission (1–5), anonymous, dueAt }`, nullable, its `dueAt` > assignment `dueAt`),
   originalityCheck, status (draft | published | closed | archived), createdByStaffProfileId, createdAt, updatedAt }`.
3. `SubmissionStatusSchema` `draft | submitted | late | returned | resubmission_requested`; `AssignmentSubmissionSchema`
   `{ id, tenantId, assignmentId, learnerId, groupLearnerIds (unique, ≤ 10, not containing `learnerId`), attempt (int
   ≥ 1), status, text (≤ 20000, nullable; personal data), files (≤ 10), linkUrl (https, nullable), submittedAt (set iff
   not draft), clientId (UUID; offline outbox id), deviceId (nullable), createdAt, updatedAt }`; a non-draft submission
   has at least one of text, files, link.
4. `SubmissionFeedbackSchema` `{ id, tenantId, submissionId, marks (≥ 0, 0.5 steps, nullable), rubricScores (record of
   rubric code → int 0–10, nullable), comment (≤ 5000, nullable; personal data), markedByStaffProfileId, markedAt,
   releasedAt (nullable, ≥ markedAt) }` — always a person's marking.
5. `AiSuggestionDecisionSchema` `pending | accepted | edited | rejected`; `AiMarkingSuggestionSchema` `{ id, tenantId,
   submissionId, suggestedMarks (nullable), suggestedRubricScores (nullable), reasons (1–10 strings, each 1–500),
   createdAt, decision, decidedByStaffProfileId + decidedAt (set iff not pending, decidedAt ≥ createdAt) }` (A-4, A-5).
6. `PeerReviewSchema` `{ id, tenantId, assignmentId, submissionId, reviewerLearnerId, anonymous, status (assigned |
   submitted), rubricScores (nullable), comment (≤ 2000, nullable), submittedAt (set iff submitted) }`.
7. `OriginalityStatusSchema` `pending | ready | failed | not_configured`; `OriginalitySignalSchema` `{ id, tenantId,
   submissionId, provider (`^[a-z][a-z0-9_-]{1,31}$`), status, similarityBps (0–10000, set iff ready), externalId
   (≤ 200, nullable), checkedAt (set iff ready | failed) }` — a signal for a person, never a verdict (doc comment).
8. `updatedAt >= createdAt`. Doc comment: server checks (reviewer is not the author or a group member, rubric codes
   match the rubric, marks ≤ `maxMarks`, kinds allowed by the assignment, gradebook marks move only when a person
   releases feedback). Strict objects, `XSchema` + `type X`, named exports, ≤ 300 lines, no workspace imports.
