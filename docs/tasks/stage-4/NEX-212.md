## Build
1. `ContentAssetKindSchema` `image | video | audio | document | package | captions`; `ContentAssetSchema` `{ id,
   tenantId, kind, fileName (plain file name, same rule as `LearnerDocumentSchema`), contentType (1–100), sizeBytes
   (1–2 000 000 000), sha256 (64 lowercase hex), createdAt }`; no storage keys or URLs (signed endpoint at build).
2. `ContentBlockSchema` discriminated on `type`: `text { markdown (1–20000) }`, `image { assetId, altText (trimmed
   1–500) }`, `video { assetId, captionAssetIds (unique, ≤ 10) }`, `question { questionId }`, `embed { url (https) }`.
3. `AccessibilityIssueSchema` `{ code (missing_alt_text | missing_captions | low_contrast | heading_order |
   missing_transcript), blockIndex (int ≥ 0, nullable), severity (error | warning) }`; `AccessibilityCheckSchema`
   `{ checkedAt, issues (≤ 200) }`.
4. `ContentKindSchema` `lesson | video | audio | document | scorm12 | scorm2004 | xapi | cmi5`;
   `ContentStatusSchema` `draft | in_review | published | archived`; `ContentPackageSchema` `{ assetId, launchPath
   (relative path ≤ 500: no leading `/`, no `..` segment, no scheme, no backslash), manifestIdentifier (1–200) }`.
5. `ContentItemSchema` `{ id, tenantId, institutionId, kind, title (1–200), language (Locale), outcomeIds (unique,
   ≤ 20), status, version (int ≥ 1), blocks (1–200, set iff lesson), assetId (set iff video | audio | document),
   package (set iff scorm12 | scorm2004 | xapi | cmi5), durationSeconds (int ≥ 0, nullable), aiAssisted,
   accessibility (nullable), createdByProfileId, createdAt, updatedAt }`. Refines: `published` needs an accessibility
   check with no `error` issue; `updatedAt >= createdAt`.
6. `ContentAttemptStatusSchema` `incomplete | completed | passed | failed`; `ContentAttemptSchema` `{ id, tenantId,
   contentItemId, learnerId, registration (UUID), status, scoreBps (0–10000, nullable), timeSpentSeconds (int ≥ 0),
   startedAt, finishedAt (set iff not incomplete, ≥ startedAt) }`; raw xAPI statements stay server-side.
7. Doc comment: server checks (assets belong to the tenant and match the block / item kind, a package's manifest is
   parsed on upload, `aiAssisted` content is published only by a person). Strict objects, `XSchema` + `type X`, named
   exports, ≤ 300 lines, no workspace imports.
