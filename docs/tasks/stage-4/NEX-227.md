# NEX-227 — M30 LMS classrooms & courses screens (read + discussion replies)

**Status:** planned · **Owner:** — · **Branch:** task/NEX-227 · **Depends on:** NEX-222, NEX-226, NEX-261 (same i18n files)

## Goal
In demo mode the campus app has a "Courses" screen: the viewer's course spaces, each with its modules, items, progress
and discussions, and viewers who can see a space post discussion replies through the outbox.

## Build
1. `modules.ts`: `M30`, path `teaching/courses`, icon `LibraryBig` (lucide), permission `m30.course.read`, `L2`, keys
   `m30.nav.title` / `m30.nav.summary`, lazy `../modules/m30/CoursesPage`.
2. `CoursesPage`: heading, intro, `LastSynced`; course spaces from `useCourseSpaces()` as cards (title, kind, status
   chip as text + icon); selecting one shows `CourseSpaceView` (back link; stacked at 360 px).
3. `CourseSpaceView`: `Tabs` "Outline" / "Discussions". `CourseOutline`: modules in order with their items (kind icon +
   text, completion rule, a done mark from `useCourseProgress()`); prerequisites shown as text; a learner sees their own
   progress meter (`percentBps` / 100, one decimal); staff see a per-learner count only, no learner list here.
4. `DiscussionsTab`: threads (pinned first, locked shown as text + icon); a thread's posts as a reply tree
   (`parentPostId`); hidden posts appear only for moderators, marked "Hidden". `ReplyForm` (react-hook-form + zod on
   `DiscussionPostInputSchema`) under the thread and under a post; not shown on a locked thread.
5. Contract: `DiscussionPostInputSchema` = strict `{ parentPostId: Id | null, body }` (same body rule as the post);
   tests for valid, empty and too-long bodies.
6. Write: `POST /threads/:id/posts` (`m30.course.read` and access to the thread's space via `courseAccess`, else 404 as
   the reads) → 201 with `authorProfileId` = the caller's role profile in the tenant, `hidden: false`; locked thread →
   409 `conflict`; `parentPostId` must be a post of the same thread (else 400 `invalid_request`); bumps `postCount` and
   `lastPostAt`; errors carry no post text. Hook `useCreateDiscussionPost()` via `useOutboxMutation` (`moduleId: "M30"`,
   `append-only`, idempotency headers), invalidating the thread's posts; offline the form says the reply is queued — L2.
7. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; no personal data in errors or logs.
