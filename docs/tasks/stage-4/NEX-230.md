# NEX-230 — M33 Online tests screens (read): test list, test view, results, item statistics

**Status:** planned · **Owner:** — · **Branch:** task/NEX-230 · **Depends on:** NEX-223, NEX-229 (same i18n files)
**Requirements:** M33, O-1 (L2 read cache), D15, D42, D71, D72, V-7, WCAG 2.2 AA · taking a test: NEX-269

## Goal
Demo campus app "Online tests" screen: tests per course space, a test view (sections, times, rules), the viewer's
own attempts and released scores, and for staff the attempt list and item statistics. Read only — no writes.

## Read first
`AGENTS.md` §7–§9; campus `app/modules.ts`, `modules/{m32,m31}/*` (after NEX-229); services `modules/m33.ts`;
mocks `handlers/m33.ts` (access rules: `testAccess`, `resultsVisible`); `contracts/src/online-tests.ts`.

## Files
Create: `frontend/apps/campus/src/modules/m33/{OnlineTestsPage,OnlineTestView,AttemptList,ItemStatistics}.tsx`
+ a `.test.tsx` for each.
Modify: `frontend/apps/campus/src/app/modules.ts` (one M33 entry); `frontend/packages/i18n/messages/{en,hi,ta}.json`
(`m33.*` keys only) and the generated backend ICU key files; `docs/guides/USER-GUIDE.md` ("Online tests" section).
No mocks, services or contracts changes (all reads exist).

## Build
1. `modules.ts`: `M33`, path `teaching/tests`, icon `FileQuestion` (lucide), permission `m33.test.read`, `L2`,
   keys `m33.nav.title` / `m33.nav.summary`, lazy `../modules/m33/OnlineTestsPage`.
2. `OnlineTestsPage`: heading, intro, `LastSynced`; `useOnlineTests()` list (title, mode as text — Practice / Graded
   / Adaptive, status text + icon, opens / closes times, "Proctored" label); status filter; selecting one shows
   `OnlineTestView` (back link; stacked at 360 px). Empty, loading and error-with-retry states.
3. `OnlineTestView` (`useOnlineTest(id)`): sections in order (title, item count or "N from pool"), time limit or
   "No time limit", attempts allowed or "Unlimited", pass mark as a percentage or none, when results show (text for
   `immediately` / `after_close` / `manual`), "Proctored" note. Below: `AttemptList`; for viewers with
   `m33.test.manage` also `ItemStatistics`. A learner sees "Taking tests comes later" instead of a start button.
4. `AttemptList` (`useTestAttempts(id)`): the handler already limits rows (staff → class, learner / guardian → own
   or linked). Show attempt number, status text + icon, started / submitted times, score as `x / max` only when
   `scorePoints` is not null (signed, 0.01 steps, locale number format), else "Not released". Staff rows show the
   learner's name; never show response text — this screen does not call `useTestResponses`.
5. `ItemStatistics` (`useItemStatistics(id)`): table — item id label, responses, facility as a percentage, discrimination
   (2 decimals or "—"); caption explains facility and discrimination in plain words; 403 → section hidden.
6. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; numbers / dates via the i18n format helpers;
   tests use `await screen.findBy…` after render (runtime gate shows "Loading…" first); no `ar` unless a test adds it
   to `supportedLocales` (pattern `m30/CourseSpaceView.test.tsx:58-68`). Run each m33 test file alone before finishing.
