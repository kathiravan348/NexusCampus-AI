# NEX-218 — Contracts (M40): test series, ranks and percentiles, doubts and answers, weak-topic plans, parent reports

**Status:** planned · **Owner:** — · **Branch:** task/NEX-218 · **Depends on:** NEX-247, NEX-214
**Requirements:** M40, O (L2 doubts), A-3, A-4, A-5, G-6, D87

## Goal
`@nexus/contracts` defines coaching and test prep: mock-test series for batches, per-test ranks and percentiles,
doubts answered by AI (labelled, cited) or staff, AI weak-topic plans a teacher shares, and parent progress reports.

## Read first
- `AGENTS.md` §7–§10; `docs/MODULES.md` (M40); `docs/CONTRACTS.md`; `contracts/src/{common,ai,academics,online-tests}.ts`

## Files
Create `frontend/packages/contracts/src/test-prep{,.test}.ts`; modify its `index.ts` (1 line), `docs/CONTRACTS.md` (1 row).

## Build
1. `TestSeriesSchema` `{ id, tenantId, institutionId, code (AcademicCode), name (1–200), targetExam (1–100), classGroupIds
   (unique, 1–50), testIds (unique, ordered, 1–100; M33 online tests), status (draft | active | completed), createdAt,
   updatedAt }`.
2. `SectionScoreSchema` `{ sectionId, scorePoints (≥ 0, 0.5 steps, ≤ maxPoints), maxPoints (> 0) }`; `TestRankSchema`
   `{ tenantId, seriesId, testId, learnerId, scorePoints, maxPoints, participants (≥ 1), rank (1…participants),
   percentileBps (0–10000), sectionScores (≤ 20, unique section ids), publishedAt }`.
3. `DoubtSchema` `{ id, tenantId, learnerId, courseSpaceId, questionItemId, subjectId (each nullable), text (1–4000;
   personal data), attachmentCount (0–5), status (open | ai_answered | answered | closed), clientId (UUID), deviceId
   (nullable), createdAt }`.
4. `DoubtAnswerSchema` `{ id, tenantId, doubtId, kind (ai | staff), text (1–8000), aiGenerated (true iff ai), tier (set iff
   ai), sources (AssistSource; 1–10 iff ai, empty for staff), answeredByStaffProfileId (set iff staff),
   verifiedByStaffProfileId (nullable; only on AI answers), createdAt }`.
5. `WeakTopicSchema` `{ outcomeId, reason (1–300, A-5), suggestedItemCount (1–50) }`; `WeakTopicPlanSchema` `{ id,
   tenantId, learnerId, seriesId, aiGenerated: literal true, tier, topics (1–10, unique outcomes), status (draft |
   shared), sharedByStaffProfileId + sharedAt (set iff shared), createdAt }` — a teacher shares it, never the AI.
6. `ParentReportSchema` `{ id, tenantId, learnerId, seriesId, periodStart, periodEnd (≥ start), testsTaken (≥ 0),
   averagePercentileBps (0–10000, nullable), attendanceBps (nullable), teacherComment (≤ 2000, nullable), status
   (draft | sent), sentByStaffProfileId + sentAt (set iff sent) }`.
7. Doc comment (G-6, A-3): a learner sees their own rank; leaderboards show names only with the learner's (a minor's
   guardian's) consent, otherwise rank numbers alone; AI doubt answers and plans need the tenant AI switch and a
   guardian's `ai_features` consent for minors, answer only from the batch's content, and are labelled AI.
   `updatedAt >= createdAt`; strict objects, named exports, ≤ 300 lines, no workspace imports.
