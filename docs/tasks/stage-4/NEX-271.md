# NEX-271 — M34 proctoring data: staff flag review and identity decision (contracts, mocks, hooks)

**Status:** planned · **Owner:** — · **Branch:** task/NEX-271 · **Depends on:** NEX-223 · screen: NEX-231
**Requirements:** M34, A-4, A-5, D87, V-1, V-7 · split from NEX-231 (data side, so it can run beside the M32/M33 chain)

## Goal
Staff can decide a proctoring flag (dismiss / uphold with a note) and record a person's identity decision for a
session. A flag still never changes an attempt or score (A-4).

## Build
1. Contracts: `FlagReviewInputSchema` strict `{ review: "dismissed" | "upheld", note: string trim 1–1000 | null }`,
   refine: `upheld` needs a note. `IdentityDecisionInputSchema` strict `{ result: "verified" | "not_verified" }`.
   Tests: `pending` review rejected; upheld without note rejected; extra keys rejected.
2. `PATCH /proctoring-flags/:id/review` (`Idempotency-Key` required, else 400): permission `m34.flag.review` or
   `m34.proctoring.manage`; flag of the viewer's tenant (else 404); the viewer must have an active staff profile
   (else 403). `pending` flag → sets `review`, `reviewNote` = note, `reviewedByStaffProfileId`, `reviewedAt` = now;
   already reviewed → 409 `conflict`, except a replay of the same key returns the stored flag (200). Never touches
   `testAttempts`, `testResponses` or scores. Returns `ProctoringFlag`.
3. `PATCH /proctoring-sessions/:id/identity` (`Idempotency-Key`): permission `m34.proctoring.manage` only; session of
   the tenant (else 404); test settings `identityCheck` ≠ `none` and `identityResult` = `pending` (else 409); sets the
   result, `identityCheckedByStaffProfileId`, `identityCheckedAt`. Same replay rule. Returns `ProctoringSession`.
4. Invalid bodies → 422 with field paths and a fixed message only — never the note text (V-7).
5. Hooks: `useReviewFlag()` → `{ flagId, sessionId, input }`; `useDecideIdentity()` → `{ sessionId, testId, input }`.
   Online only (plain `useMutation`, `networkMode: "always"`; offline → error "Connect to review"), a new
   idempotency key per call via `idempotencyHeaders`; invalidate `m34.proctoringFlags(sessionId)` /
   `m34.proctoringSessions(testId)` and `m34.proctoringSessions(null)`.
