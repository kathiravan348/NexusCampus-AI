# NEX-268 — M31 lesson block editor (create / edit drafts, blocks, alt text, captions)

**Status:** planned · **Owner:** — · **Branch:** task/NEX-268 · **Depends on:** NEX-228 (same M31 and i18n files)
**Requirements:** M31, O-1 (L2), D15, D42, D71, D72, V-7, WCAG 2.2 AA · split from NEX-228

## Goal
`m31.content.manage` creates lesson drafts and edits a draft's title, language, outcomes and blocks (text, image +
alt text, video + captions, question, embed); AI-drafted items keep their "AI-assisted" label.

## Build
1. Contract: `ContentLessonInputSchema` = strict `{ title, language, outcomeIds, blocks }` reusing the item field
   rules (`blocks` min 1, max 200, `ContentBlockSchema`). No id, tenant, status, version, `aiAssisted`, accessibility
   or timestamps in the input (server-set). Contract tests: image block without alt text and unknown keys rejected.
2. `POST /content-items` (`m31.content.manage`): creates `kind: "lesson"`, `status: "draft"`, `version: 1`,
   `aiAssisted: false`, `accessibility: null`, creator = caller profile; 201 parses with `ContentItemSchema`.
3. `PUT /content-items/:id` (`m31.content.manage`): lesson in `draft` only (else 409 `conflict`); keeps
   `aiAssisted`, sets `accessibility: null` (content changed) and a new `updatedAt`. Both writes: every asset id must
   belong to the tenant and match the block (image → `image`, video → `video`, captions → `captions`) else 422 with
   field paths only; outcome ids must exist in the tenant; other tenant / unknown → 404; no manage → 403.
4. Hooks `useCreateContentLesson()` / `useUpdateContentLesson()` via `useOutboxMutation` (`moduleId: "M31"`, as the
   NEX-228 hooks, idempotency headers), invalidating the list and item; offline → "queued" message (L2).
5. `LessonEditor`: form (title, language select, outcome multi-select) + ordered `BlockEditor` list; add block by type,
   move up / down buttons (keyboard, no drag-only), remove with confirm; client validation with the contract schema,
   errors linked to fields (`aria-describedby`); save disabled while invalid. Shows "AI-assisted" when set.
6. `BlockEditor`: text → plain textarea (markdown stored, never rendered as HTML here); image → asset select of
   `image` assets + required alt text field with 500-char counter; video → `video` asset + caption asset checkboxes
   (warning text when none: publish will be blocked); question → question id field; embed → https URL field, shows
   host name only (no iframe).
7. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; no lesson text, alt text or URLs in errors or logs.
