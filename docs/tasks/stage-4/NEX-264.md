# NEX-264 — MSW handlers + services: M37, M38, M91 — early years, inclusion, media and portfolios (read)

## Goal
Demo mode serves the NEX-260 M37, M38 and M91 data through MSW read endpoints with tenant isolation, deny-by-default
permissions and row filtering for families, and `@nexus/services` has typed hooks for them.

## Build
1. `fixtures/index.ts`: export `early-years`, `inclusion`, `portfolios`, `ids-stage4-care`. `db.ts`: a collection per
   array; `consents` = `CONSENTS` + `MEDIA_SHARING_CONSENTS`; no `DEMO_FIXTURES_VERSION` bump (if needed: a question).
2. Handlers: GET only, `get()` from `route.ts`, `list()` pages, `ofTenant` always, `entitled()` per module, 404 for
   another tenant's id; `?learnerId=` of a learner the viewer may not see → 404; files ≤ 300 lines; no personal data
   in errors. "Own learners": a guardian's linked learners (`guardianRelationships`), a learner's own learner rows.
   M37 (`m37.diary.read`): `/diary-entries?learnerId=&date=`, `/observations?learnerId=`, `/milestone-progress?
   learnerId=`, `/day-summaries?learnerId=`. Staff: whole tenant. Guardian: own learners only, diary entries and
   observations only with `sharedWithFamily`, an observation's `learnerIds` cut to own learners, day summaries only
   `sent`. `/pickup-checks?learnerId=&date=` and `/ratio-snapshots` need `m37.pickup.check` (staff only; a refusal
   reason never reaches families).
   M38 (`m38.plan.read`): `/support-plans?learnerId=`, `/support-plans/:id`, `/support-plans/:id/goals`,
   `/support-plans/:id/accommodations`, `/support-plans/:id/sessions`, `/support-plans/:id/progress`. With
   `m38.plan.manage`: the whole tenant; otherwise only plans where the viewer's staff profile is coordinator or in
   `teamStaffProfileIds` (else 404). Learners and guardians have no M38 grant → 403.
   M91: `/media-items` and `/learner-media-consents?learnerId=` need `m91.media.read` (staff; `deleted` items
   hidden); `/portfolios?learnerId=`, `/portfolios/:id`, `/portfolios/:id/entries`, `/portfolios/:id/exports` need
   `m91.portfolio.read`. Staff: whole tenant. Learner / guardian: own learners' portfolios with visibility
   `learner_and_family` only (else 404), and no entry whose media item is not `cleared` (consent withdrawn → hidden).
3. Services: one `useX()` hook per endpoint (pattern of `modules/m46.ts`, keys in `keys.ts`), exported from `index.ts`.
