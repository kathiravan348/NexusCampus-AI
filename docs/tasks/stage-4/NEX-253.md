# NEX-253 — Contracts (M45): credential templates, issued credentials, revocation, public verification

**Status:** ready-for-review · **Owner:** Claude · **Branch:** task/NEX-253 · **Depends on:** NEX-210
**Requirements:** M45, G-6, V-7, D46 (keys in OpenBao), D87 (split from NEX-217)

## Goal
`@nexus/contracts` defines certificates, badges and diplomas as Open Badges 3 / W3C verifiable credentials (or PDF
only): templates tied to outcomes, issued credentials with a hashed recipient, a status-list revocation entry and a
proof reference (never key material), and a public verification result that shows no learner data.

## Build
1. `CredentialKindSchema` `certificate | badge | diploma | micro_credential`; `CredentialFormatSchema`
   `open_badges_3 | w3c_vc | pdf_only`; `CredentialTemplateSchema` `{ id, tenantId, institutionId, kind, name (1–200),
   description (≤ 2000), criteria (1–4000), outcomeIds (unique, ≤ 20), imageAssetId (nullable), format, validityMonths
   (1–600, nullable), status (draft | active | retired), createdAt, updatedAt }`.
2. `CredentialProofSchema` `{ type (DataIntegrityProof | Ed25519Signature2020), verificationMethod (`did:web:` or
   `https:` URL, ≤ 500), created }` — a reference to the institution's public key; the private key stays in OpenBao.
3. `IssuedCredentialSchema` `{ id, tenantId, templateId, learnerId, credentialUri (`urn:uuid:` + UUID), issuerId
   (`did:web:…` or https URL, ≤ 500), recipientIdentityHash (`^sha256\$[0-9a-f]{64}$`, salted; never an email),
   issuedAt, expiresAt (nullable, > issuedAt), status (issued | revoked | expired), revokedAt + revokedReason (1–300)
   (set iff revoked, revokedAt ≥ issuedAt), verificationCode (`^[A-Z0-9]{8,16}$`), statusListIndex (int ≥ 0; set iff
   the format is not `pdf_only`), proof (set iff not `pdf_only`), format, evidenceEntryIds (unique, ≤ 10; M91 portfolio
   entries), issuedByStaffProfileId }`.
4. `CredentialVerificationSchema` (public) `{ verificationCode, result (valid | revoked | expired | not_found), kind,
   credentialName, institutionName, issuedOn (IsoDate), expiresOn (IsoDate, nullable) }` — `kind`, names and dates are
   null exactly when `not_found`; no learner name, id or hash (V-7, as `IssuedDocument`).
5. Doc comment (D46, V-7, G-6): signing keys live in OpenBao per institution and never appear in a contract, log or
   export; revocation flips the status-list bit at once; the verification page answers the same shape for unknown and
   malformed codes (no enumeration) and is rate limited; a learner may share or hide each credential.
6. `updatedAt >= createdAt`. Strict objects, `XSchema` + `type X`, named exports, ≤ 300 lines, no workspace imports.
