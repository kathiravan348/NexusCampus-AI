# NEX-215 — Contracts (M34): proctoring settings, sessions, recordings, flags for human review

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-215 · **Depends on:** NEX-247
**Requirements:** M34, A-4, A-5, G-6, V-7, D87 (rules 1–3), EU AI Act (no emotion recognition in education)

## Goal
`@nexus/contracts` defines online proctoring that a person decides on: a notice the learner accepts, an identity check
done by a person, recordings with a retention date, and flags that are only signals for review — no emotions, no
biometric templates, no automatic consequence.

## Build
1. `IdentityCheckModeSchema` `none | staff_photo_match | id_document_view`; `RecordingModeSchema` `none | screen |
   screen_and_camera`; `ProctoringSettingsSchema` `{ tenantId, testId, provider (`^[a-z][a-z0-9_-]{1,31}$`, settings
   key), identityCheck, browserLock, recording, retentionDays (1–365, set iff recording ≠ none), aiFlagging,
   noticeVersion (1–32; the notice learners accept), updatedByStaffProfileId, updatedAt }`.
2. `IdentityResultSchema` `not_required | pending | verified | not_verified`; `ProctoringSessionSchema` `{ id, tenantId,
   testId, attemptId, learnerId, status (waiting | in_progress | ended), noticeVersion, noticeAcceptedAt (set iff not
   waiting), identityResult, identityCheckedByStaffProfileId + identityCheckedAt (set iff verified | not_verified — a
   person, never a face match), startedAt + endedAt (nullable; startedAt iff not waiting, endedAt iff ended, ≥ start) }`.
3. `RecordingSegmentSchema` `{ id, tenantId, sessionId, kind (screen | camera), startedAt, endedAt (> startedAt),
   sizeBytes (1–10 000 000 000), deleteOn (IsoDate) }` — metadata only, no key or URL; recordings are personal data.
4. `ProctoringFlagKindSchema` `tab_switch | window_blur | copy_paste | device_disconnected | no_person_visible |
   another_person_visible | other_voices | other` — no gaze, emotion, behaviour or identity inference;
   `ProctoringFlagSchema` `{ id, tenantId, sessionId, kind, source (browser | ai | staff), aiGenerated (true iff ai),
   confidenceBps (0–10000, set iff ai), reason (1–300, plain words, A-5), occurredAt, offsetSeconds (int ≥ 0), review
   (pending | dismissed | upheld), reviewedByStaffProfileId + reviewedAt (set iff not pending, ≥ occurredAt),
   reviewNote (≤ 1000, nullable; required when upheld) }`.
5. Doc comment (A-4, D87): a flag never changes an attempt, score or record by itself; an upheld flag starts a person's
   academic-integrity process outside M34; settings with `aiFlagging` need the tenant AI switch; recordings are deleted
   on `deleteOn`; no biometric template is stored; learners see the notice before `in_progress`.
6. Strict objects, `XSchema` + `type X`, named exports, ≤ 300 lines, no workspace imports.
