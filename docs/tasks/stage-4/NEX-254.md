## Build
1. `CatalogueCourseSchema` `{ id, tenantId, institutionId, code (AcademicCode), name, programId (nullable; M15),
   deliveryMode (in_person | online | hybrid), sessionMinutes (15–480), ageMin / ageMax (0–120, nullable, min ≤ max),
   status (draft | active | retired), createdAt, updatedAt }`.
2. `SessionPackSchema` `{ id, tenantId, courseId, name, sessions (1–200), validityDays (1–730), price (MinorUnits ≥ 0),
   currency, trial, active }` — a trial pack has at most 2 sessions.
3. `PackPurchaseSchema` `{ id, tenantId, packId, learnerId, purchasedAt, expiresOn, sessionsTotal (1–200), sessionsUsed
   (0…total), feeInvoiceId (nullable; M18), status (active | exhausted | expired | refunded) }`; `exhausted` iff
   `sessionsUsed = sessionsTotal`; `expiresOn` not before the purchase date.
4. `ClassSessionSchema` `{ id, tenantId, courseId, staffProfileId, kind (regular | trial | make_up), startsAt, endsAt
   (> startsAt), roomId (nullable), liveSessionId (nullable; M36), capacity (1–500), status (scheduled | done |
   cancelled) }`.
5. `SessionBookingStatusSchema` `booked | attended | no_show | cancelled_by_learner | cancelled_by_institution`;
   `SessionBookingSchema` `{ id, tenantId, sessionId, learnerId, purchaseId, status, deductsSession, makeUpForBookingId
   (nullable, ≠ id), clientId (UUID; offline L2), deviceId (nullable), bookedAt }` — a booking cancelled by the
   institution never deducts a session; a make-up booking does not deduct again.
6. `LevelExamSchema` `{ id, tenantId, courseId, learnerId, level (1–50), examDate, externalBoard (≤ 100, nullable),
   examinerStaffProfileId (nullable), result (pending | pass | merit | distinction | fail), credentialId (nullable;
   M45, only with pass, merit or distinction) }`.
7. `PracticeFeedbackSchema` `{ id, tenantId, learnerId, courseId, mediaItemId (M91 recording), aiGenerated: literal
   true, tier, feedback (1–3000), focusPoints (≤ 5 of 1–200), status (draft | shared), sharedByStaffProfileId + sharedAt
   (set iff shared) }` — a teacher reviews and shares it (A-4); needs the tenant AI switch and, for minors, a guardian's
   `ai_features` consent (A-3).
8. Doc comment: server checks (capacity, packs used before expiry, refunds via M18, cancellation windows are settings).
   `updatedAt >= createdAt`; strict objects, named exports, ≤ 300 lines, no workspace imports.
