# NEX-251 — Contracts (M91): media items with consent state, portfolios, entries, portable exports

**Status:** planned · **Owner:** — · **Branch:** task/NEX-251 · **Depends on:** NEX-210, NEX-216
**Requirements:** M91, G-6, A-3, A-5, V-7, D87 (rule 4; split from NEX-216)

## Goal
`@nexus/contracts` defines the consent-aware gallery and learner portfolios: media shared beyond staff only when every
tagged learner's guardian allows it, people tagged by hand (never by face recognition), portfolio entries tagged to
outcomes, and a portable export that never carries other children.

## Build
1. `MediaConsentStatusSchema` `allowed | opted_out | pending`; `LearnerMediaConsentSchema` `{ tenantId, learnerId,
   status, consentId (Consent with purpose `media_sharing`; set iff allowed | opted_out), updatedAt }`.
2. `MediaVisibilitySchema` `staff_only | tagged_families | class_families`; `MediaItemSchema` `{ id, tenantId,
   institutionId, kind (photo | video | audio | document), fileName (plain file name), contentType, sizeBytes
   (1–2 000 000 000), sha256 (64 lowercase hex), capturedAt, uploadedByProfileId, taggedLearnerIds (unique, ≤ 30;
   tagged by a person), visibility, consentState (cleared | blocked | pending), caption (≤ 500, nullable), aiCaption
   (`{ text (1–500), tier }`, nullable; labelled AI), outcomeIds, aiSuggestedOutcomeIds (each unique, ≤ 10), status
   (active | archived | deleted), createdAt }`; a visibility other than `staff_only` needs `consentState: cleared`.
3. `PortfolioSchema` `{ id, tenantId, learnerId, title (1–200), visibility (learner_and_family | staff_only), status
   (open | archived), createdAt, updatedAt }`.
4. `PortfolioEntryKindSchema` `media | observation | assignment_submission | credential | reflection`;
   `PortfolioEntrySchema` `{ id, tenantId, portfolioId, kind, refId (null iff reflection), reflection (1–4000, set iff
   reflection; personal data), outcomeIds (unique, ≤ 10), addedByProfileId, addedByRole (learner | guardian | staff),
   addedAt }`.
5. `PortfolioExportSchema` `{ id, tenantId, portfolioId, format (pdf | zip), status (queued | ready | failed |
   expired), requestedByProfileId, requestedAt, readyAt (set iff ready | expired, ≥ requestedAt), expiresAt (set iff
   ready | expired, > readyAt, ≤ 7 days after), otherLearnersExcluded: literal true }` — no download URL (signed endpoint
   later).
6. Doc comment (G-6, A-3, V-7): `consentState` is computed by the server from every tagged learner's media consent
   (`cleared` only when all are `allowed`) and recomputed when a consent changes — a withdrawal hides the item from
   families at once; untagged faces are the uploader's duty; AI captions and outcome suggestions need the tenant AI
   switch and never identify people; exports drop or blur media that shows other tagged learners.
7. `updatedAt >= createdAt`. Strict objects, `XSchema` + `type X`, named exports, ≤ 300 lines, no workspace imports.
