check, `m31.content.publish` publishes only when the check has no errors.

## Build
1. `modules.ts`: `M31`, path `teaching/content`, icon `FileStack` (lucide), permission `m31.content.read`, `L2`, keys
   `m31.nav.title` / `m31.nav.summary`, lazy `../modules/m31/ContentPage`.
2. `ContentPage`: heading, intro, `LastSynced`; `useContentItems()` list (title, kind and status as text + icon,
   version, "AI-assisted" label); status filter; selecting one shows `ContentItemView` (back link; stacked at 360 px).
3. `ContentItemView`: metadata, outcome count, assets from `useContentAssets()` (file name, kind, size — no URL),
   `BlockPreview` for a lesson (text as escaped plain text, image shows alt text, video lists caption count, question
   shows its id label, embed shows the host name only, no iframe), `AccessibilityReport`, `PublishBar`.
4. `AccessibilityReport`: "Not checked" when null; else time and issues by severity (text + icon, translated code,
   "Block N" / "Whole item").
5. Write `POST /content-items/:id/accessibility-check` (`m31.content.manage`) recomputes `accessibility`: video block
   or item without captions → `missing_captions` error; audio item without transcript → `missing_transcript` error;
   markdown heading skipping a level → `heading_order` warning; `checkedAt` = now. Other tenant / unknown → 404.
6. Write `POST /content-items/:id/publish` (`m31.content.publish`): runs the same check; any error → 409 `conflict`
   (no item text in the error) and stores the check; already published / archived → 409; else `status: "published"`,
   new `updatedAt`, parses with `ContentItemSchema`; a person publishes (`aiAssisted` too).
7. Hooks `useCheckContentAccessibility()` and `usePublishContentItem()` via `useOutboxMutation` (`moduleId: "M31"`,
   same options as the m29 submit hook, idempotency headers), invalidating the item and list; offline the bar says the
   action is queued — L2. `PublishBar` shows "Fix the errors to publish" and disables publish while errors exist.
8. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; no personal data or content text in errors or logs.

- [ ] 360 px usable; RTL pseudo-locale ok; `fnm exec --using=24 -- pnpm --dir frontend review:check` passes; §9 done.
