## Goal
Demo mode serves the NEX-258 M39, M40 and M41 data through MSW read endpoints with tenant isolation, deny-by-default
permissions and the M39 reading-history privacy rules, and `@nexus/services` has typed hooks for them.

## Build
1. `fixtures/index.ts`: export `library`, `test-prep`, `session-courses`, `ids-stage4-more`. `db.ts`: a collection per
   array (`HARMONY_PRACTICE_MEDIA` joins the existing media collection if NEX-264 made one, else its own); no
   `DEMO_FIXTURES_VERSION` bump (if needed: a question).
2. Handlers: GET only, `get()` from `route.ts`, `list()` pages, `ofTenant` always, `entitled()` per module, 404 for
   another tenant's id; `?learnerId=` / `?borrowerProfileId=` the viewer may not see → 404; files ≤ 300 lines; no
   personal data or titles in errors.
   M39 (`m39.library.read`): `/catalogue-records`, `/catalogue-records/:id`, `/library-copies?recordId=` for everyone
   with the grant. `/loans`, `/holds`, `/library-fines`, `/reading-recommendations`: with `m39.circulation.manage`
   the whole tenant; a learner only own rows (all loan states); a guardian only own minor learners' loans with status
   `active` or `overdue` and their fines (no returned / lost loans, no holds, no recommendations — G-6); other staff
   only own rows.
   M40 (`m40.series.read`, staff only): `/test-series`, `/test-series/:id/ranks`, `/doubts?learnerId=`,
   `/doubts/:id/answers`, `/weak-topic-plans?learnerId=`, `/parent-reports?learnerId=`.
   M41 (`m41.course.read`, staff only): `/catalogue-courses`, `/session-packs`, `/pack-purchases?learnerId=`,
   `/class-sessions?from=&to=`, `/session-bookings?sessionId=`, `/level-exams?learnerId=`,
   `/practice-feedback?learnerId=`. Learners and guardians have no M40 / M41 grant → 403 (family views come later).
3. Services: one `useX()` hook per endpoint (pattern of `modules/m91.ts`, keys in `keys.ts`), exported from `index.ts`.
