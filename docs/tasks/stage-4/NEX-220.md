## Goal
`@nexus/mocks` has demo data in the M29–M31 contract shapes for every demo tenant (Little Steps EY, Riverside K12 group
with 2 campuses, Northbridge HE, Apex TP, Harmony SK), consistent with the Stage 3 fixtures they reference.

## Files
Create in `frontend/packages/mocks/src/fixtures/`: `ids-stage4-learning.ts`, `curriculum.ts`, `courses.ts`,
`content.ts`, `stage4-learning.test.ts`. Modify: `fixtures/index.ts` (4 lines).

## Build
1. `ids-stage4-learning.ts`: every new id as a named constant (D16); data files never use id literals.
2. `curriculum.ts`: `OUTCOME_FRAMEWORKS`, `OUTCOMES`, `OUTCOME_MAPPINGS`, `SYLLABUS_UNITS`, `LESSON_PLANS`,
   `COVERAGE_ENTRIES`. Little Steps: an EY milestones framework (≥ 6 milestones). Riverside: a group-wide standards
   framework (`institutionId` null) with parent and child outcomes, syllabus units for 2 subjects, lesson plans in every
   status (one `ai_draft`), coverage for 2 offerings. Northbridge: course-outcome and program-outcome frameworks with
   ≥ 4 CO → PO mappings. Apex: exam-syllabus standards. Harmony: a skills framework with graded levels.
3. `courses.ts`: `COURSE_SPACES` (a `class` space per Riverside offering on both campuses and one per other tenant;
   Harmony also a self-enrol `course`), `COURSE_MODULES` (2–4 per space, one with a prerequisite), `COURSE_ITEMS`
   (every kind at least once; `content` items point at `CONTENT_ITEMS`; links https), `COURSE_PROGRESS` (learners of
   the space's class groups), `DISCUSSION_THREADS`, `DISCUSSION_POSTS` (one reply, one hidden by a teacher).
4. `content.ts`: `CONTENT_ASSETS`, `CONTENT_ITEMS` (a lesson with every block type, a captioned video, an audio with a
   transcript, a SCORM 2004 and a cmi5 package; published items have a clean accessibility check; one draft lesson has
   a `missing_alt_text` error to show the publish block), `CONTENT_ATTEMPTS` (each status).
5. Staff are the tenant's `rp-…-staff` role profiles; learners come from `LEARNERS`; dates inside each tenant's calendar
   year; `CREATED_AT` / `UPDATED_AT` from `tenants.ts`; fictional, non-identifying text; files ≤ 300 lines.
6. D87 rule 5: export these sets from `fixtures/index.ts` for MSW only — not in `demoFixtures()`, no
   `DEMO_FIXTURES_VERSION` bump, nothing in `backend/`.
