# NEX-252 — Contracts (M44): surveys, questions, anonymity, responses, results, AI theme summaries

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-252 · **Depends on:** NEX-211

## Goal
`@nexus/contracts` defines course, faculty, parent and staff surveys whose anonymity holds: anonymous responses carry no
person or device, small groups are suppressed in results, and AI theme summaries quote no one.

## Build
1. `SurveyQuestionSchema` discriminated on `type`: `rating { id, prompt (1–500), required, scaleMax (3 | 5 | 7 | 10) }`,
   `single_choice` / `multiple_choice { id, prompt, required, options (2–10 unique strings of 1–200) }`, `text { id,
   prompt, required, maxLength (1–2000) }`.
2. `SurveyKindSchema` `course_feedback | faculty_feedback | parent | staff | general`; `AnonymitySchema` `anonymous |
   confidential | named`; `SurveySchema` `{ id, tenantId, institutionId, title (1–200), kind, audience (learners |
   guardians | staff), targetClassGroupIds, targetCourseSpaceIds (each unique, ≤ 50), subjectStaffProfileId (set iff
   faculty_feedback), anonymity, minResponsesToShow (3–50; ≥ 5 unless named), opensAt, closesAt (> opensAt), status
   (draft | open | closed | archived), questions (1–50, unique ids), createdByStaffProfileId, createdAt, updatedAt }`.
3. `SurveyAnswerSchema` `{ questionId, rating (int ≥ 1, nullable), optionIndexes (unique ints ≥ 0, ≤ 10), text (≤ 2000,
   nullable) }` (exactly one of the three is filled); `SurveyResponseSchema` `{ id, tenantId, surveyId,
   respondentProfileId (nullable), anonymous, answers (1–50, unique question ids), submittedAt, clientId (UUID),
   deviceId (nullable) }` — an anonymous response has no respondent and no device.
4. `QuestionResultSchema` `{ surveyId, questionId, responseCount (≥ 0), suppressed (= responseCount <
   minResponsesToShow, given), distribution (record of answer key → count ≥ 0; null iff suppressed), average (nullable;
   null when suppressed) }` with `minResponsesToShow` carried on the result.
5. `SurveyThemeSchema` `{ label (1–100), mentionCount (≥ 1), sentiment (positive | neutral | negative | mixed) }`;
   `ThemeSummarySchema` `{ id, tenantId, surveyId, questionId (nullable), aiGenerated: literal true, tier, themes (1–20),
   summary (1–3000), basedOnResponses (≥ 1), status (draft | published), publishedByStaffProfileId + publishedAt (set
   iff published) }` — no quotes field; a summary is made only when `basedOnResponses ≥ minResponsesToShow` (server).
6. Doc comment (G-6, A-4, V-7): the server never stores who answered an anonymous survey (a separate "has answered"
   marker prevents repeats); confidential responses are seen only by the survey owner; faculty results reach the staff
   member and their managers, and AI sentiment about a named person is never the sole basis for an appraisal (M50).
7. `updatedAt >= createdAt`. Strict objects, `XSchema` + `type X`, named exports, ≤ 300 lines, no workspace imports.
