# NEX-255 — Contracts (M43): store products, coupons, orders, subscriptions, affiliates

**Status:** planned · **Owner:** — · **Branch:** task/NEX-255 · **Depends on:** NEX-211, NEX-254
**Requirements:** M43, D9 (money), D19–D20, D87 (rules 1, 2; split from NEX-219), V-7

## Goal
`@nexus/contracts` defines a store with provider-neutral hosted checkout — products, coupons, orders that add up,
subscriptions and affiliates; no card data anywhere.

## Read first
- `AGENTS.md` §7–§10; `docs/MODULES.md` (M43); `docs/CONTRACTS.md` (`fees.ts` row); `contracts/src/{common,fees}.ts`

## Files
Create `contracts/src/store{,.test}.ts` (in `frontend/packages/`); modify its `index.ts`, `docs/CONTRACTS.md` (1 row each).

## Build
1. Money is integer minor units + `currency` (D9). `StoreProductSchema` `{ id, tenantId, institutionId, kind (course |
   session_pack | bundle | subscription), refIds (unique, 1–20; course spaces, packs, or — for a bundle — other product
   ids, never its own), slug (`^[a-z0-9-]{3,80}$`), title (1–200), description (≤ 10000), copySource (manual |
   ai_draft), price (≥ 0), currency, compareAtPrice (nullable, > price), billingInterval (month | year; set iff
   subscription), trialDays (0–90; set iff subscription), status (draft | published | archived),
   publishedByStaffProfileId (set iff published), createdAt, updatedAt }` — AI page copy is published only by a person.
2. `CouponSchema` `{ id, tenantId, code (`^[A-Z0-9-]{4,32}$`), kind (percent | amount), percentBps (1–10000, set iff
   percent), amount (> 0) + currency (set iff amount), productIds (unique, ≤ 50; empty = all), validFrom, validUntil
   (nullable, > validFrom), maxRedemptions (nullable, ≥ 1), redemptions (≥ 0, ≤ max), active }`.
3. `OrderLineSchema` `{ productId, unitPrice (≥ 0), quantity (1–10), discount (0…unitPrice × quantity) }`;
   `StoreOrderSchema` `{ id, tenantId, buyerProfileId (nullable for guest checkout), buyerEmail (Email; personal data),
   learnerProfileId (nullable; set once fulfilled), lines (1–20), couponId (nullable), subtotal (= Σ unitPrice ×
   quantity), discountTotal (= Σ discount), taxTotal (≥ 0), total (= subtotal − discountTotal + taxTotal), currency,
   status (pending | paid | fulfilled | refunded | cancelled | failed), provider (settings key), gatewayReference
   (≤ 200, nullable; never card data), affiliateId (nullable), paidAt (set iff paid | fulfilled | refunded), createdAt }`.
4. `StoreSubscriptionSchema` `{ id, tenantId, productId, learnerProfileId, status (trialing | active | past_due |
   cancelled | expired), currentPeriodStart, currentPeriodEnd (> start), cancelAtPeriodEnd, provider,
   externalSubscriptionId (≤ 200, nullable) }`.
5. `AffiliateSchema` `{ id, tenantId, name, code (`^[A-Z0-9-]{4,32}$`), commissionBps (1–5000), payoutEmail (Email;
   personal data), status (active | paused) }`; `AffiliateConversionSchema` `{ id, tenantId, affiliateId, orderId,
   commission (≥ 0), currency, status (pending | approved | paid | reversed) }`.
6. Doc comment (D19–D20, D87, V-7): checkout is the provider's hosted page — card numbers never reach NexusCampus;
   provider keys live in settings / OpenBao; no provider → store hidden; a minor cannot buy (a guardian does); refunds
   and tax display follow the region pack. `updatedAt >= createdAt`; strict objects, named exports, ≤ 300 lines.
