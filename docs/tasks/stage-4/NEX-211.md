# NEX-211 — Contracts (M30): course spaces, modules, items, progress, discussions

**Status:** planned · **Owner:** — · **Branch:** task/NEX-211 · **Depends on:** NEX-146
**Requirements:** M30, G-6, D25, D87

## Goal
`@nexus/contracts` defines course spaces — the place every Stage 4 teaching module plugs into (a K12 class, an HE
course, an online self-enrol course) — with modules, items, completion rules, progress and discussions.

## Read first
- `AGENTS.md` §7–§9; `docs/MODULES.md` (M30 row); `docs/CONTRACTS.md`; `frontend/packages/contracts/src/{common,academics}.ts`

## Files
Create in `frontend/packages/contracts/src/`: `courses.ts`, `courses.test.ts`. Modify: its `index.ts` (one line),
`docs/CONTRACTS.md` (one row; endpoint "Stage 4 build").

## Build
1. `CourseSpaceKindSchema` `class | course | community`; `CourseSpaceStatusSchema` `draft | published | archived`;
   `CourseSpaceSchema` `{ id, tenantId, institutionId, kind, subjectOfferingId (set iff class), code (AcademicCode),
   title (1–200), summary (≤ 2000, nullable), academicYearId (nullable), staffProfileIds (unique, 1–20), classGroupIds
   (unique, ≤ 20), status, startsOn / endsOn (IsoDate, nullable, end ≥ start), selfEnrol (true only for `course`),
   createdAt, updatedAt }`.
2. `CourseModuleSchema` `{ id, tenantId, courseSpaceId, title (1–200), order (int ≥ 1), unlockOn (IsoDate, nullable),
   prerequisiteModuleIds (unique, ≤ 10, not its own id), outcomeIds (unique, ≤ 20) }`.
3. `CourseItemKindSchema` `page | file | link | content | assignment | test | live_session | discussion`;
   `CourseCompletionSchema` `none | view | submit | pass`; `CourseItemSchema` `{ id, tenantId, moduleId, kind, title,
   order, refId (required for content, assignment, test, live_session, discussion; null otherwise), url (https only,
   set iff link), required, completion, passMarkBps (1–10000, set iff pass), dueAt (nullable), published }`.
4. `CourseProgressSchema` `{ tenantId, courseSpaceId, learnerId, completedItemIds (unique), percentBps (0–10000),
   lastActivityAt (nullable) }`.
5. `DiscussionThreadSchema` `{ id, tenantId, courseSpaceId, title (1–200), authorProfileId, pinned, locked, postCount
   (int ≥ 0), lastPostAt (nullable), createdAt }`; `DiscussionPostSchema` `{ id, tenantId, threadId, parentPostId
   (nullable, ≠ id), authorProfileId, body (trimmed 1–5000; personal data), hidden, hiddenByProfileId (set iff hidden),
   createdAt, editedAt (nullable, ≥ createdAt) }`.
6. `updatedAt >= createdAt` (`Date.parse`). Doc comment: server checks (module order unique per space, prerequisites
   in the same space without cycles, `refId` points to a record of the item's kind, staff and class groups of the
   institution). Strict objects, `XSchema` + `type X`, named exports, ≤ 300 lines, no workspace imports.
