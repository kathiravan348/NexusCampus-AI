# NEX-224 — MSW handlers + services: M36, M46 — live classes and early warning (read)

**Status:** planned · **Owner:** — · **Branch:** task/NEX-224 · **Depends on:** NEX-257, NEX-221, NEX-262

## Goal
Demo mode serves the NEX-257 M36 and NEX-221 M46 data through MSW read endpoints with tenant isolation, deny-by-default
permissions and row filtering, and `@nexus/services` has typed hooks for them.

## Build
1. `db.ts`: collections for `LIVE_SESSIONS`, `LIVE_JOINS`, `LIVE_RECORDINGS`, `LIVE_SUMMARIES`, `ENGAGEMENT_SNAPSHOTS`,
   `RISK_SCORES`, `INTERVENTIONS` (pattern of NEX-223).
2. Handlers: GET only, `get()` from `route.ts`, `list()` pages, `ofTenant` always, `entitled()` per module, 404 for
   another tenant's id; files ≤ 300 lines; no personal data in errors.
   M36 (`m36.live.read`): `/live-sessions?courseSpaceId=`, `/live-sessions/:id`, `/live-sessions/:id/joins`,
   `/live-sessions/:id/recordings`, `/live-sessions/:id/summary`. Sessions: course spaces the viewer may read
   (`learningSpaceAccess(viewer, "m36.live.host")`); a session with `courseSpaceId: null` only for admin / owner.
   Staff of the space (or admin) see all joins, every recording and draft summaries. A learner sees only joins whose
   `profileId` is one of their own role profiles, only recordings with `visibleToLearners` and status `ready`, and the
   summary only when `published` (else 404). Recordings are metadata only — no URL field exists; add none.
   M46 (`m46.risk.read`): `/engagement?learnerId=`, `/risk-scores?learnerId=&level=`, `/risk-scores/:id`,
   `/interventions?learnerId=`. Admin / owner: all of the tenant; a teacher: only learners of course spaces they are
   staff of (NEX-262 mastery rule). Risk scores whose `validUntil` is before `DEMO_NOW` (`fixtures/compliance.ts`) are
   hidden from lists and 404 by id. Learners and guardians have no M46 grant → 403 (A-3: never shown to families).
3. Services: one `useX()` hook per endpoint (pattern of `modules/m35.ts`, keys in `keys.ts`), exported from `index.ts`.
