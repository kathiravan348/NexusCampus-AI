## Rules
- The planner opens the next stage's folder (`stage-N/BOARD.md` + task files) at the current stage's freeze, and
  updates this table (task range, status). Next free task ID is one above the highest ID in any stage board.
- A stage is `done` when every task in its board is `done` or `withdrawn` and the Owner approved its release.
- Cross-stage work (e.g. a fix to a done stage) is a new task in the **current** stage's board.
- Two stages may be active at once only if the Owner says so; then both are marked **current** here.
