## Build
1. `modules.ts`: `M08`, path `forms`, icon `ListChecks` (lucide), permission `m08.config.read`, `L1`,
   keys `m08.nav.title` / `m08.nav.summary`, lazy `../modules/m08/ConfigPage`.
2. `ConfigPage`: heading, intro, `LastSynced` (fields query), `Tabs` "Fields" / "Forms" / "Workflows & numbering";
   "Ask Assist" button opening `AssistPanel` (same rule as `StructurePage`).
3. `FieldsTab`: entity select (`ConfigEntity`), fields in `order` (label in the current locale, else the first label;
   type, required, a "Sensitive" text badge; archived ones under "Archived"). `FormsTab`: forms with their field
   count. `WorkflowsTab`: workflows (subject, step count) and numbering formats (subject, pattern as returned).
   Empty / error states; 360 px usable (stacked cards, no table overflow).
4. Write: move the definition's fields into a shared const (as `academics.ts` did for class groups) and add
   `CustomFieldInputSchema` = those fields minus `id`, `tenantId`, `archived`, timestamps, with the same refines.
   `POST /custom-fields` (entitlement M08, permission `m08.config.manage`): label must include the tenant's
   `defaultLocale` (else 400 `invalid_request`, path `label`); duplicate `key` for the same `entity` in the tenant →
   409 `conflict`; server sets `archived: false`; adds to `mockDb.customFieldDefinitions`. Hook `useCreateCustomField()`
   invalidates the M08 keys.
5. `AddFieldDialog` (react-hook-form + zod): entity, key, label per supported locale (default required), type,
   required, sensitive, options editor only for `choice` / `multi_choice`, min / max only for `number`; shown only
   with `m08.config.manage`; disabled offline with `common.offline` as the hint.
6. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; no field values or labels in errors or logs (V-7).

## Questions
- Which locale settings govern a tenant-wide custom field when a Group has multiple institutions? The API guide documents locale settings by institution, while the field has only a tenant ID. Please identify the existing tenant-default lookup, or allow reading the locale-settings handler and campus tenant runtime so Codex can use the same rule in the dialog and POST.
  (answered by the planner 2026-11-24) Use the tenant's first institution — the same rule `GET /locale-settings`
  uses without `institutionId` (`institutionOf` in `mocks/src/handlers/m01.ts`): in the POST handler,
  `ofTenant(mockDb.institutions, viewer.tenantId)[0]?.locale.defaultLocale`. In the dialog use `useLocaleSettings()`
  (no institution, as `app/TenantRuntime.tsx` does): `defaultLocale` is required, `supportedLocales` lists the label
  inputs. You may read `mocks/src/handlers/m01.ts` and `app/TenantRuntime.tsx`; do not modify them (not in `Files`).
