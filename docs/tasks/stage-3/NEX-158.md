# NEX-158 — MSW handlers + services: M18–M23

**Status:** planned · **Owner:** — · **Branch:** task/NEX-158 · **Depends on:** NEX-155, NEX-156, NEX-157
**Requirements:** M18, M19, M20, M21, M22, M23, D9, G-6, V-7, D75

## Goal
The prototype can read fees, accounting, assessment, exams, report cards and issued documents from MSW,
tenant-scoped and permission-checked, through typed `@nexus/services` hooks.

## Read first
- `AGENTS.md` §7–§9; NEX-156 / NEX-157 handlers and services (follow them); `stage3-access.ts`;
  `frontend/packages/mocks/src/{db,context}.ts`, `handlers/route.ts`, `fixtures/{ops-fees,ops-assessment}.ts`
- `frontend/packages/contracts/src/{fees,accounting,assessment,exams,records}.ts`

## Build
1. `stage3-access.ts` (D75): add `m18.fees.read`, `m18.fees.manage`, `m19.accounts.read`, `m19.accounts.manage`,
   `m20.marks.read`, `m20.marks.enter`, `m21.exams.read`, `m21.exams.manage`, `m22.reports.read`,
   `m22.reports.publish`, `m23.documents.read`, `m23.documents.issue`. Roles: owner + admin all; teacher
   `m20.marks.read`, `m20.marks.enter`, `m21.exams.read`, `m22.reports.read`; guardian and learner none of these
   (family access below). Entitlements: M18–M23 for every demo tenant.
2. `db.ts`: collections for every NEX-155 fees / accounting / assessment / exam / record set.
3. Handlers (GET only, `get()`, `list()` pages, `ofTenant` always, `found()` → 404 for another tenant's id):
   M18 `/fee-heads`, `/fee-plans`, `/concessions`, `/fee-invoices?learnerId=&status=`, `/fee-payments?invoiceId=`,
   `/fee-refunds` — `m18.fees.read`; guardians / learners: only their family's invoices and payments; refunds
   staff only (`reason` is personal data).
   M19 `/ledger-accounts`, `/journal-entries`, `/budgets` — `m19.accounts.read` only (no family access).
   M20 `/grading-schemes`, `/assessments?classGroupId=`, `/rubrics`, `/assessments/:id/marks` — `m20.marks.read`;
   family: only their own learners' entries of `published` assessments; `remark` → `null` for family.
   M21 `/exams`, `/exams/:id/papers`, `/exam-papers/:id/seats`, `/hall-tickets?learnerId=`,
   `/revaluation-requests` — `m21.exams.read`; family: only their own hall tickets and revaluation requests.
   M22 `/report-cards?learnerId=` — `m22.reports.read` all; family: only their own `published` cards.
   M23 `/issued-documents?learnerId=` — `m23.documents.read`; family: only their own documents.
4. Money: integer minor units in the tenant's currency (D9). Services: one `useX()` hook per endpoint (pattern
   `modules/m13.ts`, keys in `keys.ts`), exported from `index.ts`.
5. i18n: `m18…m23.permission.<camelCase>` keys in en / hi / ta (D42). The harness runs `export:fixtures`.
6. Files ≤ 300 lines; no personal data (remarks, reasons) in errors or logs (G-6, V-7).

  `/fee-refunds`; no permission → 403.
- [ ] Service tests: each hook loads and parses (pattern `modules/m13.test.tsx`).
- [ ] `fnm exec --using=24 -- pnpm --dir frontend review:check` passes. Definition of done `AGENTS.md` §9.
