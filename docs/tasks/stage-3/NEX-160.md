## Goal
In demo mode the campus app has an "Academic structure" screen: programs with their year levels and class groups,
subjects with their offerings per academic year, an "Add class group" dialog for managers, and the Assist (M11) helper.

## Build
1. `modules.ts`: `M15`, path `academics/structure`, icon `Layers` (lucide), permission `m15.structure.read`, `L1`,
   keys `m15.nav.title` / `m15.nav.summary`, lazy `../modules/m15/StructurePage`.
2. `StructurePage`: heading, intro, `LastSynced` (programs query), `Tabs` "Programs & classes" / "Subjects"; an
   "Ask Assist" button opening `AssistPanel` (hidden when offline or AI is off — same rule as the shell's Assist entry).
3. `ProgramsTab`: each program (name, kind) with its year levels in `order` and their class groups (code, name, kind,
   capacity); batches without a year level under "No year level". Empty and error states; 360 px usable (no table
   overflow — stacked cards on small screens).
4. `SubjectsTab`: subjects (code, name, kind); academic-year select (`useCalendars(institutionId)` from M01) filtering
   `useSubjectOfferings(academicYearId)`.
5. Write: `ClassGroupInputSchema` = `ClassGroupSchema` fields minus `id`, `tenantId`, `institutionId`, timestamps.
   `POST /class-groups` (permission `m15.structure.manage`, `ofTenant` checks that program, year level and calendar
   exist in the tenant and the year level belongs to the program → else 400 `invalid_request`; duplicate `code` in the same
   academic year → 409 `conflict`); adds to `mockDb.classGroups`. Hook `useCreateClassGroup()` invalidates the M15
   keys. `AddClassGroupDialog` (react-hook-form + zod, field errors as text keys), shown only with
   `m15.structure.manage`, disabled offline (L1 = read-only offline) with `common.offline` as the hint.
6. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; no personal data in errors or logs.
