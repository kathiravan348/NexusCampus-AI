## Build
1. `stage3-access.ts` (D75; never `rbac.ts` or `backend/`): add `m12.admissions.read`, `m12.admissions.manage`,
   `m09.import.read`, `m09.import.manage`, `m86.rollover.read`, `m86.rollover.manage`, `m16.timetable.read`,
   `m16.timetable.manage`, `m17.attendance.read`, `m17.attendance.mark`, `m17.leave.decide`. Roles: owner + admin
   all; teacher `m16.timetable.read`, `m17.attendance.read`, `m17.attendance.mark`; guardian and learner
   `m16.timetable.read`. Entitlements: M09, M12, M16, M17, M86 for every demo tenant.
2. `db.ts`: collections for every NEX-155 admissions / import / rollover / timetable / attendance set.
3. Handlers (GET only, `get()`, `list()` pages, `ofTenant` always, `found()` → 404 for another tenant's id):
   M12 `/enquiries?status=`, `/applications`, `/admission-offers`, `/waitlist` — `m12.admissions.read`.
   M09 `/import-jobs`, `/import-jobs/:id/mappings`, `/import-jobs/:id/issues` — `m09.import.read`.
   M86 `/rollover-runs`, `/rollover-runs/:id/decisions` — `m86.rollover.read`.
   M16 `/rooms`, `/bell-schedules`, `/timetable-slots?classGroupId=&staffProfileId=`, `/teacher-load?academicYearId=`
   (computed from the slots into `TeacherLoad`; staff only) — `m16.timetable.read`; guardians / learners get only
   slots of their family's class groups (active `ENROLMENTS`, `familyOf`), and 403 on `/teacher-load`.
   M17 `/attendance-sessions?classGroupId=`, `/attendance-sessions/:id/marks`, `/leave-requests` — staff with
   `m17.attendance.read`; guardians / learners only their family's marks and leave requests (G-6). Mark `note` is
   `null` unless the viewer has `m17.attendance.mark`; `/leave-requests` lists only the viewer's family's requests,
   or all with `m17.leave.decide` (a teacher without it gets 403).
4. Services: one `useX()` hook per endpoint (pattern `modules/m13.ts`, keys in `keys.ts`), exported from `index.ts`.
5. i18n: `m09|m12|m16|m17|m86.permission.<camelCase>` keys in en / hi / ta (D42). The harness runs `export:fixtures`.
6. Files ≤ 300 lines; no personal data (contact details, notes, reasons) in errors or logs (G-6, V-7).
