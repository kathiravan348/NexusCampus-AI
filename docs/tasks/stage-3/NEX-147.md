## Goal
`@nexus/contracts` defines how an institution configures Stage 3 without code: its own fields on learners, guardians,
staff, enquiries and applications; forms built from them; approval chains with SLAs; and numbering formats.

## Build
1. `ConfigEntitySchema` `learner | guardian | staff | enquiry | application`.
2. `LocalizedLabelSchema`: record of `Locale` → trimmed text (1–120 chars), at least one entry (tenant-defined labels
   are tenant data; the institution's default locale must be present — a server check).
3. `CustomFieldTypeSchema` `text | long_text | number | date | choice | multi_choice | boolean | email | phone`;
   `CustomFieldDefinitionSchema` `{ id, tenantId, entity, key (/^[a-z][a-zA-Z0-9]{1,39}$/), label, type, required,
   sensitive (personal data: never in logs, exports need consent — V-7), options (for `choice` / `multi_choice` only:
   1–100 `{ value (key format), label }`, unique values), min / max (numbers, for `number` only, `min <= max`),
   order (int ≥ 0), archived, createdAt, updatedAt }`.
4. `CustomFieldValuesSchema`: record of field key → `string | number | boolean | string[] | null` (checked against the
   definitions by the server).
5. `FormDefinitionSchema` `{ id, tenantId, entity, name, fieldKeys (1–80, unique, in order), public (boolean; only
   `enquiry` / `application` forms may be public), published, createdAt, updatedAt }`.
6. `WorkflowDefinitionSchema` (approval chain) `{ id, tenantId, subject (`application | leave_request |
   document_request | fee_concession | record_change`), name, steps: 1–10 `{ id, approverRoleId, slaHours (int
   1–720, nullable), escalateToRoleId (nullable, not equal to approverRoleId) }` with unique ids, active, createdAt,
   updatedAt }`.
7. `NumberingFormatSchema` `{ id, tenantId, subject (`learner | application | receipt | invoice | certificate`),
   pattern (tokens `{YYYY}`, `{YY}`, `{CAMPUS}`, `{SEQ:n}` with n 1–9; exactly one `{SEQ:n}`; other text `[A-Za-z0-9/_-]`,
   max 60 chars), resetsYearly, nextSequence (int ≥ 1), updatedAt }`.
8. Every object `z.strictObject`; `updatedAt >= createdAt` (`Date.parse`); named exports; file ≤ 300 lines.
