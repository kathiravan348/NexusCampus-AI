## Build
1. Migration `0029`: `enquiry_forms` (`id`, `tenant_id`, `institution_id`, `created_at`), composite `(id, tenant_id)`
   reference to institutions, one form per institution (unique). ENABLE + FORCE RLS, `tenant_isolation`,
   `nexus_app` SELECT. Backfill one row per existing institution in Python with `pef-` ids from `nexus.core.ids`
   (cryptographically random — never `random()` / `md5`). Function `nexus_public_enquiry_form(form_id varchar)`
   (SECURITY DEFINER, owner-owned, `SET search_path`) returns only `tenant_id, institution_id` for that id;
   `REVOKE ALL FROM PUBLIC`, `GRANT EXECUTE` to `nexus_app`.
2. Routes, no session, in the mock's order: rate limit (step 3) → resolve the form with the function, then run the
   rest in that tenant's RLS transaction → `404 not_found` for an unknown id, M12 not entitled, or suspended
   institution (all identical). `GET /public/enquiry-forms/:formId` → `PublicEnquiryForm` (institution name, type,
   locales; active programs and campuses of that institution as `{ id, name }` only). `POST
   …/enquiries`: bad JSON → `400` path `""`; filled `website` → the same `202 { received: true }` and nothing stored;
   invalid fields → `400` with paths only; program / campus not of that institution → `400` path. Store a `new`
   enquiry, `source: public_form`, assignee null, institution from the form; audit `m12.enquiry.publicReceived`
   (`system` actor, field names only) in the same transaction; `202`, never echo data.
3. `ratelimit.py` (D81): Valkey fixed windows, keys `m12:pub:ip:<sha256(ip)>` and `m12:pub:form:<sha256(formId)>`.
   POST: 5 per IP per 10 min, 100 per form id per hour; GET: 60 per IP per 10 min. Counted before the form lookup
   (unknown ids too), honeypot posts count. Over the limit → `429 rate_limited` (path `""`) with `Retry-After`.
   Valkey unavailable → `429` (fail closed). IP from `request.client.host` only. Never log or store an IP, form
   input or a key.
4. Staff `GET /enquiry-forms` (module `M12`, `m12.admissions.manage`, paged) → `Page<EnquiryFormSummary>` of the
   viewer's tenant; guard before anything else.
5. Tests (real DB + Valkey): GET / POST happy path and stored row; honeypot stores nothing, same body; foreign program
   / campus `400`; unknown id, M12 off, suspended → identical `404`; IP and form limits `429` + `Retry-After`,
   unknown ids counted; no IP in Valkey keys or audit; forms of tenant B not listed; forced RLS on `enquiry_forms`;
   function returns ids only and `nexus_app` cannot read other tenants' forms directly; backfill ids are unique.
