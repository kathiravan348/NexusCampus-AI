# NEX-163 — M13 Learner records and M14 Families & guardians screens

**Status:** done · **Owner:** Gemini · **Branch:** task/NEX-163 · **Depends on:** NEX-156

## Goal
In demo mode the campus app has a "Learners" screen (searchable list → learner profile with enrolments, documents
and family) and a "Families" screen (households with guardians and pickup rights). Restricted data stays masked
exactly as the NEX-156 handlers return it; guardians see only their own children.

## Build
1. `modules.ts`: `M13` path `learners`, icon `GraduationCap`, permission `null` (the handlers scope guardians and
   learners to their family; staff need `m13.learner.read`), `L1`; `M14` path `families`, icon `HeartHandshake`,
   permission `null`, `L1`. Keys `m13.nav.title|summary`, `m14.nav.title|summary`.
2. `LearnersPage`: heading, intro, `LastSynced`; search by name or learner number (client side); list of learners
   (name, `learnerNumber`, `status`) — names come from `usePeople()` (M02, already scoped and masked); a person it
   does not return shows the learner number only; selecting one opens `LearnerProfile` (URL `learners/:learnerId` via the router's nested
   route pattern, or a `?learner=` search param if the router has none — note which in the Handoff).
3. `LearnerProfile`: details, enrolments (`useLearnerEnrolments`), documents (`useLearnerDocuments`: name, kind,
   status — no file download), health flags and custom fields **only as returned** (never re-derive hidden ones; an
   empty masked list shows nothing, not "none"), guardians (`useGuardianRelationships(personId)`) with pickup right;
   `court_restricted` shows a warning badge; the court note only when the response has it.
4. `FamiliesPage` + `GuardianList`: households (`name`, `address` as returned, members via `usePeople()`) and per learner the
   guardians and `useAuthorisedPickups(personId)`. Empty / error / 403 states (403 → the existing no-access message).
5. Accessibility: lists are real lists, the profile has headings per section, badges have text (not colour only);
   360 px usable (stacked, no horizontal scroll); pseudo-locale RTL ok.
6. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; no personal data in console, errors or test names.
