## Build
1. `ops-admissions.ts`: `ENQUIRIES` (3 per tenant, one `lost`), `APPLICATIONS` (2 per tenant), `ADMISSION_OFFERS`,
   `WAITLIST_ENTRIES`, `IMPORT_JOBS` (one completed, one dry-run with `IMPORT_ROW_ISSUES`), `COLUMN_MAPPINGS`,
   `ROLLOVER_RUNS` (one `dry_run_ready` per tenant) with `PROMOTION_DECISIONS` for its learners.
2. `ops-timetable.ts`: `ROOMS`, `BELL_SCHEDULES`, `TIMETABLE_SLOTS` (each class group ≥ 3 slots, no room / teacher
   clash), `ATTENDANCE_SESSIONS` (last 5 school days for one class group per tenant), `ATTENDANCE_MARKS` (one per
   enrolled learner per session; at least one `late` and one `absent`; one mark with a `deviceId`), `LEAVE_REQUESTS`.
3. `ops-fees.ts`: per tenant in its currency (INR / GBP / USD / SGD from the tenant's institution): `FEE_HEADS`,
   `FEE_PLANS` (instalments sum 10000), `CONCESSIONS`, `FEE_INVOICES` (one each of issued / part_paid / paid),
   `FEE_PAYMENTS`, `FEE_REFUNDS` (1 requested), `LEDGER_ACCOUNTS`, `JOURNAL_ENTRIES` (balanced), `BUDGETS`.
4. `ops-assessment.ts`: `GRADING_SCHEMES` (letter for K12, GPA for HE, descriptor for EY), `ASSESSMENTS`, `RUBRICS`,
   `MARK_ENTRIES` (one absent), `EXAMS`, `EXAM_PAPERS`, `SEAT_ASSIGNMENTS`, `HALL_TICKETS`, `REVALUATION_REQUESTS`,
   `REPORT_CARDS` (one published per tenant), `ISSUED_DOCUMENTS` (one signed transfer certificate).
5. `ops-communication.ts`: `MESSAGE_THREADS` (one class_group, one direct per tenant), `THREAD_MESSAGES`, `NOTICES`
   (one published to everyone, one scheduled to class groups), `MEETING_SLOTS`, `MEETING_BOOKINGS`.
6. Text that is personal data (remarks, reasons, notes, bodies) is short, fictional and neutral; no real names,
   phones or emails (`people.ts` ranges only). Money in integer minor units (D9). Files ≤ 300 lines; split a file
   into `…-2.ts` only if needed and list it in the Handoff.
7. D75: exported from `fixtures/index.ts` for MSW only — not in `demoFixtures()`, no `backend/` changes.
