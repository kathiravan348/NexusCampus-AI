# NEX-177 — M28 Dashboards screen (KPI tiles, units and trends, offline from cache)

**Status:** ready-for-review · **Owner:** Codex · **Branch:** task/NEX-177 · **Depends on:** NEX-159, NEX-176
**Requirements:** M28, M11, O-1 (L2), V-7, G-6, D42, D71, D72, D75

## Goal
An owner / admin opens "Dashboards" and sees the institution's KPI tiles (value by unit, trend as text and icon,
"as of" time) and "Ask Assist". The leader home card `/dashboards` opens this page. It renders offline from the
cache (L2). A user without `m28.dashboards.read` gets the existing no-access message.

## Build
1. `modules.ts`: `M28`, path `dashboards`, icon `ChartColumn` (lucide), permission `m28.dashboards.read`, `L2`, keys
   `m28.nav.title` / `m28.nav.summary`, lazy `../modules/m28/DashboardsPage`.
2. `DashboardsPage`: heading, intro, `LastSynced` (KPI query), "Ask Assist" (as `FamilyPortalPage`; prompt names no
   person). 403 → no-access message; error without cache → `m28.page.failed`; empty list → `m28.page.empty`;
   loading → the shared skeleton. Tiles in a grid: 1 column at 360 px, 2 at `sm`, 3 at `lg`.
3. `KpiTile`: label `t(kpi.labelKey)` (unknown key → `m28.page.unknownKpi`, never the raw code); value by unit —
   `count` → `formatNumber`; `percent` → `formatNumber` + `%` via an ICU key (`m28.unit.percent`); `minor_units` →
   `formatMoney(value, currency, locale)`; `days` → plural ICU key `m28.unit.days`. Trend: icon (`TrendingUp`,
   `TrendingDown`, `Minus`) with `aria-hidden` plus text `m28.trend.{up,down,flat}`; `null` → nothing. "As of"
   with `formatDateTime` (tenant locale and time zone). Tenant locale as in `m25/HomeCards` (pseudo → source).
4. i18n en / hi / ta (D42); tokens only (no colour meaning without text); files ≤ 300 lines; RTL ok; touch targets
   ≥ 44 px; no names, ids or values in console, errors or test names (V-7, G-6).
