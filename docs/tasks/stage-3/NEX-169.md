## Build
1. `modules.ts`: `M20`, path `gradebook`, icon `NotebookPen` (lucide), permission `m20.marks.read`, `L2`, keys
   `m20.nav.title` / `m20.nav.summary`, lazy `../modules/m20/GradebookPage`.
2. Contract: `MarkEntryInputSchema` = `{ marks, absent, rubricScores, remark }`; move these fields into a const and the
   absent refine into a named function + issue const, reused by `MarkEntrySchema` (as NEX-166 did for marks).
3. `GET /assessments/:id/roster` (entitlement M20, `m20.marks.read`): assessment in the viewer's tenant (else 404);
   learners enrolled (effective today) in the class group of its subject offering; page of `AttendanceRosterEntrySchema` (reuse, sorted as NEX-166).
4. `PUT /assessments/:id/marks/:learnerId` (entitlement M20, `m20.marks.enter`, active staff profile, else 403): assessment
   status `open` or `marking` (else 409 `conflict`, path `status`); learner on the roster (else 400 path `learnerId`);
   `marks ≤ maxMarks` (else 400 path `marks`); `rubricScores` null when the assessment has no rubric, else exactly the
   rubric's criterion codes with a score that is one of that criterion's level scores (else 400 path `rubricScores`).
   Upsert: replaces the learner's entry for that assessment (keeps its `id`), sets `enteredByStaffProfileId`,
   `enteredAt` now, `deviceId` null; 200 with it. Repeated `Idempotency-Key` per tenant → the stored result (as NEX-166).
   Errors carry paths only, never values.
5. Services: `useAssessmentRoster(assessmentId)`; `useSaveMarkEntry(assessmentId)` via `useOutboxMutation` (`moduleId`
   `M20`, operation `marks.enter`, `mergeRule` `lww-audited`, priority `normal`, idempotency header), updating the marks
   cache on success and exposing queued entries (as `useSaveAttendanceMark`).
6. `GradebookPage`: heading, intro, `LastSynced`, class group select (`useClassGroups()`), `AssessmentList` (name, kind as
   text, max marks, weight %, due date, status badge with text; selecting sets `?assessment=`). `MarkSheet`: one row per
   roster learner (name via `useLearners()` + `usePeople()`, else roll-number fallback), marks input (step 0.5, 0…max),
   "Absent" checkbox (clears and disables marks), percent shown, rubric scores as a select per criterion when the
   assessment has a rubric, optional remark (personal data), "Save" per row. Queued entry → "Waiting to sync" text badge.
   Not `open` / `marking`, or no `m20.marks.enter` → read-only. Touch targets ≥ 44 px; 360 px stacked, no horizontal
   scroll; RTL ok; i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; no names, marks, remarks or learner ids in
   console, errors or test names (V-7, G-6).
