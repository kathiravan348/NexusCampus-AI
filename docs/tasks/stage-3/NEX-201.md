# NEX-201 — Public enquiry form in the institution's language, with a language switch

**Status:** ready-for-review · **Owner:** Gemini · **Branch:** task/NEX-201 · **Depends on:** NEX-186
**Requirements:** M12, D42 (en + hi + ta), D79, G-1 (localisable UI, per-user language); NEX-186 review follow-up

## Goal
`/apply/<formId>` opens in the institution's default language (Riverside in Hindi, Apex in Tamil) with its own
wording pack, and the family can switch to any language the institution supports; the choice is kept on reload.

## Build
1. The page wraps the form in `I18nProvider` with the chosen locale and `typePack: institutionType`; `<html lang>`
   and `dir` follow the locale as the signed-in shell does.
2. Locale order: the family's saved choice for this form (localStorage key `nexus.publicLocale.<formId>`, only
   if still supported) → the institution's `defaultLocale`. A visible **Language** select lists `supportedLocales`
   with the same labels as `LocaleSwitch`; changing it re-renders without losing typed values.
3. Before the form loads (loading, not found, offline) the page uses the browser language if supported by the app,
   else English; nothing is stored until the family picks a language.
4. Tests: Riverside form renders Hindi texts by default; Apex Tamil; switching to English keeps typed values and
   survives a reload; an unsupported saved value falls back to the default; contract rejects a default locale
   missing from `supportedLocales`.
