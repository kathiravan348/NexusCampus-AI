# NEX-178 — M86 Year-end rollover screen (runs, promotion decisions, read-only)

**Status:** done · **Owner:** Codex · **Branch:** task/NEX-178 · **Depends on:** NEX-159, NEX-177
**Requirements:** M86, M11, O-1 (L1), V-7, G-6, D42, D71, D72, D75, D76

## Goal
An owner / admin opens "Year-end rollover" and sees the rollover runs (status, counts per action, fee carry-forward,
roll-back window) and, for a chosen run, its promotion decisions per learner with a filter by action. Read-only in
Stage 3 (D76). Offline: the cached page shows with "Last synced" (L1). Users without `m86.rollover.read` get the
existing no-access message.

## Build
1. `modules.ts`: `M86`, path `rollover`, icon `CalendarSync` (lucide), permission `m86.rollover.read`, `L1`, keys
   `m86.nav.title` / `m86.nav.summary`, lazy `../modules/m86/RolloverPage`.
2. `RolloverPage`: heading, intro, `LastSynced` (runs query), "Ask Assist" (as m25; prompt names no person). 403 →
   no-access; error without cache → `m86.page.failed`; no runs → `m86.page.empty`; loading → shared skeleton.
   Selected run kept in `?run=` (unknown id → newest run by `createdAt`).
3. `RolloverRunList`: one row / card per run: status as text (`m86.status.*`, Badge with text, not colour only),
   created date (`formatDate`, tenant locale), counts per action (`formatNumber`, `m86.action.*` labels), fee
   carry-forward yes / no, `rollbackUntil` shown only for `completed`. Never show raw ids (no year names exist yet:
   show the dates and status only).
4. `PromotionDecisions`: table on desktop, stacked cards at 360 px: learner (name via `useLearners` + `usePeople`,
   else learner number, else `m86.decision.learnerFallback`), action text, target class group name (`useClassGroups`;
   `null` → "—"), reason `t(reasonKey)` when known, "Changed by staff" text when `overriddenByStaffProfileId` is set
   (no staff name). Filter select by action (`?action=`, "All" default). Empty filter result → `m86.decision.none`.
5. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; RTL ok; touch targets ≥ 44 px; no names, ids or counts
   in console, errors or test names (V-7, G-6).
