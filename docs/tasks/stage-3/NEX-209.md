1. Export (version bump): fee heads, plans, concessions, invoices, payments, refunds; ledger accounts, journal
   entries, budgets; grading schemes, rubrics, assessments, mark entries; exams, papers, seats, hall tickets,
   revaluation requests; report cards, issued documents; message threads and messages, notices, meeting slots and
   bookings; rollover runs and promotion decisions.
2. Seed: insert in dependency order, upsert by id, tenant by tenant with `app.tenant_id` set; camelCase → snake_case

   the CLI builds it from settings, tests pass a fake vault). `--reset` deletes the new tables children first.
3. Tests: each seeded table has the mock's row count per tenant; sealed columns hold ciphertext; a second seed run
   changes nothing; the staff and family reads of M18–M24 and M86 return the demo rows through the API.
