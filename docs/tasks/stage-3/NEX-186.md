## Build
1. Contract: `PublicEnquiryFormSchema` {`id`, `institutionName`, `programs`: [{`id`,`name`}], `campuses`: [{`id`,`name`}]}
   — names only, nothing else about the institution; `PublicEnquiryInputSchema` {`learnerName`, `contactName`,
   `contactPhone` (E.164 or null), `contactEmail` or null, at least one of them, `programId`/`campusId` or null,
   `consent: true` (literal), `website` (honeypot, must be empty string)}; `PublicEnquiryReceiptSchema` {`received: true`}.
2. Mocks: one form per demo institution (`pef-` ids). `GET /api/v1/public/enquiry-forms/:formId` (no session) → form
   or `404`. `POST …/:formId/enquiries` → `202` receipt; stores an enquiry (status `new`, source `public_form`,
   no assignee) in the form's tenant; a filled `website` returns the same `202` but stores nothing; bad body →
   `400 invalid_request` with `details[].path`. Never echo stored data back. Staff route
   `GET /api/v1/enquiry-forms` (`m12.admissions.manage`) → the institution's form id(s).
3. Page `/apply/:formId` (outside the shell, no sign-in, demo banner kept): institution name, the same fields as
   **Add enquiry** with NEX-182 phone clean-up, consent checkbox (required, text names the institution), hidden
   honeypot, **Send enquiry** → a thank-you message; offline → "needs a connection" and the button is disabled.
   Unknown form → a not-found message. 360 px, light/dark, keyboard and screen reader labels.
4. Enquiries tab: **Copy public form link** (manage permission only) copies `<origin>/apply/<formId>`; toast.
5. Tests: contract (consent false, honeypot, no contact → fail); handlers (404, 202 stores, honeypot stores
   nothing, other tenant's form id cannot write elsewhere); page (send, validation, offline, not found); tab button.
