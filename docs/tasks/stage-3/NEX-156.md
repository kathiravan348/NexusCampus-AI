## Goal
Demo mode serves the NEX-154 data through MSW read endpoints with tenant isolation, deny-by-default permissions and
restricted-data masking, and `@nexus/services` has typed hooks for them — ready for the M15, M08, M13/M14 screens.

## Build
1. `stage3-access.ts` (D75 — mocks only; never edit `rbac.ts`, `plans.ts` or `backend/`): `STAGE3_PERMISSIONS`
   (`Permission` rows, same `perm()` shape): `m08.config.read`, `m08.config.manage`, `m13.learner.read`,
   `m13.learner.read_restricted` (sensitive), `m13.learner.manage`, `m14.family.read`, `m14.family.read_restricted`
   (sensitive), `m14.family.manage`, `m15.structure.read`, `m15.structure.manage`; `STAGE3_ROLE_PERMISSIONS`
   (`Record<SystemRoleKey, PermissionCode[]>`: owner + admin all; teacher the four `read` codes; guardian and learner
   `m15.structure.read` only); `STAGE3_ENTITLEMENTS`: M08, M13, M14, M15 enabled for every demo tenant.
2. `db.ts`: `permissions` = Stage 1 + `STAGE3_PERMISSIONS`; each system role (`roleId(tenant, key)`) gets its
   `STAGE3_ROLE_PERMISSIONS`; entitlements include `STAGE3_ENTITLEMENTS`; new collections for every NEX-154 set.
3. Handlers (GET only, `get()` from `route.ts`, `list()` pages, `ofTenant` always; 404 `found()` for another
   tenant's id): M15 `/programs`, `/year-levels`, `/class-groups`, `/subjects`, `/subject-offerings` (filter
   `?academicYearId=`) — `m15.structure.read`. M08 `/custom-fields?entity=`, `/forms`, `/workflows`,
   `/numbering-formats` — `m08.config.read`. M13 `/learners`, `/learners/:id`, `/learners/:id/enrolments`,
   `/learners/:id/documents` — with `m13.learner.read` all learners, else only the viewer's family (`familyOf`);
   `healthFlags` emptied and `customFields` of `sensitive` definitions removed unless `m13.learner.read_restricted`
   or family (G-6). M14 `/households`, `/guardian-relationships?learnerPersonId=`, `/authorised-pickups?learnerPersonId=`
   — `m14.family.read` or family; `courtOrderNote` → `null` unless `m14.family.read_restricted`.
4. Services: one `useX()` hook per endpoint (pattern of `modules/m02.ts`, keys in `keys.ts`), exported from `index.ts`.
5. i18n: `m08|m13|m14|m15.permission.<camelCase>` keys in en / hi / ta (D42). The harness runs `export:fixtures`.
6. Files ≤ 300 lines; no personal data in errors or logs.
