# NEX-168 — M19 Accounting screens (chart of accounts, journal, budgets)

**Status:** in-progress · **Owner:** Codex · **Branch:** task/NEX-168 · **Depends on:** NEX-158, NEX-167
**Requirements:** M19, M11, O-1 (L1), V-7, G-6, D42, D71, D72, D75

## Goal
In demo mode the campus app has an "Accounting" screen: finance staff see the chart of accounts, journal entries and
budgets (read), and post a balanced manual journal entry online (L1).

## Build
1. `modules.ts`: `M19`, path `accounting`, icon `Landmark` (lucide), permission `m19.accounts.read`, `L1`, keys
   `m19.nav.title` / `m19.nav.summary`, lazy `../modules/m19/AccountingPage`.
2. `AccountingPage`: heading, intro, `LastSynced` (journal query), "Ask Assist" (as `ConfigPage`), tabs Accounts /
   Journal / Budgets. A 403 from any list → the existing no-access message.
3. `AccountsTab`: accounts as a tree by `parentId` (code, name, kind as text, "Inactive" text badge); < 768 px stacked
   cards with indentation by logical padding. `JournalTab`: newest `postedOn` first; date, reference, source as text,
   total debit with `formatMoney`; open row shows lines (account code + name, debit, credit). `BudgetsTab`: per budget
   status badge with text, currency, lines (account, amount), total.
4. Contract: `JournalEntryInputSchema` = `{ institutionId, postedOn, reference, currency, lines }` with the same line
   rules; move the shared fields into a const and reuse `isBalancedJournalEntry` (named, with a shared issue const) in
   both schemas.
5. `POST /journal-entries` (entitlement M19, permission `m19.accounts.manage`, else 403): institution in the tenant;
   every `accountId` an active account of that institution (else 400 `invalid_request`, top-level path only, never
   values); `source` = `manual`, `createdAt` now. 201 with the entry. Hook `useCreateJournalEntry()` invalidates the M19 keys.
6. `PostJournalDialog` (react-hook-form + zod, `useFieldArray`; only with `m19.accounts.manage`): date (default today in
   the tenant time zone), reference, currency (tenant default), 2–20 lines (account select of active accounts, debit or
   credit in major units → minor). Live totals; "Post" disabled until balanced; disabled offline with `common.offline`.
7. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; 360 px stacked, RTL ok; no references, amounts or ids in
   console, errors or test names (V-7, G-6).

## Acceptance checks
- [ ] Riverside admin: sees the account tree, journal and budgets; posts a balanced entry; it appears first.
- [ ] Unbalanced lines → "Post" disabled and a lines error; inactive / other-tenant account → 400 field error.
- [ ] A viewer without `m19.accounts.read` gets no Accounting tile and the 403 message; without manage: no "Post entry", POST → 403.
- [ ] Offline from cache: "Last synced", post disabled. `fnm exec --using=24 -- pnpm --dir frontend review:check` passes (§9).

## Out of scope
- Editing / reversing entries, account or budget writes, reports (trial balance, P&L), fee auto-posting, backend (D75).
