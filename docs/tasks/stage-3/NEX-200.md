## Build
1. Migration `0025`: `custom_field_definitions`, `form_definitions`, `workflow_definitions`, `numbering_formats`,
   columns as the contract (snake_case); labels, options, field keys and workflow steps as JSONB; `tenant_id` on
   every table with composite `(id, tenant_id)` references as in `0024`. Unique custom field `key` per tenant and
   entity, archived rows included. Every table: ENABLE + FORCE RLS, `tenant_isolation`, `nexus_app` SELECT, plus
   INSERT on `custom_field_definitions` only.
2. Routes (prefix `/api/v1`, module `M08`): `GET /custom-fields?entity=` (`m08.config.read`; unknown entity →
   `400`), `GET /forms`, `/workflows`, `/numbering-formats` (`m08.config.read`, paged), `POST /custom-fields`
   (`m08.config.manage`) in the mock's order: guard first, then body; `400 invalid_request` whose `details[].path`
   names only known top-level contract fields (never a key the user typed); `400` path `label` when the label in the
   tenant's default locale (first institution) is missing; `409 conflict` for a duplicate key on the same entity
   (atomic, `ON CONFLICT`); `201` returns the stored row with `archived: false`.
3. Audit `m08.customField.created` (field names only, no values) in the same transaction; ids `cf-` via
   `nexus.core.ids`.
4. Tests (real database, as `tests/db/m15`): each route; paging; entity filter and bad entity; teacher without
   manage → `403`; module off → `403 module_disabled`; another tenant's rows invisible; duplicate key incl. archived
   → `409`; missing default-locale label → `400 label`; a user-typed key never appears in error paths; audit row;
   forced RLS on all four tables; models match the migrated schema.
