## Build
1. `modules.ts`: `M17`, path `attendance`, icon `ClipboardCheck` (lucide), permission `m17.attendance.read`, `L2`, keys
   `m17.nav.title` / `m17.nav.summary`, lazy `../modules/m17/AttendancePage`.
2. Contracts: `AttendanceRosterEntrySchema` = `{ learnerId, rollNumber }` (rollNumber as in `EnrolmentSchema`).
   `AttendanceMarkInputSchema` = `{ learnerId, status, minutesLate, note }` with the mark's `minutesLate` refine
   (move it to a named function, reused by both schemas); server sets `method: "manual"`, ids, times, staff, device.
3. `GET /attendance-sessions/:id/roster` (entitlement M17, `m17.attendance.read`, staff only as the list route):
   session in the viewer's tenant (else 404); learners with an enrolment in the session's `classGroupId` whose
   `effectiveFrom ≤ date ≤ effectiveTo` (null = open), sorted by roll number then id; `classGroupId` null → empty page.
4. `POST /attendance-sessions/:id/marks` (entitlement M17, `m17.attendance.mark`, active staff profile else 403):
   session `open` (else 409 `conflict`, path `status`); learner on the roster (else 400 `invalid_request`, path
   `learnerId`); appends a mark (`append-only`: never edits an older one), 201 with it. A repeated `Idempotency-Key`
   for the same tenant returns the first mark without appending (module-level `Map`). No body values in errors.
5. Services: `useAttendanceRoster(sessionId)`; `useSaveAttendanceMark(sessionId)` via `useOutboxMutation`
   (`moduleId` `M17`, operation `attendance.mark`, `mergeRule` `append-only`, priority `high`, idempotency header);
   on success it updates the marks query cache. Shown marks: the latest `markedAt` per learner.
6. `AttendancePage`: heading, intro, `LastSynced`, class group select (`useClassGroups()`), `SessionList` (date, mode
   as text, status badge with text; newest first; selecting sets `?session=`). `RollCall`: one row per roster learner
   (name from `usePeople()` via the learner's `personId`, else `m17.rollCall.learner` with roll number), status as a
   segmented control with text labels (present / absent / late / excused), minutes for late, optional note
   (`m17.attendance.mark` only); "Mark all present". A queued mark shows a "Waiting to sync" text badge. A session not
   `open` is read-only. Touch targets ≥ 44 px; 360 px, no horizontal scroll. i18n en / hi / ta (D42); tokens only;
   files ≤ 300 lines; RTL ok; no names, notes or learner ids in console, errors or test names (V-7, G-6).
