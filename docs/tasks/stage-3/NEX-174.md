# NEX-174 — M25 Family portal screen (home cards, child switcher, offline from cache)

**Status:** planned · **Owner:** — · **Branch:** task/NEX-174 · **Depends on:** NEX-159, NEX-173
**Requirements:** M25, M11, O-1 (L2), V-7, G-6, D42, D71, D72, D75

## Goal
A guardian opens "Family" and sees one home page: their children (switcher), summary cards with counts that link to
the module pages, and "Ask Assist". It renders offline from the cache (L2). Other roles get the no-access message.

  (`roleHome` — family branch); `frontend/packages/contracts/src/homes.ts` (`RoleHome`, `HomeCard`)

## Files

No contract, handler or service changes: use `useRoleHome()` and the existing `m28.card.*` keys as they are.

## Build
1. `modules.ts`: `M25`, path `family`, icon `House` (lucide), permission `null`, `L2`, keys `m25.nav.title` /
   `m25.nav.summary`, lazy `../modules/m25/FamilyPortalPage`.
2. `FamilyPortalPage`: heading, intro, `LastSynced` (role home query), "Ask Assist" (as `ReportCardsPage`).
   `useRoleHome()`: role `family` → page; any other role or 403 → the existing no-access message; error without
   cache → `m25.page.failed`. Loading → the shared skeleton / spinner the other pages use.
3. `ChildSwitcher`: children from `home.learnerIds`; name via `useLearners()` + `usePeople()`, else the learner
   number, else "Child". One child → just the name; more → a select (label "Child"), choice kept in `?child=`
   (unknown id → first child). Below it, links to Attendance, Fees, Report cards, Documents (module paths from
   `MODULES`, shown only when that module is in the nav for this user).
4. `HomeCards`: one card per `home.cards` item: title `t(card.titleKey)`, count (`formatNumber`, tenant locale;
   `null` → no number), severity as text when set, whole card is a link to `card.href` (router `Link`, ≥ 44 px).
   Counts are for all children together; say so once ("Totals for all your children") when there are 2+.
5. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; 360 px stacked (cards one column), RTL ok; touch
   targets ≥ 44 px; no names, learner ids or counts in console, errors or test names (V-7, G-6).

## Acceptance checks
- [ ] Riverside guardian with two children: switcher lists both by name, `?child=` keeps the choice, cards show
      counts and open the right module pages.
- [ ] Guardian with one child: name only, no select. Staff / leader / learner persona: no-access message.
- [ ] Offline from cache: page renders with "Last synced"; offline with no cache → failed message, no crash.
- [ ] `fnm exec --using=24 -- pnpm --dir frontend review:check` passes (§9).
