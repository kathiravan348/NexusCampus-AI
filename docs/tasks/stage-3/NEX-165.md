## Goal
In demo mode the campus app has a "Timetable" screen: a class group's week, rooms, bell schedules and teacher load
(read), an "Add slot" dialog for managers with room / teacher / class clash checks, and the Assist (M11) helper.

## Build
1. `modules.ts`: `M16`, path `timetable`, icon `CalendarClock` (lucide), permission `m16.timetable.read`, `L1`,
   keys `m16.nav.title` / `m16.nav.summary`, lazy `../modules/m16/TimetablePage`.
2. `TimetablePage`: heading, intro, `LastSynced` (slots query), "Ask Assist" (same rule as `ConfigPage`), tabs
   Week / Rooms & bells / Teacher load. The Teacher load tab is shown only to staff (the handler returns 403 to
   others: show the existing no-access message if it does).
3. `WeekTab`: class group select (`useClassGroups()`, first one selected), `useTimetableSlots(classGroupId)`; ≥ 768 px a
   weekday × time grid (weekdays 1–7 that have slots), < 768 px one list per weekday (stacked cards, no overflow).
   Each slot: subject name (`useSubjectOfferings()` → `useSubjects()`), start–end, room code or "No room".
4. `RoomsTab`: rooms (code, name, kind as text, capacity or "—", inactive badge) and bell schedules (name, periods
   with label, start–end, "Break" text badge). `LoadTab`: `useTeacherLoad()` rows — staff name if `usePeople()` can
   resolve it (see `mocks/src/handlers/m02.ts`), else `m16.load.staff` with the row number; periods, minutes, max or
   "No limit", "Overloaded" text badge.
5. Write: move the slot's fields into a shared const (as `forms.ts` did in NEX-161) and add `TimetableSlotInputSchema`
   = those fields minus `id`, `tenantId`, timestamps, with the same refines (named functions, reused).
   `POST /timetable-slots` (entitlement M16, permission `m16.timetable.manage`): offering / room / staff profiles /
   academic year must be in the tenant (else 400 `invalid_request`, top-level path only); a clash → 409 `conflict`
   with `details: [{ path }]`, path `roomId`, `staffProfileIds` or `subjectOfferingId` (same class group): another
   tenant slot on the same weekday whose times overlap (`start < other.end && other.start < end`) and whose effective
   dates overlap (null `effectiveTo` = open). 201 with the slot. Hook `useCreateTimetableSlot()` invalidates the M16 keys.
6. `AddSlotDialog` (react-hook-form + zod): offering, weekday, start, end, room (optional), teachers (multi-select of
   staff profiles from teacher load or the offering), effective from; academic year = the offering's. Shown only
   with `m16.timetable.manage`; disabled offline with `common.offline`; 409 → error on the clashing field.
7. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; RTL pseudo-locale ok; no names in console, errors or
   test names (V-7). Times as `HH:MM` text, weekday names from `Intl` in the current locale.
