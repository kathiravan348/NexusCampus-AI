## Goal
In demo mode the campus app has an "Admissions" screen for staff: enquiries pipeline, applications, offers and
waitlist (read), an "Add enquiry" dialog for managers, and the Assist (M11) helper. A person decides every outcome (A-4).

## Build
1. `modules.ts`: `M12`, path `admissions`, icon `ClipboardList` (lucide), permission `m12.admissions.read`, `L1`,
   keys `m12.nav.title` / `m12.nav.summary`, lazy `../modules/m12/AdmissionsPage`.
2. `AdmissionsPage`: heading, intro, `LastSynced`, "Ask Assist" button (as `StructurePage`), tabs Enquiries /
   Applications / Offers & waitlist. 403 → existing no-access message; empty / error states per tab.
3. `EnquiriesTab`: status filter (`useEnquiries(status)`), list (learner name, contact name, source, status badge with
   text, follow-up date, program name via `usePrograms()`); lost ones show the reason. Contact phone / email only in
   the opened row, never in the list summary line.
4. `ApplicationsTab`: application number, applicant name via `usePeople()` (absent → number only), program, status
   badge, submitted date (tenant time zone). `OffersTab`: offers (application number, class group, expiry, status)
   and waitlist (position order, application number, program).
5. Write: `EnquiryInputSchema` = `{ source, campusId, contactName, contactPhone, contactEmail, learnerName, programId,
   followUpOn }` with the same "phone or email" refine (reuse it as a named function). `POST /enquiries` (entitlement
   M12, permission `m12.admissions.manage`; `campusId` / `programId` must be in the tenant → 400) creates status
   `new`, `campaignCode: null`, `lostReason: null`, `assignedStaffProfileId` = viewer's staff profile or `null`;
   201 with the enquiry. Hook `useCreateEnquiry()` invalidates the M12 keys. Online only (L1: disabled offline).
6. `AddEnquiryDialog`: shown only with `m12.admissions.manage`; field errors from the schema and the 400 details.
7. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; 360 px stacked, RTL pseudo-locale ok; no names, phones
   or emails in console, errors or test names (G-6, V-7).
