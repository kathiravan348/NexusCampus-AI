# NEX-175 — M26 Learner portal screen (own home cards, quick links, offline from cache)

**Status:** planned · **Owner:** — · **Branch:** task/NEX-175 · **Depends on:** NEX-159, NEX-174
**Requirements:** M26, M11, O-1 (L2), V-7, G-6, D42, D71, D72, D75

## Goal
A learner opens "My portal" and sees one home page: summary cards with counts that link to the module pages, quick
links and "Ask Assist". It renders offline from the cache (L2). Other roles get the no-access message.

## Build
1. `modules.ts`: `M26`, path `learner`, icon `GraduationCap` (lucide), permission `null`, `L2`, keys `m26.nav.title` /
   `m26.nav.summary`, lazy `../modules/m26/LearnerPortalPage`.
2. `LearnerPortalPage`: heading, intro, `LastSynced` (role home query), "Ask Assist" (as `FamilyPortalPage`).
   `useRoleHome()`: role `learner` → page; any other role or 403 → the existing no-access message; error without
   cache → `m26.page.failed`. Loading → the shared skeleton / spinner the other pages use. No name or learner number
   on the page (the learner may not read the people list).
3. Cards: `HomeCards` with `home.cards` (one learner, so no "totals for all children" line).
4. `QuickLinks`: links to Timetable, Attendance, Report cards, Documents, Messages (module paths from `MODULES`,
   shown only when that module is in the nav for this user; none → render nothing). Links ≥ 44 px, one column at 360 px.
5. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; 360 px stacked, RTL ok; touch targets ≥ 44 px; no names,
   learner ids or counts in console, errors or test names (V-7, G-6).
