# NEX-197 — Stage 3 screens on real data: every Stage 3 screen against the real backend (M08–M28, M86)

**Status:** planned · **Owner:** — · **Branch:** task/NEX-197 · **Depends on:** NEX-196
**Requirements:** D78, D85, NEX-060 method (real-mode e2e). NEX-198 is folded into this task (D83 planning).

## Goal
In real mode every Stage 3 screen loads its data from the backend for an admin, a teacher and a guardian: no server
errors, no "failed to load" states, and permitted screens never answer `403`. (A route check found every one of the
126 mock routes served by the backend, so no handler work is left.)

## Files
Create: `frontend/e2e/real/stage3.spec.ts`. Modify: `frontend/apps/campus/vite.config.ts` (proxy target from
`NEXUS_API_URL`, default `http://127.0.0.1:8000`, for machines where that port is taken); `frontend/e2e/real/playwright.config.ts`
header note; `docs/guides/` testing notes if they list the real-mode run.

## Build
1. Spec: for each persona, sign in through Keycloak, open every menu screen, wait until ready; fail on any `/api`
   response ≥ 500, any `403` on a screen the menu offered, or a visible error state.
2. Run it live: Compose, `nexus-keycloak-dev`, the backend (`NEXUS_PORT` if 8000 is taken) and `pnpm dev:real`
   with `NEXUS_API_URL`; fix every backend or screen mismatch it finds in this task.
