# NEX-171 — M22 Report cards screens (staff list, card view, publish / withdraw, family view)

**Status:** done · **Owner:** Codex · **Branch:** task/NEX-171 · **Depends on:** NEX-158, NEX-170
**Requirements:** M22, M11, O-1 (L1), V-7, G-6, D42, D71, D72, D75

## Goal
Staff see report cards per class group and learner, open a card, and move it draft → approved → published or
published → withdrawn (online, L1). Guardians and learners see only their own published cards.

## Build
1. `modules.ts`: `M22`, path `report-cards`, icon `Award` (lucide), permission `null` (family viewers too; the handler
   decides), `L1`, keys `m22.nav.title` / `m22.nav.summary`, lazy `../modules/m22/ReportCardsPage`.
2. `ReportCardsPage`: heading, intro, `LastSynced` (report cards query), "Ask Assist" (as `ConfigPage`). Staff with
   `m22.reports.read`: class group select (`useClassGroups()`) and learner select; family: learner select only when
   more than one child. 403 → the existing no-access message.
3. `ReportCardList`: rows of learner name (`useLearners()` + `usePeople()`, else learner number), period / year id hidden
   → "Term" text, status badge with text, published date (tenant formatting). `?card=` opens `ReportCardView`.
4. `ReportCardView`: lines (subject name via `useSubjects()`, else "Subject"), grade, marks % (or "—"); remarks and the
   overall remark shown only to staff with `m22.reports.read` and to the card's own family (V-7: never in logs).
5. Contract: `ReportCardStatusInputSchema` = `{ status: "approved" | "published" | "withdrawn" }` (strict).
6. `POST /report-cards/:id/status` (entitlement M22, permission `m22.reports.publish`, else 403): card in the tenant
   (else 404); allowed moves draft → approved, approved → published, published → withdrawn (else 409 `conflict`,
   path `status`); `publishedAt` = now when published, `null` when withdrawn; `updatedAt` = now. 200 with the card
   (parse with `ReportCardSchema`). Errors carry paths only, never names, grades or remarks.
7. Service `useSetReportCardStatus(cardId)`: online mutation (as NEX-168 `useCreateJournalEntry`), invalidates the
   `queryKeys.m22` prefix.
8. `StatusDialog` (only with `m22.reports.publish`): shows the next allowed move as a button ("Approve", "Publish",
   "Withdraw"); confirm text says families see published cards and stop seeing withdrawn ones; disabled offline with
   `common.offline`; 409 → "This card changed, reload" message.
9. i18n en / hi / ta (D42); tokens only; files ≤ 300 lines; 360 px stacked, RTL ok; touch targets ≥ 44 px; no names,
   grades, remarks or learner ids in console, errors or test names (V-7, G-6).
