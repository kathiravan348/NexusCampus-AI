# NEX-097 — Staff SSO with mandatory MFA: realm `nexus-staff`, OIDC sign-in for Control, sessions

**Status:** in-progress · **Owner:** Claude · **Branch:** task/NEX-097 · **Depends on:** NEX-096
**Requirements:** P13 (staff SSO + mandatory MFA), D21 (staff identity separate from institutions), D44, D55

## Goal
Provider staff sign in to Nexus Control through their own Keycloak realm **`nexus-staff`** (never the product realm).
Every sign-in needs password **and** a one-time code (TOTP): the realm's browser flow maps the second factor to
level-of-authentication `mfa`, the backend asks for `acr_values=mfa` and refuses any ID token whose `acr` is not
`mfa`. A successful sign-in creates a short server-side session (hashed token in an HttpOnly, Secure-in-prod,
SameSite=Lax cookie, stored in `nexus_control`), records `last_sign_in_at`, and `/me` reads the session. Sign-out
revokes it. The dev header from NEX-096 keeps working outside prod only.
