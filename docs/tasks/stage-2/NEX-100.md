# NEX-100 — Control app real mode: staff sign-in, `/me` from the control backend, sign-out

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-100 · **Depends on:** NEX-097
**Requirements:** P13 (staff SSO + mandatory MFA), D50, D56 (screens frozen: sign-in page changes only in real mode)

## Goal
With `VITE_DATA_MODE=real`, Nexus Control signs staff in through the control backend: the sign-in page shows one
**Sign in with your work account** link to `/control/api/v1/auth/login` (password + one-time code in `nexus-staff`),
the app reads the staff session from `/me` (HttpOnly cookie, no token in the browser), a 401 sends the user back to
sign-in, and **Sign out** ends the session in Control and in Keycloak. Demo mode is unchanged.
