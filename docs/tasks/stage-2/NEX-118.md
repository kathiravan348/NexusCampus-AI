# NEX-118 — Lago sync, part 1: catalogue, customers, subscriptions and learner usage → Lago (one way, idempotent)

**Status:** ready-for-review · **Owner:** Gemini · **Branch:** task/NEX-118 · **Depends on:** NEX-116

## Goal
`python -m nexus.devtools.billing_sync [--dry-run]` pushes Control's billing data into Lago through the existing
`BillingEngine`, safely re-runnable: per-learner SaaS plans, the customers that subscribe, their subscriptions and
their learner counts as usage events. Only account id, name, country and currency ever reach Lago.

## Build
1. `sync.py` — `async sync_to_lago(conn, engine, dry_run) -> SyncReport` reading the control DB with the
   `control_app` connection (read only), in this order:
   - `ensure_learner_metric()`.
   - Plans: each **active** catalogue item of kind `saas_plan` with unit `per_learner_month` / `per_learner_year`,
     one Lago plan per regional price: code `<item.code>-<currency lower>-<monthly|yearly>`, `base_amount_minor` 0,
     `per_learner_minor` = the price. Any other kind / unit → skipped with a reason (later parts).
   - Customers: accounts with at least one `trialing` / `active` / `past_due` subscription → `BillingCustomer(id, name,
     country, currency)`, currency = the plan's regional price for the account's country; no price for that
     country → skip the account with a reason (never guess a currency).
   - Subscriptions: those same subscriptions → `subscribe(account_id, subscription.id, plan code for that currency and
     period)`. `cancelled` ones are not sent (terminating in Lago is part 2).
   - Usage: `learners` usage records whose tenant has a synced subscription → `UsageEvent(transaction_id = usage
     record id, subscription id, quantity, timestamp = period end)`; the record id makes a re-run count nothing twice.
2. `SyncReport`: counts per step and the skipped items with reasons (ids only, no names). `BillingUnavailable` →
   stop, report the step that failed, exit 1. `--dry-run` uses `FakeBillingEngine` and prints what would be sent.
3. `billing_sync.py`: settings from `ControlSettings` (Lago URL + key; key never printed); refuses to run when the
   key is empty (unless `--dry-run`).
