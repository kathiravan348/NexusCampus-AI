## Build
1. `control/parity.ts`: the same generator as `fixtures/parity.ts` (reuse its helper; do not copy it) over the
   Control contracts the real backend serves: Partner, Account, AccountContact, Opportunity, Contract, AccountNote,
   StaffDirectoryEntry, StaffSession, CatalogueItem, Quote, Subscription, Invoice, Payment, CreditNote, DunningState,
   UsageRecord, Licence, LicenceFile, Deployment, HealthSignal, Release, Rollout. Check the routes in
   `backend/src/nexus/control/main.py`; a served contract missing from this list is added, a listed one not served is
   left out and named in the handoff.
2. `control_contract_map.py`: contract name → Pydantic model. `test_control_parity.py`: unmapped contract fails;
   each sample parsed with `model_validate_json(…, strict=True)` must match Zod's verdict (or `shapeValid`).
3. Fix every drift in the backend model, never in the contract (D43/D56): ID patterns, enums, ranges, string
   lengths, nullability, no extra fields. A drift that needs a contract change → stop and write it under `Questions`.
4. `docs/CONTRACTS.md`: Control rows get their backend model or "mock only (stage 2 build pending)".
