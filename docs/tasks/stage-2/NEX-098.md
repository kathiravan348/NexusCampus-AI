## Goal
Lago (AGPL-3.0, open source) runs inside our control plane only, as a separate stack (`backend/compose.billing.yaml`):
its own PostgreSQL (`getlago/postgres-partman:15.0-alpine`), Valkey, migrate, API and worker
(`getlago/api:v1.57.0`), bound to 127.0.0.1, no Lago web UI, no PDF service. The control backend talks to it only
through a `BillingEngine` protocol (`LagoBillingEngine` over HTTP with the org API key, `FakeBillingEngine` for tests):
customers (our account id, name, country, currency — no institution data), the per-learner metric, plans,
subscriptions, usage events (idempotent transaction id) and current usage / invoices.
