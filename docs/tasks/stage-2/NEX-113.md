## Build
1. `c0006_fleet`: `deployments` (every Deployment field; `extension_ids` text[]; checks mirroring the contract's
   refines), `health_signals` (PK `deployment_id` → deployments; latest check-in only, no history),
   `deployment_agent_tokens` (`deployment_id` PK, `token_sha256` char(64) unique, `created_at`, `revoked_at`).
   Grants to `control_app`: SELECT on all three; UPDATE (version, health, last_check_in_at, telemetry_enabled) on
   deployments; INSERT, UPDATE on health_signals. No DELETE. Tokens are written only by the owner-role tool.
2. Export `deployments` and `healthSignals` from the mocks; `CONTROL_FIXTURES_VERSION` / `FIXTURES_VERSION` = 5;
   regenerate the JSON (`pnpm --filter @nexus/mocks export:fixtures`); seed both tables (upsert, after accounts).
3. `fleet.py`: two `Resource`s with `ctl.fleet.read` and the mocks' filters and keys (`deploymentId` for signals).
   Partner scoping like `visibleTo`: deployments by `account_id`; health signals have neither column, so partner
   viewers see none — make `Resource.scoped` return a false condition when the table has no `account_id` / `id`.
4. `POST /control/api/v1/agent/health`: `Authorization: Bearer <token>` only (no staff cookie, no CSRF); look up by
   SHA-256, refuse revoked / unknown → 401 (same answer for both). Body = HealthSignal **without** `deploymentId`
   (strict; > 4 KB → 413). Deployment from the token. Air-gapped deployment → 403. More than 1 report per 60 s per
   deployment → 429. Upsert the signal, set the deployment's `version`, `last_check_in_at` = server time,
   `telemetry_enabled` = true, `health` = `degraded` if uptimePct < 99 or errorRatePct ≥ 2 or p95LatencyMs ≥ 1500
   or diskUsedPct ≥ 90, else `healthy`. Answer 204. Log the deployment id and outcome only (no IP, no body).
5. `nexus-control-agent-token <deployment-id> [--revoke]` (owner connection): prints a new `token_urlsafe(32)` once, stores only its hash; re-issue replaces.
