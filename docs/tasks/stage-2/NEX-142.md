# NEX-142 — Nexus Control P18: buttons to start a move, confirm its staff steps and retry

**Status:** planned · **Owner:** — · **Branch:** task/NEX-142 · **Depends on:** NEX-136, NEX-139
**Requirements:** P18, D61, D63, D65 (Owner OK to change the frozen P18 screen), D8, D42, WCAG 2.2 AA

## Goal
Staff run a whole move from the Moves page (demo and real): start, confirm each staff step, retry — no API by hand.

## Build
1. Contracts, exactly as the backend bodies: `PortabilityRequestSchema` `{accountId, tenantId, direction, toRegion}`
   (region move needs two regions) and `ConfirmMoveStepSchema` `{step, pem?, fileName?, rows?, chainOk?,
   checkpointOk?}` (`fileName` a plain name, `rows` ≥ 1). Tests against mock samples.
2. Services hooks (refetch moves and accounts): `useStartMove()`, `useConfirmMoveStep(jobId)`, `useRetryMove(jobId)`.
3. Moves page (buttons only with `ctl.portability.manage`):
   - **Start move** modal: account, one of its tenants, direction, destination region; says the institution is frozen.
   - On the current step, when it is a staff step for that direction, **Confirm…** opens a modal asking only what that
     step needs: the destination's public key (self-hosted destination, `preflight`); file name and row count
     (self-hosted source, `export_encrypted`); "the file is in the destination's import folder" (`transfer`); row
     count and two checks (self-hosted destination, `import`); a cut-over warning that cannot be undone (`cutover`);
     "source copy deleted" (self-hosted source, `shred_source`). Cell steps show status only; a cell source's
     `shred_source` says two staff approve the source's key destruction on the Provisioning page (NEX-141).
   - **Retry** on a `failed` job. A failed request keeps the error state. All texts `p18.*` keys with `hi` / `ta`;
     real `<button>`s; works at 360 px.
4. Mocks (`handlers/p18.ts`, on the same `controlDb.portabilityJobs`): create (422 one-region move, 409 wrong
   delivery model), confirm (409 unless the current pending staff step), retry (failed only); cell steps finish at
   once in demo and stop at the next staff step; `shred_source` on a cell source completes in demo.
5. `CONTROL-GUIDE.md`: describe the buttons under Moves; drop P18 from the API-only known limit.
