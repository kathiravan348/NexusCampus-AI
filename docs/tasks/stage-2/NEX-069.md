# NEX-069 — Control contracts (operations): support desk, access broker, partners, compliance, projects, analytics

**Status:** planned · **Owner:** — · **Branch:** task/NEX-069 · **Depends on:** NEX-068
**Requirements:** P09, P10, P12, P14, P15, P16, V-3, V-5, V-6, V-7, D22, D50

## Goal
Zod schemas + types for how we support and run the business: tickets and SLAs, the provider side of access
requests (mirrors M83 so the institution approves), partners, trust operations, onboarding projects and business
metrics. Metadata only (V-7).

## Read first
- `AGENTS.md` §7; `frontend/packages/contracts/src/vault.ts` (M83 `AccessRequest`, `AccessGrant`,

## Files
Create (each with `*.test.ts`, using `control/test-utils.ts`):
- `frontend/packages/contracts/src/control/support.ts` — `TicketPriority` (`p1`–`p4`), `TicketStatus` (`new`, `open`,
  `waiting_customer`, `resolved`, `closed`), `SupportTicket` (accountId, subject ≤ 200, priority, status, assigneeStaffId?,
  slaDueAt, breached, channel `portal|email|phone`, createdAt; `resolvedAt` iff resolved/closed; no message bodies
  with institution data — `summary` ≤ 500), `TicketReply` (authorKind `staff|customer`, body ≤ 5000, `aiDrafted`,
  `internal`), `SlaPolicy` (slaTier → first response / resolution minutes per priority), `KnowledgeArticle`
  (title, body, locale, published)
- `.../control/broker.ts` — `BrokerRequest` (provider side of M83: id = the M83 `AccessRequest.id`, accountId,
  tenantId, requestedByStaffId, reason, modules, mode `read|edit`, durationHours 1–`MAX_GRANT_HOURS`, status
  `pending|approved|denied|expired|revoked|ended`, ticketId?, decidedAt?), `BrokerSession` (grantId, startsAt, endsAt
  ≤ 72 h, recorded true, actionsCount), `BreakGlassCase` (category as M83, two distinct approverStaffIds, tenantId,
  openedAt, institutionNotifiedAt ≥ openedAt, reportDeliveredAt?)
- `.../control/partner.ts` — `Partner` (name, country, tier `registered|silver|gold`, commissionPct 0–50, active),
  `DealRegistration` (partnerId, accountId, status `submitted|approved|rejected|expired`, expiresAt), `Commission`
  (partnerId, invoiceId, amountMinor, currency, status `pending|payable|paid`)
- `.../control/trust.ts` — `SubProcessor` (name, purpose, country, dpaSigned), `Certification` (`iso27001|soc2|
  iso27701|cert_in`, status, validUntil), `SecurityIncident` (severity `sev1`–`sev4`, status, affectedAccountIds,
  breachNotificationDueAt?, notifiedAt?), `DpaRecord` (accountId, version, signedAt)
- `.../control/project.ts` — `ImplementationProject` (accountId, kind `onboarding|migration|self_hosted_install|
  training`, status, goLiveDate?, tasks `{ title, done, dueDate? }[]` ≥ 1)
- `.../control/metrics.ts` — `BusinessMetrics` (period month, mrrMinor, arrMinor = 12 × mrr, currency, activeAccounts,
  newAccounts, churnedAccounts, grossChurnPct, nrrPct, openTickets), `AccountHealth` (accountId, score 0–100,
  `reasons` message keys, churnRisk `low|medium|high`, aiGenerated true)
