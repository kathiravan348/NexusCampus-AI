**Status:** done · **Owner:** Claude · **Branch:** task/NEX-076 · **Depends on:** NEX-075

## Goal
Staff with `ctl.licence.read` open **Licences**: every self-hosted licence with edition, modules, learner and campus
caps (learners used from PII-free usage, when the install reports it), expiry or "perpetual", support end,
online/offline activation and state. Staff with `ctl.licence.issue` renew a licence for a year (new signed file) and
download the licence file for offline (air-gapped) activation.
