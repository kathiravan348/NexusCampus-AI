# NEX-103 — Control API: licences (P05) — list, really signed licence files, renew

**Status:** in-progress · **Owner:** Claude · **Branch:** task/NEX-103 · **Depends on:** NEX-095, NEX-102
**Requirements:** P05, D23 (offline-verified licence), D52, V-7, D56

## Goal
The control backend serves the frozen Licences page: `GET /licences` (+ detail; filters `accountId`, `state`,
`edition`; partner scoping), `GET /licence-files/{id}` and `POST /licences/{id}/renew` (both `ctl.licence.issue`, as
the mocks). Unlike the mocks, files are **really signed**: Ed25519 in OpenBao Transit through `nexus.licensing`
(NEX-095), `signingKeyId` = the vault key version, `fingerprint` = SHA-256 of the canonical file. A demo licence
without a stored signature is signed on first download. Renewing (not revoked; else 409) moves expiry and support end
one year on, sets `active`, and re-signs — terms and signature change together in one transaction.
