# NEX-111 — Lago sync, part 2: signed invoice webhooks into Control, and cancellations

**Status:** planned · **Owner:** — · **Branch:** task/NEX-111 · **Depends on:** NEX-118

## Goal
Lago's invoices reach Control's own invoice list through a signed webhook (nothing unsigned is ever stored), and a
subscription cancelled in Control is ended in Lago by the sync.

## Build
1. `c0009`: `invoices.lago_invoice_id` (text, unique, nullable, internal: never in `Invoice`); sequence
   `invoice_number_seq`; table `billing_webhook_events` (`id` = SHA-256 of the raw body, `received_at`, `kind`).
   `control_app`: INSERT on invoices and billing_webhook_events, USAGE on the sequence; keep UPDATE (status, paid_at).
2. `POST /control/api/v1/billing/lago-webhook`: no cookie, no staff header. Body ≤ 256 KB, read raw. Verify Lago's
   HMAC signature (`X-Lago-Signature`, base64 HMAC-SHA256 of the raw body) with `NEXUS_CONTROL_LAGO_WEBHOOK_KEY`
   (SecretStr) in constant time; key empty or signature wrong → 401, nothing stored. A body seen before → 200, no-op.
3. `invoice.created` (finalized only; drafts ignored): customer `external_id` must be a Control account (else 422,
   log the Lago id only). Insert an `Invoice`: id `inv-` + 12 hex of the Lago id, number `INV-<year>-<6-digit seq>`,
   lines from fees (name, units ≥ 1, amount), subtotal / tax / total from Lago (must add up), tax scheme from the
   account country (IN → `gst`, EU / GB → `vat`, else `none`), status `open`. `invoice.payment_status_updated` →
   `succeeded` = `paid` + `paid_at`; `failed` = stays `open`. Unknown events → 200, ignored. Log event kind + ids only.
4. Cancellations: `BillingEngine.terminate(subscription_id)` (Lago `DELETE /subscriptions/{id}`; already ended or
   unknown = done). The sync terminates `cancelled` subscriptions it finds active in Lago and reports them.
5. `nexus-lago-dev` registers the dev webhook (HMAC) to the control backend and writes the key into `backend/.env`
   only when missing (never printed).
