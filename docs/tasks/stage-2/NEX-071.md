## Goal
A runnable Nexus Control app (`pnpm dev:control`, port 3200, mock mode) where provider staff pick a demo staff member,
see a menu built from their permissions, and open module screens that later tasks register with one line each.
Control texts live in their own catalogue (en/hi/ta), never in the tenant-overridable one (D53).

## Build
1. Menu = registered modules whose permission the staff member has; a module URL without it shows a "no access"
   page (deny by default). Home shows one tile per visible module. `DemoBanner` in mock mode.
2. Header: staff name + roles, light/dark, staff switch (mock), sign out. Locale switch en/hi/ta.
3. `@nexus/ui-control` is created by the first task that shares a control component between two screens.
