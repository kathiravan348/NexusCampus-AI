## Goal
The Owner can approve the Stage 2 release from one checklist with measured results: the Control app works in real
mode for every role with keyboard and screen reader, in en / hi / ta, within its budgets, and both Compose stacks
install, upgrade and back up cleanly.

## Build
1. Opt-in e2e against the real stack (`control-real` + control backend): sign in as each staff role (dev MFA helper
   as NEX-100's tests), visit every Control page the role may open; axe finds no serious or critical issue; every
   page also renders in hi and ta with no missing key and no raw key on screen.
2. Budgets (soft, as Stage 1): Control list endpoints p95 on demo data, the agent's command / health / update calls,
   Control app first load on a 4G profile; record numbers in `docs/TIMINGS.md`.
3. Install tests on this machine, each torn down after: `deploy/control` fresh install, upgrade (re-run), control-db
   and Lago backup + restore into a scratch volume; `deploy/compose` (product) the same, plus one tenant export /
   import between the two databases (NEX-119). Helm: only if NEX-120 is done, else listed as open.
4. `docs/review/STAGE-2-RELEASE.md`: every P01–P18 and M84 item with its task, test and result; NEX-110's security
   summary; Owner items (hi / ta native review, payment gateways NEX-107, Helm NEX-120, deck contact line).
