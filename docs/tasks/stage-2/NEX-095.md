# NEX-095 — Licence signing (Ed25519 in OpenBao) and offline verification for M84

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-095 · **Depends on:** NEX-068
**Requirements:** P05, D23 (offline-verified licence; expiry → grace → read-only, never data loss), D52, D55, V-6

## Goal
The backend can issue a signed licence file exactly in the `LicenceFile` contract shape (`nexus-licence/1`, terms +
base64 Ed25519 signature) with the private key kept inside OpenBao Transit (never exported), and an install can verify
it **offline** with only the public key: signature, known key, and the licence state on a given day (active, grace,
read-only after grace; a perpetual licence never stops working). One fixed test vector is shared with the frontend
contract test so both sides agree on the format.
