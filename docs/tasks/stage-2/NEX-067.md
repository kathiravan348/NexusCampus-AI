# NEX-067 — Control contracts (commercial): staff, accounts, CRM, plans, quotes, billing, usage

**Status:** planned · **Owner:** — · **Branch:** task/NEX-067 · **Depends on:** NEX-065
**Requirements:** P01, P02, P03, P11, P13, V-7, D15, D21, D50, D51, D52

## Goal
Zod schemas + types for the commercial side of Nexus Control, so mocks (NEX-070) and screens can be built against
them. Metadata only (V-7): institutions appear as an account name, type, country, region and tenant ids — never
their learners, families or staff.

## Read first
- `AGENTS.md` §7; `docs/DECISIONS.md` D50–D52; `frontend/packages/contracts/src/{common,page,plan}.ts`

## Files
Create (each with `*.test.ts`: valid example parses, each invalid rule rejects):
- `frontend/packages/contracts/src/control/staff.ts` — `StaffRole` (`super_admin`, `sales`, `billing`, `support`,
  `implementation`, `release_manager`, `sre`, `security_officer`, `partner`), `StaffUser` (id, displayName, work email,
  roles ≥ 1, mfaEnrolled, active, lastSignInAt?), `StaffSession` (staff, permissions: string[])
- `.../control/account.ts` — `DeliveryModel` (`saas_shared`, `saas_dedicated`, `self_hosted`, `hybrid`),
  `AccountStage` (`lead`, `trial`, `customer`, `churned`), `Account` (id, name, institutionType, country, region,
  deliveryModel, stage, ownerStaffId, partnerId?, tenantIds, learnerCount, healthScore 0–100, renewalDate?,
  createdAt), `AccountContact` (customer-side commercial contact: name, work email, phone E.164?, kind
  `billing|technical|executive|dpo`), `Opportunity` (stage `qualify|proposal|negotiation|won|lost`, value minor +
  currency, closeDate), `AccountNote` (authorStaffId, body ≤ 2000, createdAt), `Contract` (kind
  `saas_subscription|licence_perpetual|licence_term|support`, start/end dates, autoRenew, value, slaTier
  `standard|priority|enterprise`, status `draft|active|ended`)
- `.../control/pricing.ts` — `PriceUnit` (`per_learner_month`, `per_learner_year`, `flat_month`, `flat_year`,
  `per_pack`), `CatalogueItem` (code, nameKey or name, kind `saas_plan|addon|ai_credit_pack|licence_edition|support`,
  modules: ModuleId[], unit, prices: `{ country, currency, amountMinor, taxRatePct }[]`), `Quote` + `QuoteLine`
  (quantity, unitAmountMinor, discountPct 0–100) with totals that refine-check: subtotal = Σ lines, total = subtotal +
  tax; status `draft|sent|accepted|expired`, validUntil, `aiDrafted` flag
- `.../control/billing.ts` — `Subscription` (status `trialing|active|past_due|cancelled`, period `monthly|annual`,
  learners, current period dates), `Invoice` (+ lines; `taxScheme` `gst|vat|none`; status
  `draft|open|paid|overdue|void`; totals refine-check), `Payment` (method `card|upi|netbanking|bank_transfer`,
  gateway `razorpay|stripe|manual`, status `pending|succeeded|failed|refunded`), `CreditNote`, `DunningState`
- `.../control/usage.ts` — `ControlUsageMetric` (`learners`, `staff`, `storage_gb`, `ai_credits`, `messages`),
  `UsageRecord` (accountId, deploymentId?, tenantId?, metric, periodStart/End, quantity, cap?)
- `.../control/index.ts` (exports)
Modify:
- `frontend/packages/contracts/src/index.ts` (one export line), `docs/CONTRACTS.md` (Control section)
