## Goal

exactly as the mocks do, so those frozen screens work in real mode; partners see only their accounts' rows.

## Build
1. `c0011_delivery_extras`: `extensions`, `extension_compatibility` (FK extension; unique extension + release version),
   `implementation_projects` (tasks as `jsonb`, shape checked in the model), `sandboxes` — every contract field;
   checks mirroring the Zod refines (compatibility notes, project `live` rule, sandbox kind / data kind / account /
   expiry rules). `control_app`: SELECT only on all four.
2. Export the four mock collections (`extensions`, `compatibility`, `projects`, `sandboxes`); fixtures version 8 in
   `export.ts` and `seed.py`; seed after accounts.
3. `delivery_extras.py`: Resources `extensions` (`ctl.extension.read`, filter `accountId`), `extension-compatibility`
   (`ctl.extension.read`; `extensionId`, `releaseVersion`, `result`), `projects` (`ctl.project.read`; `accountId`,
   `status`, `kind`), `sandboxes` (`ctl.sandbox.read`; `kind`, `status`, `accountId`) with the mocks' keys. Partner
   scoping by the existing `Resource` rule only: compatibility rows and sandboxes without an account are hidden from
   partners, as in the mocks.
4. Parity: add `Extension`, `ExtensionCompatibility`, `ImplementationProject`, `Sandbox` to `control/parity.ts` and the map.

## Acceptance checks
- [ ] API tests per resource: list, each filter, detail and 404 match the fixtures; a role without the read
  permission → 403; partner sees only its accounts' extensions / projects / sandboxes, no compatibility rows;
  `control_app` cannot insert, update or delete; a project `live` with an open task or a sales demo with real data is
  refused by the database; parity tests green.
- [ ] `uv run --project backend backend-check` and `fnm exec --using=24 -- pnpm --dir frontend review:check` pass.
- [ ] Live: control DB migrated to c0011 and re-seeded; Control app in real mode (`control-real`): Extensions,
  Projects and Sandboxes pages show the fixture rows and a detail each; reset the dev data afterwards.
