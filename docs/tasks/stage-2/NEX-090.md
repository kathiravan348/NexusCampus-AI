**Status:** done · **Owner:** Claude · **Branch:** task/NEX-090 · **Depends on:** NEX-070

## Goal
In an install that runs on the institution's own servers, the admin opens **Install** (`/install`): licence summary
(edition, state, learners and campuses used of the cap, support end), version and channel, the available update
(online or signed offline bundle, security fix, covered by support), encrypted backups, telemetry on / off, and
diagnostic bundles — each marked "nothing is sent until you approve it". Read-only in the prototype.

**Demo install (decision, logged in `OWNER-AWAY-DECISIONS.md`):** no campus demo tenant is self-hosted; **Apex
Coaching** is `hybrid` in Nexus Control (its exam centres run local nodes), so its tenant gets the M84 entitlement
(source `core`) and the install fixtures, in the mock database only. Other demo tenants do not see the menu item.
