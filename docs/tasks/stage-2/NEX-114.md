# NEX-114 — M84: the install agent sends PII-free health reports to Control

**Status:** done · **Owner:** Gemini · **Branch:** task/NEX-114 · **Depends on:** NEX-113
**Requirements:** M84, V-4, V-6 (switchable, never when air-gapped), V-7, D23, D57

## Goal
`nexus-agent report` measures the install's health and sends one check-in to Control's
`POST /control/api/v1/agent/health` (NEX-113) — only counts, rates and timings, only when telemetry is on and the
install is not air-gapped. `loop` sends one report per run.

## Build
1. Settings: `control_url` (default `https://control.nexuscampus.example`), `control_agent_token: SecretStr`
   (empty = not paired), `agent_probe_url` (default `http://127.0.0.1:8000/healthz`), `agent_probes` (default 20).
2. `0019`: SQL function `nexus_install_active_users(since timestamptz) RETURNS integer`, SECURITY DEFINER,
   `SET search_path = pg_catalog, public`, counting distinct `sessions.user_id` with `last_seen_at > since` across
   tenants; returns a number only. `REVOKE ALL … FROM PUBLIC`; `GRANT EXECUTE` to `nexus_app` (as `0017` does).
3. `health.py` → a dict matching HealthSignal minus `deploymentId`: `at` (UTC, `Z`), `version` = `app_version`;
   `agent_probes` GETs to the probe URL (5 s timeout each): uptimePct = answered / sent, errorRatePct = 5xx and
   failures / sent, p95LatencyMs over answered probes; diskUsedPct of `install_dir` (`shutil.disk_usage`);
   queueDepth = running backups + generating diagnostic bundles; activeUsers = the function for the last 15 min.
   Round percentages to 2 decimals; clamp to the contract ranges.
4. `send_report`: if `air_gapped` or not `telemetry_enabled` or no token → do nothing and say why (no network call).
   Else POST JSON with `Authorization: Bearer`, 10 s timeout, TLS verified (never `verify=False`). 204 → "sent";
   401 / 403 / 429 / network error → a one-line reason, exit code stays 0 in `loop` so the agent keeps running.
   Never print or log the token, the body's URL query, or any person.
5. `run.py`: `report` mode; `once` / `loop` also call `send_report` after the status run.
