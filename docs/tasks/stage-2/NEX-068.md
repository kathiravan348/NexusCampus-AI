- `frontend/packages/contracts/src/control/provisioning.ts` — `ProvisioningRequest` (accountId, region,
  institutionType, planCode, trialDays?, deliveryModel), `ProvisioningJob` (steps `create_tenant|create_keys|

  ready, keys destroyed, `shredCertificateId?`)
- `.../control/deployment.ts` — `DeploymentKind` (`saas_shared_cell`, `saas_dedicated_cell`, `self_hosted`, `edge`),
  `Deployment` (id, accountId?, kind, region, version, channel, health `healthy|degraded|down|unknown`, lastCheckInAt?,
  telemetryEnabled, extensionIds, tenantCount), `HealthSignal` (counts and error rates only)
- `.../control/licence.ts` — `LicenceEdition` (`standard`, `enterprise`), `LicenceState` (`active`, `grace`,
  `read_only`, `expired`, `revoked`), `Licence` (edition, modules, learnerCap, campusCap, issuedAt, expiresAt?
  (null = perpetual), supportEndsAt, graceDays, activation `online|offline`, signingKeyId, fingerprint), `LicenceFile`
  (payload + base64 Ed25519 signature; schema only, signing is backend)
- `.../control/release.ts` — `ReleaseChannel` (`stable`, `lts`, `preview`), `Release` (semver, channel, status
  `draft|published|withdrawn`, publishedAt?, signed, offlineBundle, migrationNotes, minUpgradeFrom), `Rollout` (ring
  0–3, deploymentIds, status)
- `.../control/extension.ts` — `Extension` (accountId, name, version, signed), `ExtensionCompatibility` (releaseVersion,
  result `compatible|warning|incompatible`, notes)
- `.../control/sandbox.ts` — `Sandbox` (kind `sales_demo|staging_clone`, institutionType, dataKind
  `synthetic|masked`, expiresAt, status)
- `.../control/portability.ts` — `PortabilityJob` (direction `saas_to_self_hosted|self_hosted_to_saas|region_move`,
  from/to, steps with `pending|running|done|failed`, encrypted true), `ShredCertificate` (tenantId, keyIds, destroyedAt,
  signature)
- `frontend/packages/contracts/src/install.ts` (M84, in product) — `InstallStatus` (version, channel, licence summary +
  state, lastUpdateCheckAt, telemetryEnabled, airGapped), `UpdateOffer`, `BackupJob`, `DiagnosticBundle` (status
  `generating|ready_for_review|approved|sent|discarded`, scrubbed true, sizeBytes)
