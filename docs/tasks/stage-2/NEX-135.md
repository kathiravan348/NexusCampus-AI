## Goal
A destination cell's agent can hand Control its import public key (`tenant.import_key`) and load a moved tenant
from a file placed in its import folder (`tenant.import`), so a region move between our cells needs no shell access.
The source side reuses `tenant.freeze` and `tenant.export` from NEX-133.

## Build
1. `tenant.import_key` (no args): ensures the `tenant-import` Transit key (NEX-106) and returns `{pem, pemSha256}` —
   public material only.
2. `tenant.import` (args `{tenantId, fileName, pemSha256, expectedRows}`): `fileName` must be a plain name (no path
   parts) inside `import_dir`; the header's tenant id and fingerprint must match the args (else `rejected`); runs the
   NEX-119 import (all its refusals apply); then `verify_checkpoints` for the tenant; result
   `{tenantId, rows, checkpointsSkipped, chainOk, checkpointOk}`. The file is deleted after a successful import.
3. Both kinds run on cells (`saas`); on a self-hosted install only when the institution switched commands on
   (NEX-129); the import still refuses an existing tenant (D59).
4. Output and results: ids, counts, booleans; never people; the PEM is public and may be returned.
