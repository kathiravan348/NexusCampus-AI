# NEX-101 — Control API: accounts, contacts, opportunities, contracts, notes, staff directory (P01)

**Status:** done · **Owner:** Claude · **Branch:** task/NEX-101 · **Depends on:** NEX-096, NEX-100
**Requirements:** P01, P12 (partner users see only their own customers), V-7 (metadata only), D50, D56

## Goal
The control backend serves everything the frozen Accounts page (P01) reads and writes, with the exact contract
shapes the mocks serve: `GET /accounts` (filters `stage`, `deliveryModel`, `partnerId`, `region`; page envelope),
`GET /accounts/{id}`, `GET /contacts`, `GET /opportunities`, `GET /contracts` (filter `accountId` …), `GET /notes`,
`POST /notes` (`ctl.account.manage`), `GET /staff-directory`, `GET /partners` (`ctl.partner.read`, for partner names).
Every route checks the staff member's permission (deny by default) and a partner user only ever sees rows of the
accounts their partner manages. Data lives in `nexus_control`, seeded from the same fixtures as the mocks.
