# NEX-102 — Control API: catalogue & quotes (P02), billing (P03), usage (P11) on the control DB

**Status:** in-progress · **Owner:** Claude · **Branch:** task/NEX-102 · **Depends on:** NEX-101
**Requirements:** P02, P03, P11, A-1 (AI drafts need a person), D23 (billing never deletes data), D51, D52, V-7, D56

## Goal
The control backend serves what the frozen Pricing, Billing and Usage pages read and write, in the mocks' shapes:
`GET /catalogue`, `/quotes` (+ detail), `/subscriptions`, `/invoices`, `/payments`, `/credit-notes`, `/dunning`,
`/usage` with the mocks' filters, page envelope and partner scoping; `POST /quotes/{id}/send`
(`ctl.quote.manage`; draft only; an AI-drafted quote needs `checkedByHuman: true`) and
`POST /invoices/{id}/record-transfer` (`ctl.billing.manage`; open or overdue only; adds a `manual` payment with our
statement reference, pays the invoice, clears dunning, past-due subscriptions become active — all in one
transaction). The list/detail logic becomes one reusable resource helper (also used by P01).

**Split (planner):** the Lago sync (catalogue → plans, subscriptions → Lago, usage → events, Lago invoice webhooks →
control invoices) is its own task, NEX-111.
