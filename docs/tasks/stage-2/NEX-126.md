## Build

   (`affected_account_ids` text[] without duplicates; `breach_notification_due_at` set iff personal data affected and

   checks mirroring the Zod refines. `control_app`: SELECT only on all four.
2. Export `subProcessors`, `certifications`, `incidents`, `dpas`; fixtures version 10 in `export.ts` and `seed.py`;
   seed after accounts.
3. `trust.py`: Resources `sub-processors` and `certifications` (list only, `ctl.trust.read`), `incidents`
   (`ctl.trust.read`; `status`, `severity`; key `id`), `dpas` (`ctl.trust.read`; `accountId`; as the mocks' key).
   Partner scoping by the existing `Resource` rule only (DPAs by account; the others hidden from partners, as the
   mocks). Log ids only — incident titles are never logged.
4. Parity: add `SubProcessor`, `Certification`, `SecurityIncident`, `DpaRecord` to `control/parity.ts` and the map.
