# NEX-132 — Control: P04 provisioning for real, Control side — a job queues `tenant.provision` and follows it

**Status:** ready-for-review · **Owner:** Gemini · **Branch:** task/NEX-132 · **Depends on:** NEX-127, NEX-125 (c0017 first)
**Requirements:** P04, D60, D22, V-6, V-7, D50, D56, D57

## Goal
`POST /provisioning-jobs` creates a job and a signed `tenant.provision` command for the right cell; the job's steps
follow the cell's report; the account gains the tenant id only once `create_tenant` is really done. Staff can retry
a failed job. The mock's manual "advance" is never served in real mode.

## Build
1. `c0018`: `control_app` INSERT on `provisioning_jobs`; UPDATE (`steps`, `status`, `tenant_id`) on it; UPDATE
   (`tenant_ids`) on `accounts`; a column linking the job to its latest command (internal, never in the contract).
2. `POST /provisioning-jobs` (`ctl.provisioning.manage`, body = `ProvisioningRequest`): account visible (else 404),
   not self-hosted (409, as the mock), delivery model matches the account; the cell = the account's dedicated cell or
   the shared cell of `region` (none / air-gapped → 409). One transaction: job `prv-` + 16 hex, all steps `pending`,
   tenant id chosen now (`ten-` + 12 hex, kept internal until step 1 is done); signed command with args from
   NEX-127 (owner = the account's `executive` contact, else its `technical` contact: name and work e-mail only;
   none → 409). 201 with the job.
3. Command results update the job: each name in `stepsDone` → `done`; `failedStep` → `failed` and the job `failed`;
   all done → `done`. When `create_tenant` is done, the tenant id is set on the job and appended to the account's
   `tenant_ids` (once). Done in the result handler of NEX-128, for kind `tenant.provision` only.
4. `POST /provisioning-jobs/{id}/retry` (`ctl.provisioning.manage`): only `failed` jobs; queues a new command with the
   same tenant id (steps are idempotent); 409 otherwise. `…/advance` stays unserved (404).
5. Log job id, command id, step names and outcome only — never the owner's contact.
