   `paid_at` set iff paid), `business_metrics` (key `month` `YYYY-MM`; ARR = 12 × MRR; new ≤ active),
   `account_health` (key `account_id`; reasons `text[]` 1–5 message keys; churn risk / score rules) — every contract
   field, checks mirroring the Zod refines. `control_app`: SELECT only on all four.
2. Export `deals`, `commissions`, `metrics`, `accountHealth`; fixtures version 9 in `export.ts` and `seed.py`; seed
   after invoices.
3. Resources: `deals` (`ctl.deal.read`; `partnerId`, `accountId`, `status`), `commissions` (`ctl.partner.read`;
   `partnerId`, `status`), `metrics` (`ctl.analytics.read`, key `month`), `account-health` (`ctl.analytics.read`;
   `churnRisk`, key `accountId`). Partner scoping by the existing `Resource` rule only: deals and health by account;
   commissions and metrics have no account, so partners see none (as the mocks).
4. Figures are stored monthly snapshots as in the mocks; nothing is computed here. Log ids only.
5. Parity: add `DealRegistration`, `Commission`, `BusinessMetrics`, `AccountHealth` to `control/parity.ts` and the map.
